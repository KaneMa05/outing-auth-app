화면별 대응
로그인 / 포털

직무 / 인성 준비
- 상단 고정 돌아가기·중앙 모의면접, 모드 이름과 직렬 표시.

- 선택 상자의 제목·값·테두리·화살표를 구분하고 해당 버튼 옆에 체크 표시 팝업을 연다.
- 문항 수는 3/5/10/15/20. 분야·직렬·지역 필터와 시작 전 서버 재확인 유지.
- 정상 조회 실패는 빈 결과와 구분하며, 로그인·연결 안내와 재시도를 제공한다.

직무 / 인성 진행
- 질문 번호와 다시 듣기를 같은 행, 경과 시간을 그 아래에 표시.
- 실제 스피커/마이크 벡터 아이콘, 5개 음량 막대, 질문/답변 상태, 중앙 질문 문구.
- 첫 입력 확인 후 3초 카운트다운. 질문 재생 중 마이크는 멈춘다.
- 답변 녹음을 준비하고 첫 PCM 기록을 확인한 뒤 시작 알림음을 재생한다.
- 답변 시작 후 로컬 4초 침묵으로 한 번 전환. 첫 마디와 재생 중 WAV 보존.
- 직무는 답변 돌아보기 후 다음 질문, 인성은 다음 질문으로 진행한다.
- 질문 재생은 ID와 원문이 함께 일치하는 기존 녹음만 연결한다.

중간 확인 / 결과
- 중간 확인은 질문·내 녹음·내 답변·연습 피드백·자기 점검·다음 질문으로 구성한다.
- 중간 확인에는 예시답변과 예시답변 기준 판정을 표시하지 않는다.
- 모든 선택 문항을 완료한 결과에서만 예시답변·판정 근거를 펼쳐 본다.
- 중단된 결과에는 예시답변을 표시하지 않는다. 내 녹음·답변 기록은 유지한다.
- 결과 카드의 재생·나의 답변·예시답변·○/△/×/보류·근거·분석 중·피드백 순서를 맞췄다.
- 일부 판정만 확인된 경우 확인된 항목 수와 각 항목의 충족/보류 상태를 iPhone과 같이 표시한다.
- 같은 질문 재연습, 재생 중지, 다시 연습하기, 기록, 면접 준비로 이동을 제공한다.
- 화면이 바뀔 때만 위로 이동하며 같은 화면의 비동기 결과 갱신은 스크롤을 보존한다.

기록
- 계정별·모드별 기록만 표시하고 날짜·직렬·문항 수·분야·지역·보기·삭제 카드로 구성한다.
