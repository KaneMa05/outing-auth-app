# 면접반 마이 · DB 복사와 역할별 지침

면접반 앱의 마이와 웹의 마이 메뉴에서 저장된 본인 DB를 확인한 뒤 복사한다. DB와 지침은 각각 별도로 복사한다. 기존 일반 수강생 및 교사 화면의 메뉴와 기능은 변경하지 않는다.

## 본인 DB

- 마이에 진입할 때는 기존 수강 정보만 조회한다. DB 복사하기를 누를 때 기존 인증 API의 `life_get`과 `diagnosis_get`을 한 번씩 호출한다.
- 기본 이력, 자격·어학, 소속 이력, 수상·성과, 내용이 저장된 인생그래프 경험, 진단하기에 저장한 질문·답변 쌍을 출력한다. 현재 입력 양식과 이전 경험 양식을 모두 지원한다. 빈 항목은 생략하고 실제 0점·0%는 유지한다.
- 질문은 저장 당시 원문과 짝지어 표시한다. 별도 작성 답변, 강사 피드백, 이력, 내부 식별자, 계정 정보와 AI 지침은 포함하지 않는다. 경험별 추가 질문 세션의 미반영 원문도 이번 범위에는 포함하지 않는다.
- 이름·생년월일·성별·수험번호는 출력 항목에서 제외한다. 알고 있는 이름·수험번호·생년월일 표기와 입력 항목에서 식별한 학교·회사·소속명, 전화번호·이메일 형식도 가린다. 자유 입력 문장 전체의 완전한 익명화를 보장하지 않으므로 복사 전 원문 확인 안내를 제공한다.
- 원본과 저장 상태를 변경하지 않는다. 복사 자료를 localStorage, 서비스 워커, 로그 또는 별도 DB에 저장하지 않는다. 화면을 닫거나 계정 화면을 떠나면 내용을 비우고, 늦게 도착한 조회 결과를 무시한다.
- 자료 일부를 읽지 못하면 이전 내용을 비우고 재시도 안내를 표시한다. 경험이 없으면 작성·저장 안내를 표시한다.
- 복사 성공은 Clipboard API가 성공한 뒤 표시한다. 차단되면 전체 선택과 수동 복사를 안내한다. 외부 AI에 자동 전송하거나 파일로 저장하지 않는다.

## 역할별 지침

1. 경험 정리 코치: 실제 경험과 면접 주제를 연결하고 부족한 내용을 구체화한다.
2. 답변 구성 코치: 질문과 답변 시간을 먼저 확인하고 DB로 개요를 구성한다.
3. 실전 면접관: 질문을 한 개씩 하고 답변에 따른 꼬리질문으로 연습한다.
4. 평가·첨삭 코치: 작성 답변의 질문 적합성·구체성·논리·사실 일관성·표현을 점검한다.
5. 사실 확인 도우미: 정확한 정보와 확인한 출처·기준 시점을 바탕으로 사실을 점검하고 확인 불가능한 부분을 구분한다.

고정 문구이며 실제 AI 호출은 없다. 지침 선택·복사는 DB 조회를 추가로 발생시키지 않는다. 신상 정보 요구나 없는 경험 생성을 금지하는 공통 원칙을 포함한다.
