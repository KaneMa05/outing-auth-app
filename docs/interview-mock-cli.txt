모의면접 PC CLI 분석 실행 안내
2026년 11월 2일

전공 판정, 인성 구조 분석, 실전 종합 피드백을 기존 PC 질문 생성기와 같은
codex exec 방식으로 처리한다. 기본은 기존 API 경로이며 pc 모드를 명시한
기능만 새 대기열을 사용한다. 기존 학생 답변과 사실 기록 리포트는 보존한다.

구현 범위
학생 녹음 제출 -> 비공개 저장 -> PC 대기열 -> 별도 음성 전사 -> CLI 분석
-> 서버 근거 검증 -> 기존 응시 리포트 저장 -> 학생 화면 자동 상태 조회.
실전 종료 기록에는 종합 분석 버튼을 제공하며 결과를 별도 저장한다.
실시간 음성 대화와 진행 중 꼬리질문은 기존 경로를 유지한다.
iOS 네이티브 소스는 변경하지 않는다.

음성 인식 연결 전 검토
음성 인식 엔진 자체는 포함하지 않는다. scripts/interview-mock-transcriber.example.json
형식의 로컬 설정으로 실행 파일을 지정한다. 셸을 거치지 않고 WAV 경로와 패스 번호를
전달하며 stdout에서 {"text":"실제로 인식한 문장"} JSON을 받는다.
엔진 설치, 한국어 모델 확보, 실제 발화 품질과 처리 시간은 별도 검증한다.
외부 STT API를 선택하면 이 전사 어댑터만 바꿀 수 있다.
전사 설정 없는 PC 실행기는 종합 리포트만 처리하고 음성 작업은 가져가지 않는다.
서버의 INTERVIEW_MOCK_CLI_AUDIO_READY는 실제 전사 검증 후에만 true로 설정한다.

이 명령은 기존 ChatGPT 로그인과 계정 사용량을 소비한다. 과금 API 키는 전달하지 않는다.
출력 파일이 이미 있으면 재실행하지 않는다. .lock 파일이 남으면 이전 실행을 확인한다.
직접 입력한 전사문은 음성 인식 검증을 통과한 것으로 취급하지 않으며 전공 판정을 보류한다.

검증과 보관
전공은 두 CLI 실행의 실제 인용과 항목별 판정을 서버에서 다시 확인한다.
동일 모델 두 번 실행은 모델 다양성 검증을 대신하지 않으며 판정 제안을 보류한다.
모든 공식 grade/score는 null이다. 숫자 성적이나 합격 가능성을 확정하지 않는다.
인성은 네 요소 및 상황/본인 행동/결과의 원문 인용을 검증한다.
종합 피드백은 각 의견을 실제 학생 답변 인용과 연결한다.
PC 모델 실행은 독립 ephemeral 세션이며 도구/웹/개인 메모리를 끈다.
실행 영수증과 미전송 결과는 기존 Windows 현재 사용자 DPAPI로 암호화한다.
모델 실행 중에는 15초 간격으로 임대를 갱신하고, 최대 실행 시간은 25분이다.
임대 만료는 unknown으로 남기며 다른 PC에 자동 재배정하지 않는다.
완료 결과 업로드만 재시도하고 모델은 자동 재실행하지 않는다.
started 영수증, worker.lock, 결과 전달 실패가 남으면 실제 실행 종료와 결과부터 확인한다.
영수증/잠금 파일을 자동 삭제하여 새 모델 실행을 시작하지 않는다.
음성과 보고서는 기존 응시의 수강 종료 후 30일 보관 기한을 따른다.
기존 음성 정리 동작에서 만료된 큐 사본도 정리한다. 정리 스케줄 운영 연결은 별도로 확인한다.

처음 만든 임시 복사본은 디스크 공간 부족으로 불완전해 운영에 승격하지 않았다. 임시 복사본과 압축 파일만 정리하고 완전한 원본 폴더에서 재배포했다.
이 반영 기록 추가는 문서 전용이며 추가 앱 배포하지 않는다.
