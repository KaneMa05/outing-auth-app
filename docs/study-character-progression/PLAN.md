# 공부시간에 따라 달라지는 캐릭터 — 기획안

> 이전 시안 보관본입니다. 사용자 피드백을 반영한 현재 제안은 [불꽃형 기획안 v2](fire-v2/PLAN.md)입니다. 아래의 빛·노트·별 중심 외형은 v1 비교용입니다.

작성일: 2026-09-11 · 상태: 디자인 검토용, 운영 앱 미반영

## 제안

**같은 나, 조금 더 깊어진 집중.** 지금의 캐릭터를 유지한 채 공부 자세, 필기 흔적, 은은한 빛이 순서대로 더해진다. 열품타 스터디콘처럼 공부시간을 외형으로 알아볼 수 있게 하되, 현재 앱의 차분한 책상 장면에 맞춘다. 캐릭터를 다른 생물로 바꾸거나 큰 불꽃을 추가하지 않는다.

현재 코드는 검은 머리, 둥근 얼굴, 작은 점 눈, 선택 가능한 옷 색상, 나무 책상과 의자, 펼친 책과 컵으로 이루어진 CSS 캐릭터다. 시안은 이 도형을 `styles.css`에서 복사하여 사용했다. 선택 색상 중 현재 스터디 화면의 청록 계열을 대표로 사용했다. 시안의 화면 배치와 단계 효과는 새 제안이며, 운영 화면을 캡처한 것은 아니다.

## 적용 범위 제안

1차 적용은 **인터넷 수강생 화면(`lecture`)의 스터디카페 캐릭터**를 권장한다. 내 좌석, 좌석 상세, 나의 캐릭터에서 동일한 단계가 보이도록 한다. 다른 사람의 좌석에서도 하루 순공시간에 맞는 간소화된 효과를 표시한다. 기존 홈 · 플래너 · 스터디카페 · 마이 메뉴 체계를 유지하고, 마이에서 진입하는 나의 캐릭터 화면에 성장 안내를 추가한다.

온라인 관리반과 오프라인 수강생, 교사·관리자 화면으로 확대하는 것은 별도 범위로 둔다. 사용자 요청에서 수강생 유형이 특정되지 않았으므로 이 범위는 기획 가정이다. 이번 산출물은 문서와 독립 시안만 추가하며 앱 동작을 변경하지 않는다.

## 단계 정의

기준은 **한국시간 기준 당일 누적 순공시간**이다. 한 번에 연속으로 공부할 필요 없이 과목과 세션을 합산한다. 쉬는 시간은 제외한다. 정확히 임계치에 도달하는 순간 다음 단계가 된다.

| 단계 | 누적 시간 | 외형 변화 | 안내 문구 |
|---|---|---|---|
| 기본 · 공부 시작 | 0 이상 ~ 3시간 미만 | 현재 캐릭터와 책상 그대로 | 나만의 속도로 시작해요 |
| 1 · 집중에 들어선 나 | 3 이상 ~ 5시간 미만 | 고개가 책 쪽으로 1~2px 낮아짐. 손끝 연필과 책의 필기 흔적 추가 | 차분히 집중이 쌓이고 있어요 |
| 2 · 흐름을 찾은 나 | 5 이상 ~ 7시간 미만 | 이전 모습 + 책갈피, 작은 정리 노트, 아주 옅은 민트빛 | 공부에 나만의 리듬이 생겼어요 |
| 3 · 깊이 몰입한 나 | 7 이상 ~ 9시간 미만 | 이전 모습 + 겹친 노트와 몸 뒤의 부드러운 집중빛 | 꾸준히 쌓아온 시간이 보여요 |
| 4 · 빛나는 집중 | 9 이상 ~ 10시간 미만 | 집중빛이 따뜻한 금빛으로 바뀌고 어깨 옆 반짝임 2개 추가 | 오늘의 노력이 은은하게 빛나요 |
| 5 · 오늘의 결실 | 10시간 이상 | 이전 모습 + 얇은 금빛 아치, 작은 별 1개 | 충분히 쌓았어요. 잠깐 쉬어가요 |

10시간 이후에는 외형을 더 과장하지 않고 최종 모습을 유지한다. 단계명은 개인의 성취를 나타내며 학생의 우열·능력 등급으로 표현하지 않는다.

## 자연스럽게 보이는 규칙

- 얼굴, 머리, 피부색, 체형과 책상 크기는 모든 단계에서 고정한다. 선택한 의상·모자·의자와 옷 색상도 유지한다.
- 단계마다 직전 단계의 요소를 보존하고, 한두 종류의 변화만 추가한다. 9시간에서 빛 색상이 변할 때 민트에서 금빛으로 부드럽게 이어진다.
- 고개 숙임은 3시간에 작게 바뀐 뒤 유지한다. 단계가 높아질수록 계속 숙이거나 몸을 크게 흔들지 않는다.
- 기본 캐릭터의 숨쉬기·필기 리듬을 유지한다. 시간에 비례해 동작을 빠르게 하지 않는다.
- 모자 영역을 피해서 별·아치를 배치한다. 착용 모자가 큰 경우 상단 여백을 늘리거나 별을 장면 모서리의 배지로 옮긴다. 장식이 얼굴을 덮지 않게 한다.
- 정리 노트는 책상 왼쪽의 보조 영역에 둔다. 구매한 책상 소품과 겹치는 경우 소품을 우선하고 노트는 생략한다. 이때 빛과 단계 배지는 유지해 식별 가능하게 한다.
- 랭킹룸·여러 좌석의 축소 화면에서는 빛, 작은 단계 배지만 남긴다. 필기선·노트·반짝임의 반복 애니메이션은 상세 화면에서만 허용한다.

## 화면 구성

**나의 캐릭터:** 오늘 순공시간 → 캐릭터 장면 → `7시간 달성 · 깊이 몰입한 나` 배지 → 짧은 응원 문구 순서. 아래에 3·5·7·9·10시간의 5개 체크포인트와 다음 변화까지 남은 시간을 표시한다. 기본 단계는 체크포인트에 포함하지 않는다. 최종 단계는 `오늘의 성장 완료`로 대체한다. 기존 닉네임·상태메시지·꾸미기 기능은 구현 때 함께 유지해야 한다. 시안은 성장 영역을 중심으로 재구성했다.

**내 좌석 / 좌석 상세:** 기존 시간·과목·일시정지 조작을 유지한다. 캐릭터 주변 효과와 작은 `7h` 배지만 추가한다. 자세한 성장 설명은 캐릭터 화면에서 본다.

**다른 사람의 좌석:** 실제 오늘 순공시간으로 단계를 계산한다. 전체 방에 큰 이펙트를 표시하지 않고 각 좌석 안에만 제한한다. 상태메시지·좌석 번호·공부시간 위로 효과가 겹치지 않는다.

현재 미리보기 HTML의 단계 선택·휴식 전환은 검토용 조작이다. 시안 속 꾸미기·메뉴·뒤로가기는 화면 구성을 보여주는 정적 요소이며 실제 앱 기능에 연결되지 않는다.

## 시간과 상태 정책

| 상황 | 동작 |
|---|---|
| 공부 중 | 기존 순공 타이머와 같은 시간값으로 계산, 새 임계치 도달 때만 외형 변경 |
| 일시정지·휴식 | 달성 단계·빛·노트 유지. 필기 동작만 멈추고 `휴식 중` 표시 |
| 재개·과목 변경·자리 이동 | 당일 합산 단계 유지, 달성 알림을 반복하지 않음 |
| 앱 재접속 | 서버가 확인한 당일 시간으로 복원. 지난 단계 연출을 순서대로 재생하지 않음 |
| 백그라운드에서 여러 단계 도달 | 최신 단계로 한 번 전환. 알림 여러 개를 쌓지 않음 |
| 다음 날 | KST 00:00에 새 날짜의 순공시간으로 계산. 전날 기록은 보존. 자정을 넘긴 세션은 기존 날짜별 집계 방식과 일치하게 분리 |
| 기록 정정·동기화 오차 | 확인된 시간으로 일치시킨다. 정정에 따른 변화에 축하 연출을 재생하지 않음 |
| 시간 조회 실패 | 기존 확인된 모습 유지. 처음 진입해 시간이 없으면 `시간 확인 중` 표시 후 확정 |

KST 00:00은 기획 기본값이다. 실제 적용 전에 기존 순공시간의 일자 경계와 일치하는지 확인하고, 별도 날짜 계산을 중복 구현하지 않는다. 누적 평생 시간이나 주간·월간 랭킹 시간, 상점의 포인트 적립 시간으로 단계를 계산하지 않는다.

## 전환 연출 명세

전체 800ms: 0~200ms 기존 자세에서 미세한 자세 보정 → 150~550ms 새 노트·필기·빛을 opacity로 노출 → 400~800ms 단계 배지 갱신과 반짝임 한 번. 얼굴·몸을 교체하거나 장면 크기를 변경하지 않는다. 타이머와 입력 포커스는 그대로 유지한다. 9→10시간은 아치가 그려지고 별이 한 번 나타나는 것으로 마친다.

달성 안내는 내 화면에서만 짧은 비차단 메시지로 한 번 표시하고 소리·진동·확인 모달은 기본으로 사용하지 않는다. 동작 줄이기 설정에서는 즉시 변경 또는 150ms 페이드만 사용한다. 시각 효과와 별도로 `오늘 순공 7시간, 깊이 몰입한 나`라는 텍스트를 제공한다. 매초 스크린리더 알림은 하지 않는다.

독립 UI 시안은 단계별 정지 상태와 휴식 상태를 확인하기 위한 것이다. 실제 800ms 연속 전환과 필기 애니메이션은 이번 기획 시안에서 구현하지 않았다.

## 구현 연결점과 검증 기준

- 캐릭터: `app.js`의 `renderStudyCafeAvatar`, `renderStudyCafeSeatedVisual`. 기존 구성요소를 유지하고 효과용 하위 요소와 단계 속성만 추가하는 방향.
- 내 시간: 기존 `getStudyCafeMemberSeconds(null, true)`가 사용하는 순공시간과 동일한 원천. 다른 사람은 동기화된 `todaySeconds` 및 기존 세션 상태를 사용한다.
- 순수 계산 함수 예시: `getStudyCharacterStage(seconds)`는 `[10800,18000,25200,32400,36000]` 중 `seconds >= threshold`인 항목 수를 반환한다. 결과는 0~5. 날짜가 분리된 확정 순공시간을 입력한다.
- 타이머 매초 전체 캐릭터 DOM을 다시 만들지 않는다. 단계가 바뀔 때만 단계 속성을 갱신한다. 별도 실시간 구독·폴링·시간 저장을 추가하지 않는다.
- 새 효과 스타일은 인터넷 수강생의 해당 장면에만 범위를 제한한다. 공용 CSS 캐릭터를 쓰는 다른 수강생·교사 화면에 번지지 않도록 한다.
- 필수 검증: 각 임계치 1초 전·정각·1초 후, 휴식·재개, 과목·방 이동, 재접속, KST 자정, 서버 정정, 10시간 초과, 의상·모자·최대 책상 소품 동시 착용, 작은 좌석·좁은 화면, 동작 줄이기, 접근성 텍스트.
- 실제 기능 구현 시 기존 스터디카페·상점·타이머 관련 검증과 빌드를 수행한다. 푸시·배포는 프로젝트 지침에 따라 사용자의 최종 확인 후 진행한다.
