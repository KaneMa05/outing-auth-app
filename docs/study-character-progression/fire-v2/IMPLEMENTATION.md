# 불꽃형 캐릭터 구현 결과

로컬 좌석현황의 랭킹방 예시를 10·9·7·5·3시간·기본 순으로 배치했다. 기존 헤어 예시를 유지하며 localhost 테스트 데이터에만 적용한다. `scripts/study-fire-guide-qa.cjs`에서 실제 좌석의 단계가 5·4·3·2·1·0 순인지 검증했다. [로컬 좌석 화면](images/local-hourly-seats.png)

상태: 로컬 코드 구현·검증 완료. 사용자 지시에 따라 푸시·배포하지 않음.

추가: 로컬 스터디카페의 **좌석 현황 오른쪽 `🔥 불꽃 안내`**에서 시간별 캐릭터 6개와 누적 시간·휴식 유지·오전 4시 초기화·10시간 이후 유지 규칙을 확인할 수 있다. 실제 로컬 앱(`http://localhost:3000/?studentMode=online#study-cafe`)에서 안내 버튼 표시, 6단계 도형, 모바일 범위, 열기·닫기를 검증했다. `scripts/study-fire-guide-qa.cjs`로 다시 확인할 수 있으며 전체 `npm.cmd test`도 통과했다. 가이드의 예시 캐릭터는 고정된 시간으로 표시하고 실제 기록이나 DB를 변경하지 않는다.

## 반영 내용

- 인터넷 수강생(`lecture`)의 공용 좌석·랭킹룸·개인 스터디룸·내 좌석·좌석 상세·나의 캐릭터에 연결했다.
- 기존 순공시간으로 3·5·7·9·10시간 단계를 계산한다. 정확히 임계치에서 바뀌고 10시간 이후 최종 단계를 유지한다. 순위는 단계 계산에 사용하지 않는다.
- `study-character.js`의 `fire`는 단계 계산, 표시 문구, 불꽃 도형을 제공한다. `app.js`는 기존 시간 원천과 갱신 루프를 사용한다. 별도 타이머·폴링·실시간 구독을 만들지 않았다.
- 불꽃의 크기·색은 800ms로 전환하며 단계가 같으면 DOM과 단계 속성을 다시 만들지 않는다. 캐릭터·장비 DOM은 유지한다.
- 좌석 그리드는 정지 불꽃, 내 좌석·상세는 공부 중에만 천천히 일렁인다. 휴식 상태는 단계와 불꽃을 유지한다. 동작 줄이기 환경에서는 전환과 반복 동작을 중지한다.
- 기존 헤어·모자·의상·의자·책상 소품을 보존한다. 독립된 `study-character-fire.css`를 사용하고 다른 수강생 유형과 관리자 미리보기에는 불꽃 노드를 만들지 않는다.
- 나의 캐릭터에 현재 불꽃 단계와 다음 변화까지 남은 시간을 추가했다. 단계 문구만 접근성 알림으로 갱신한다.
- 학습일은 기존 API와 동일하게 KST 오전 4시 기준이다. 이전 학습일 스냅샷을 새 학습일의 불꽃 단계에 재사용하지 않으며 기존 동기화가 새 기록을 받으면 그 시간으로 갱신한다.
- `index.html`과 서비스워커에 새 CSS 및 코드 버전을 연결했다. 배포는 실행하지 않았다.

## DB

불꽃용 스키마·마이그레이션은 필요 없다. 기존 `api/study-cafe.js`와 `api/study-cafe-rooms.js`가 반환하는 `todaySeconds`, 본인의 기존 순공시간 상태를 재사용한다. 단계 값을 별도 저장하지 않으므로 시간이 정정되거나 재접속해도 확인된 시간으로 계산한다. 이번 작업에서 운영 DB를 변경하거나 예시 공부시간을 삽입하지 않았다.

## 검증

- `npm.cmd test`: 전체 통과. 기존 테스트의 렌더러 추출 목록에 새 의존 함수를 포함하고, 서비스워커 버전 검증을 갱신했다.
- `tests/study-character-fire.test.js`: 각 임계치 1초 전·정각·1초 후, 최대 단계, 잘못된 값, 시간 역행, 휴식, 기록 정정, DOM 유지, 수강생 유형 제한, KST 오전 4시 전환 확인.
- `scripts/study-character-fire-qa.cjs`: 실제 앱 렌더 함수와 실제 CSS를 사용해 320/390/768px에서 단계 표시·시간 경계·좌석 범위·라이브 갱신·휴식·타 화면 제외·6종 머리 및 모자/의상/4개 소품 병행·동작 줄이기를 검증했다. API는 호출하지 않는 로컬 렌더 검증이다.
- [실제 렌더러 검증 이미지](images/implemented-render-390.png): 도형 시안이 아닌 현재 앱의 렌더 함수를 사용한 결과. 운영 화면 캡처는 아니다.
- `node --check`: app.js, study-character.js, sw.js 통과.
- `git diff --check`: 검사 대상 변경 파일에 공백 오류 없음.
- `npm.cmd run build`: `tmp/study-fire-build`에 현재 빌드 입력을 복사해 실행, 통과. 이 저장소의 빌드는 `config.js` 생성 단계이며 임시 폴더에서는 환경변수 없는 기본 설정을 생성했다. 사용 중인 루트 config.js와 환경 파일은 변경하지 않았다. 운영 환경변수로 실행한 배포 빌드나 운영 로그인 검증은 포함하지 않는다.

운영 반영은 사용자가 별도로 푸시·배포를 승인한 뒤 진행한다. 이 불꽃 기능 때문에 선행 DB 배포가 필요한 것은 아니다.
