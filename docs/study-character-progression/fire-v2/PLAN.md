**공부가 쌓일수록, 불꽃도 자라요.** 현재 캐릭터 뒤에 공부 에너지를 나타내는 불꽃을 배치한다. 같은 불꽃의 높이·폭·안쪽 밝기가 점진적으로 커져 시간 증가를 직관적으로 보여준다. 얼굴, 머리, 체형, 옷, 책상과 소품은 고정한다.

## 단계와 UI 이미지

기준: KST 당일 누적 순공시간. 연속 공부시간이 아닌 과목·세션 합산이며 휴식시간은 제외한다. 정확히 기준 시간에 도달하면 다음 단계로 바뀐다.

| 기준 | 이름 | 변화 | 모바일 UI |
|---|---|---|---|
| 0 이상 ~ 3시간 미만 | 공부 시작 | 기존 모습, 불꽃 없음 | [기본](images/00h-mobile.png) |
| 3 이상 ~ 5시간 미만 | 집중의 불씨 | 몸 양옆에 작은 노란 불꽃이 나타남 | [3시간](images/03h-mobile.png) |
| 5 이상 ~ 7시간 미만 | 타오르는 집중 | 주황색으로 깊어지고 어깨 위로 자람 | [5시간](images/05h-mobile.png) |
| 7 이상 ~ 9시간 미만 | 몰입의 불꽃 | 짙은 주황색, 머리 위까지 또렷한 불꽃 | [7시간](images/07h-mobile.png) |
| 9 이상 ~ 10시간 미만 | 뜨거운 몰입 | 붉은 외곽, 넓어진 불꽃, 작은 불티 2개 | [9시간](images/09h-mobile.png) |
| 10시간 이상 | 황금 불꽃 | 붉은 테두리를 유지하며 황금 중심이 넓고 밝아짐 | [10시간](images/10h-mobile.png) |

[전체 단계 비교](images/00-all-stages.png) · [단계 선택·휴식 미리보기](index.html)

10시간 이후 불꽃은 더 커지지 않는다. `오늘의 불꽃을 완성했어요. 잠깐 쉬어가요`로 성취를 표시한다. 보유 의상이나 유료 아이템에 따라 시간 단계가 달라지지 않는다.

## 자연스러운 표현

- 하나의 둥근 불꽃 실루엣을 계속 키운다. 노랑 → 주황 → 짙은 주황 → 빨강 → 황금 중심으로 이어진다. 9→10시간에서도 붉은 외곽을 남겨 연결감을 준다.
- 불꽃은 캐릭터와 의자 뒤, 책상 뒤에 놓는다. 얼굴과 옷을 덮지 않는다. 장면 안에서만 보이게 하고 시간·상태메시지·버튼에는 침범하지 않는다.
- 외형 변화는 불꽃에 집중한다. 이전 안의 노트 증가·별·금빛 아치는 사용하지 않는다. 기존 구매 소품과 장비가 계속 잘 보여야 한다.
- 색을 구별하기 어려운 상황에서도 높이·폭과 `7시간 달성` 문구로 단계를 식별한다.
- 상세 화면은 2.8초 주기로 ±0.6도, 크기 1~2.5% 범위에서 천천히 일렁인다. 상위 단계에서도 속도를 높이지 않는다. 휴식 중에는 단계·불꽃 크기·색을 유지하며 움직임만 정지한다.
- 동작 줄이기 설정에서는 정지 불꽃을 사용한다. 작은 좌석이 많은 화면에서는 불티와 반복 동작을 생략한다. 내 좌석 또는 열린 상세 장면만 애니메이션을 사용한다.

## 화면 배치

나의 캐릭터 화면에 오늘 순공시간, 캐릭터와 불꽃, 단계 배지, 다음 단계까지 남은 시간, 3·5·7·9·10시간 체크포인트를 표시한다. 기본 0시간은 단계 목록에만 표시한다. 최종 단계는 `오늘의 성장 완료`로 바뀐다.

내 좌석·좌석 상세에도 같은 불꽃 단계를 사용한다. 축소된 좌석에서는 좌석 크기에 맞춰 전체 장면을 축소하고 주변 좌석으로 번지지 않게 제한한다. 다른 학생은 확인된 오늘 순공시간을 기준으로 표시한다. 기존 닉네임·상태메시지·꾸미기 기능은 구현 시 유지한다. 독립 시안의 메뉴·꾸미기는 정적 레이아웃이며 실제 앱 기능에 연결되지 않는다.

1차 범위는 캐릭터 기능이 있는 인터넷 수강생(`lecture`)의 스터디카페로 제안한다. 온라인 관리반·오프라인 수강생·교사·관리자 화면으로 확대하는 것은 별도 검토한다. 이는 수강생 유형이 특정되지 않은 요청에 대한 기획 가정이다.

## 시간과 전환 정책

- 단계 계산은 기존 순공 타이머와 같은 시간 원천을 사용한다. 휴식·과목 변경·자리 이동·재접속으로 초기화하지 않는다.
- 다음 학습일에는 새 학습일의 누적 순공시간으로 시작한다. 전날 기록은 보존한다. 현재 `app.js`의 `formatStudyBusinessDateKey`와 랭킹 안내를 확인하여 **KST 오전 4시**를 경계로 사용한다. 앞서 제안한 자정 초기화는 이 기준으로 정정한다.
- 재접속 시 확인된 최신 단계로 복원한다. 여러 임계치를 지나도 중간 단계 알림을 줄줄이 재생하지 않는다. 기록 정정 시 확정된 시간에 맞추고 축하 알림을 반복하지 않는다.
- 전환 제안은 800ms: 첫 150ms 약한 불빛 → 150~650ms 높이·폭과 색을 보간 → 마지막 150ms 안정화. 이미 켜진 불꽃을 껐다가 다시 켜지 않는다. 얼굴·몸·책상은 움직이지 않는다.
- 실제 구현에서는 기존 불꽃 DOM을 유지하고 단계 속성과 변수만 바꾼다. 순공 타이머나 입력 포커스를 다시 만들지 않는다. 추가 폴링·실시간 구독은 필요하지 않다.

현재 미리보기는 단계별 정지 화면, 불꽃의 반복 일렁임, 휴식 정지를 구현했다. 단계 버튼을 누를 때는 선택 상태로 즉시 바뀐다. 800ms 연속 단계 전환은 구현 명세이며 아직 시안에 적용하지 않았다.

## 검증과 적용

검토 이미지 7장: 전체 비교 1장, 기본 및 시간별 모바일 UI 6장. 브라우저에서 이미지 렌더링, 가로 잘림, 단계 선택, 휴식 전환 후 최종 단계 유지 여부를 확인했다. 전체 비교와 최종 모바일 UI를 시각 검토했다.

기능 구현 시에는 임계치 전후, 휴식·재개, 재접속, 오전 4시 학습일 전환, 기록 정정, 10시간 초과, 장비 동시 착용, 축소 좌석, 동작 줄이기 및 타이머 회귀를 검증한다. 공용 캐릭터를 사용하는 다른 화면에 효과가 번지지 않도록 적용 범위를 제한한다.

현재 CSS 캐릭터 위에 SVG 불꽃을 더한 브라우저 렌더링 시안이다. 생성형 이미지 모델은 사용하지 않았다. 기존 운영 파일은 변경하지 않았으며 푸시·배포도 진행하지 않았다.

## 실제 좌석 화면에 적용하는 방식

[랭킹룸 적용 비교 이미지](images/seat-context.png) · [좌석 시안 HTML](seat-preview.html)

**최신 시안:** [모든 단계가 함께 있는 좌석현황](images/seat-room-all-levels.png) · [설명을 포함한 전체 비교](images/seat-context-all-levels.png). 사용자 요청에 따라 7·9·10시간 캐릭터를 실제 좌석 그리드에도 배치했다. 비교를 위한 가상 데이터이며 첫 줄은 1위 `10:12:43` 황금 불꽃, 2위 `09:28:45` 붉은 불꽃, 3위 `07:54:44` 짙은 주황 불꽃, 4위 `06:02:43` 주황 불꽃이다. 5~10위에는 3시간 단계, 11위 이후에는 기본 단계를 배치했다. 상단 내 좌석은 기존 예시 `00:02:34`를 유지한다. 아래의 원본 시간 설명은 이전 시안 기록이다.

첨부 화면의 배치를 기준으로 재구성했다. 닉네임은 예시로 대체했으며 로고와 일부 세부 요소는 단순화했다. 운영 화면의 직접 캡처 또는 실제 반영 결과는 아니다.

- 내 좌석 `00:02:34`: 불꽃 없는 기본 단계. 상단 내 좌석과 그리드의 본인 좌석은 같은 누적 시간으로 계산한다.
- 1위 `06:02:43`: 5시간 단계인 주황 불꽃.
- 2~10위의 3~4시간대: 3시간 단계인 노란 불씨. 10위도 `03:10:58`이므로 불씨가 있다.
- 11위 이후 3시간 미만: 기본 모습. 쉬는 중인 좌석은 일시정지 표시를 유지한다.

76×110px 좌석을 기준으로 불꽃은 54×32px → 58×37px → 62×41px → 66×44px → 68×46px로 커진다. 불꽃 밑면은 좌석 하단에서 24px 위에 두고 몸 양옆으로 보이게 한다. 이름·시간이 있는 상단 구역은 침범하지 않는다. 불티는 생략하고 반복 동작은 사용하지 않는다. 좌석마다 정적 불꽃을 보여주며 내 좌석·상세에서만 일렁임을 사용한다.

좌석 20개와 확대 예시 6개의 불꽃 경계를 검사하여 좌석 밖이나 공부시간 글자 위로 침범하지 않는 것을 확인했다. 좌석 배치·시간·순위·버튼은 기존 기능을 유지하는 기획이다.
