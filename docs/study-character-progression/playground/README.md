# 시간별 캐릭터 테스트

[로컬 테스트 화면 열기](http://localhost:3000/docs/study-character-progression/playground/index.html)

로컬 개발 서버가 실행 중일 때 위 주소를 연다. 서버 없이 `index.html`을 브라우저로 직접 열어도 동작한다.

- 기본·3·5·7·9·10시간 테스트 캐릭터 6명을 함께 비교한다. 각 좌석 또는 시간 버튼을 누르면 큰 캐릭터와 실제 크기의 좌석이 바뀐다.
- 슬라이더와 `시:분:초` 입력으로 0~12시간을 직접 지정한다.
- 기준 시간 선택 후 `1초 전 / 정각 / 1초 후`로 임계치를 검증한다.
- `2초 전부터 변화 보기`는 선택한 기준 시간 2초 전부터 실제 속도로 진행하고, 기준 시간 2초 후 자동으로 정지한다. 같은 캐릭터 DOM에서 실제 800ms 불꽃 전환이 보인다.
- `시간 자동 진행`과 배속으로 빠르게 확인한다. `휴식으로 전환`하면 시간을 멈추고 달성 단계는 유지한다. 탭이 보이지 않을 때는 테스트 시간이 진행되지 않는다.
- 머리 6종·옷 색상·모자/제복/책상 소품 조합을 비교한다.

실제 API 호출이나 DB 저장 없이 메모리의 테스트 시간만 사용한다. 운영 학생·봇을 생성하거나 기존 순공 기록을 수정하지 않는다. `docs/`는 기존 `.vercelignore`에 따라 배포에서 제외된다.

## 현재 앱 코드로 갱신

프로젝트 루트에서 `node scripts/build-study-fire-playground.cjs`를 실행한다. 현재 `app.js`와 `shared.js`의 캐릭터 렌더 함수가 `renderer.js`에 추출된다. `study-character.js`, `styles.css`, `study-character-fire.css`는 프로젝트 파일을 직접 읽는다. 앱 부트스트랩·인증·서버 요청 코드는 실행하지 않는다.

## 검증

`node scripts/study-fire-playground-qa.cjs`: 시간 버튼, 5개 임계치 전후, 직접 입력·잘못된 입력 차단, 휴식, 장비·머리 조합, 좌석 클릭, DOM 유지, 자동 경계 통과, 배속 진행·휴식 정지, 390/1100px 배치를 확인한다. 생성된 화면은 `preview-390.png`, `preview-1100.png`로 저장한다.

푸시·배포·DB 변경은 진행하지 않았다.
