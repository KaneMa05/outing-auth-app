Apple 로그인 버튼 표시 개선 · 2026-11-09

문제
- 기존 378×57 PNG에 로고와 문구가 함께 들어 있어 문구가 크고 고해상도 화면에서 흐리게 보임.

변경
- 문구를 실제 HTML 텍스트로 분리, 한글 시스템 글꼴과 15.5px 크기 사용.
- Apple Design Resources의 공식 검정 로고 SVG 사용. 원본 로고와 여백은 변경하지 않음.
- 두 소셜 버튼의 표시 높이 36px, 실제 터치 영역 최소 44px. Apple 문구 크기는 표시 높이의 약 43%.
- 버튼 흰색·검정 조합과 기존 로그인 이벤트, 접근 가능한 이름 유지.
- 변경 범위는 면접반 로그인 화면. 기존 교사·학생 화면의 기능 및 인증 로직 변경 없음.
- 로그인 CSS·모듈 URL 및 서비스 워커 캐시 버전 갱신.
