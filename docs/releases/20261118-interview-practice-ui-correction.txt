직무·인성 운영 UI 수정

사용자 요청
- 간이 테스트 UI 대신 기존 앱의 준비·면접·기록 UI를 사용.
- 실제 UI는 분야·지역·문항 수 설정과 음성 표시가 있는 화면으로 명시 확인.
- 베타 표시는 타이틀 왼쪽 상단으로 이동.
- 앞서 승인된 운영 반영의 잘못된 UI 연결을 바로잡는 수정.

원인 및 변경
- 이전 배포가 production job/personality를 간이 interview-practice-pilot 렌더러에 연결했다.
- 원본 iOS InterviewPracticeView 및 Android InterviewPortalPracticeActivity의 화면 구성을 운영 웹 앱에 적용했다.
- 새 운영 진입 client/interview-practice.mjs: 고정 상단 내비게이션, 모드/직렬 제목, 직무 분야·지역 두 열/인성 분야 한 열, 3·5·10·15·20문항 선택, 연습 시작, 질문/즐겨찾기와 내 기록.
- 진행: 3초 준비, 질문 번호/다시 듣기/시간, 원본과 같은 마이크·스피커 벡터 및 음성 막대, 상태/질문, 답변 완료/종료.
- 직무 답변 돌아보기 후 다음 질문/최종 결과. 인성은 다음 질문으로 진행. 결과/기록에서 원음 재생 및 계정별 기록 유지.
- 메뉴·각 연습 화면 모두 제목 위 왼쪽의 베타 배지 한 개만 표시. 메뉴 카드의 반복 배지를 제거.
- 새 UI CSS는 ip-mock-practice 범위로 제한해 관리자 전사 화면 클래스와 충돌하지 않게 했다.
- 기존 녹음/비공개 업로드/계정 저장을 client/interview-practice-core.mjs로 분리해 공유한다. 기존 pilot 진입은 테스트 경로에서만 유지.
- IndexedDB 이름, 계정·모드별 키, 즐겨찾기, 저장 녹음 형식, 업로드 프로토콜 유지.
- 질문 다시 듣기는 녹음을 잠시 멈추고 재개한다. 다시 듣기 중 종료해도 이전 녹음 보존.
- 카운트다운/마이크 권한 대기 중 취소와 백그라운드 전환을 처리. 초기 조회 실패는 실제 UI 내에서 재시도 가능.
- 수강 권한·API·DB·관리자 전사 처리 변경 없음. 유료 분석 기능 공개 범위 확대 없음.
- 두 앱 진입점의 모듈/CSS 캐시 키 갱신. 기존 네이티브 바이너리/스토어 제출 변경 없음.

검증
- 관련 권한/라우팅/탐색/배포 회귀 63개, 기존 앱 본 테스트, 격리 빌드 통과.
- 기존 테스트 네이티브 경로 및 간이 연습 회귀 브라우저 통과.
- 실제 운영 앱 셸의 직무/인성 각각 3문항 합성 마이크 녹음·압축·재생·비공개 업로드 프로토콜 검사 통과.
- 준비/진행/직무 돌아보기/결과/기록/기록 뒤로/즐겨찾기/계정 분리 확인.
- 320/390/844px 레이아웃 및 베타 배지의 제목 위/왼쪽 정렬 검사 통과.
- 조회 재시도, 늦은 마이크 권한 응답 취소, 백그라운드 카운트다운 취소, 일시정지된 녹음 종료 보존 검사 통과.
- 실제 학생 계정으로 녹음하거나 운영 DB에 검증 자료를 추가하지 않았다. 실제 휴대전화 마이크 재검사는 아님.
- 증빙: .tmp/practice-app-ui-review. 정식 앱의 웹 화면을 수정하며 앱스토어 바이너리 업데이트로 가장하지 않는다.
