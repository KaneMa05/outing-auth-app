# 취약단원 오답 이력 유지

상태: 2026-09-23 사용자 푸시·배포 승인. 검증 완료 후 main 푸시에 연결된 Vercel 운영 배포로 반영한다.

## 변경

- 취약단원 기본 보기를 취약 이력으로 변경. 오답 경험률은 `틀린 적 있는 서로 다른 문항 수 / 풀어본 서로 다른 문항 수`이며 재정답·복습 완료로 줄지 않는다.
- 오답 경험률 → 오답 이력 문항 수 → 목차 순으로 정렬. 학습 기록이 적은 단원, 이력 없는 단원, 미학습 단원을 구분한다.
- 현재 정답률과 기존 현재 취약도는 ‘현재 상태’에서 확인한다.
- 단원별 이전 오답 조회·재풀이에 복습 완료 문항을 포함한다. 전체/아직 틀림/다시 맞힘과 반복 오답 필터를 제공한다.
- 일반 오답노트의 기존 미완료 목록은 유지하고 전체 이력 보기·완료 취소를 추가한다. ‘오답 삭제’는 실제 동작에 맞게 ‘복습 완료’로 변경한다.
- 서버가 제공하는 기존 누적 오답 횟수를 사용한다. DB 마이그레이션·API 변경·운영 기록 변경 없음.
- 생성 경로: `build-local-preview.py` → `local-app-preview.js` → `scripts/build-ox-learning.py` → 배포용 JS/CSS. 취약 이력 템플릿은 `weakness-history-view.js`.
- 앱/지연 로딩 자산 URL과 서비스워커 캐시 버전을 함께 갱신한다. 교사 HTML 변경은 공유 앱 스크립트의 버전 참조만 해당한다.

## 검증

- `npm.cmd run test:criminal-law-ox`: 신규 이력 회귀 7건과 기존 OX SQL·권한·등록·기기·교재·일괄 지급 테스트 통과.
- `node tests/criminal-law-ox-loading.test.cjs`: 24건 통과.
- `node docs/criminal-law-ox-proposal/chapter-flow.test.cjs`: 단원 완주·세트·재풀이 기록 보존 검증 통과.
- `node tests/release-safety.test.js`: 자산 버전/캐시 및 설정 보존 2건 통과.
- `node scripts/ox-history-ui-qa.cjs`: 실제 생성 모듈·스타일에 가상 데이터만 연결. 세 수강생 테마 × 320/390/768px, 이력 조회·필터·복습 완료/취소·지연 로딩 실패 재시도·재풀이·목록 복귀·재마운트·재오답 검증.
- 생성 스크립트 실행, JS 구문 검사, `git diff --check` 확인.
- `.tmp/ox-history-build`에 실제 빌드 스크립트와 입력 파일을 복사해 `npm.cmd run build` 통과. 환경 설정이 없는 로컬 빌드이며 빈 설정 파일은 이 검증 폴더에만 생성했다. 기존 루트 설정은 변경하지 않았다.

## 범위와 적용 상태

세 수강생 유형의 OX 화면에 공통 적용. 홈의 기존 복습 대상 집계, 채점, 북마크, 메모, 교재 접근 권한 유지. 실제 운영 계정으로 접속하거나 운영 DB에 쓰지 않았다. 사용자 최종 승인에 따라 이번 변경만 커밋·푸시하며, 작업 전부터 별도로 수정된 final-scope-data.js는 포함하지 않는다.
