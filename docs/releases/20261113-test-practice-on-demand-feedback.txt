테스트앱 직무·인성 연습 피드백 요청형 전환 — 배포 완료

사용자 요청
연습 종료 시 기본 AI 피드백을 없애고 결과에서 피드백 받기를 누를 때 제공.
직무 판정도 같은 분석 호출에 포함돼 버튼 요청 후 함께 표시.
실전 모의면접·일반앱 및 나머지 연습 기능은 유지. 먼저 테스트앱에 적용.

구현
DEBUG 네이티브 포털의 직무·인성 연습만 요청형.
녹음 저장 시 분석 대기·요청 ID를 생성하지 않고 not_requested 상태로 보관.
결과 열기·앱 복귀·기록 재조회는 새 분석 제출을 하지 않음.
질문별 피드백 받기에서 요청 ID를 먼저 로컬에 저장한 뒤 기존 분석 경로 실행.
연속 탭은 같은 요청으로 제한. 완료된 피드백은 피드백 보기로 접어 저장 결과 재사용.
전송/처리 결과가 불확실하면 새 ID 자동 발급·새 분석 자동 재시도하지 않음.
모델·전사·판정 기준·분석 파이프라인은 유지하며 실행 시점만 변경.
직무 중간 돌아보기에서 미요청을 AI 미연결/실패로 표시하지 않음.
기존 녹음 재생바·구간 이동·영상·질문 수·다시 연습·기록은 유지.
분석 서비스 준비 여부가 미요청 연습 시작을 막지 않게 분리. 문항/수강 권한 확인은 유지.

예시답변 보존
현재 테스트 문항은 번들 예시답변이 없어 기존 유료 분석 결과 조회에 예시가 연결돼 있었다.
AI 없이 예시답변만 읽는 practice_reference 경로를 추가.
실제 로그인·테스트앱 마커·모의 연습 권한·공개 문항 범위·직렬·원문 일치 확인.
클라이언트가 보낸 계정 ID는 인증 근거로 쓰지 않고 서버 응답의 실제 계정과 로컬 기록 소유자를 대조.
직무·인성만 허용. 일반앱·실전·다른 문항·변경된 원문은 거부.
DB GET만 실행하며 AI 호출·신규 분석 기록 생성 없음. DB 스키마/권한 변경 없음.
예시답변을 로컬 결과에 보관하고 재조회에서 재사용. 실패가 분석을 시작시키지 않음.

검증
iOS 모의 API 단위 검사: 직무/인성 기본 분석 제출 0회, 예시답변 조회 유지.
버튼 연속 탭 시 제출 1회와 요청 ID 1개, 저장 피드백 재조회 시 추가 제출 없음.
이전 모드의 기록이 남아 있어도 현재 준비 모드로 요청형 정책 결정.
실전 ai 모드의 기존 분석 정책 유지.
기존 녹음 보존 및 예시답변/분석 상태/재조회 검사 포함.
서버 예시답변/카탈로그/기존 실전 문맥 검사 16개 통과.
Debug 및 Release 빌드 검사. 모의 API만 사용, 새 실제 녹음·실제 분석 API 호출 0회.
학생 화면에 비용 안내를 추가하지 않음.
