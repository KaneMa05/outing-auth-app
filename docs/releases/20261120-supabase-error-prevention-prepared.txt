변경
- PC 처리기는 claim의 bundle_mismatch를 받으면 bundle_update_required 상태로
  새 작업 요청을 중단한다. 서버가 올바른 버전으로 돌아와도 같은 프로세스에서는
  자동 재개하지 않는다. 승인된 지침과 서버 해시 확인 후 처리기를 재시작한다.
- 서버가 반환한 작업 자체의 지침 해시가 다를 때에도 AI를 실행하지 않고
  bundle_mismatch로 보고한 뒤 새 작업 요청을 중단한다.
- 기존 결과 업로드·복구, 일반 네트워크 오류 재시도, 안전 종료는 유지한다.
- PC 상태 창은 지침 업데이트·버전 확인·재시작 필요 안내를 표시한다.
- 관리자 화면은 서버에서 읽은 정답의 원본을 보관하여 실제 정답 변경만 검사한다.
  제출자가 있고 정답이 바뀐 경우 정정 사유가 5자 미만이면 API 요청 전에 차단한다.
  제목 등 설정만 변경하거나 정답을 원래대로 되돌린 경우에는 사유를 강제하지 않는다.
- 정정 사유는 과목 목록·입력 화면 어디에서든 입력할 수 있고 과목 이동 시 유지한다.
- 관리자 모듈의 버전 URL과 서비스 워커 캐시 버전을 갱신했다.
  API 캐시·열린 화면 강제 이동 동작은 추가하지 않았다.
