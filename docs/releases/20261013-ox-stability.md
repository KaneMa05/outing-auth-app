# OX 화면 종료 신고 대응

상태: 로컬 수정·검증 완료. 2026-10-13 사용자가 거친 질감 유지 방식의 최종 변경에 대해 커밋·푸시·배포를 승인했다. main 푸시로 연결된 운영 배포를 진행하며 완료 여부는 Vercel Ready 상태와 운영 자산 응답으로 확인한다. 실제 iPad에서의 종료 재현 및 해결 확인은 미완료다.

## 신고와 조사 한계

아이패드 설치형 앱에서 O·X 답 선택 또는 다음 문제 이동 중 앱이 종료되어 다시 실행해야 한다는 신고다. 자동 잠금만으로 설명할 수 없다. 사용자 확인 전 수집한 Mac 표기는 iPad Safari의 데스크톱 User-Agent와 구별되지 않는다.

2026-10-13 13:45~14:40 KST의 Supabase 전체 OX gateway HTTP 응답은 534건 모두 200이었다. 해당 학생의 14:39 답안 저장과 기기 등록 유지도 확인했다. 이 자료는 특정 실패 답안의 저장 여부나 기기의 종료 원인을 증명하지 않는다. 운영 데이터 변경은 없다.

채점 표시에 매번 생성되는 SVG 노이즈·색상행렬·합성 필터가 있었다. [WebKit의 과거 SVG 메모리 사용 보고](https://bugs.webkit.org/show_bug.cgi?id=218422)는 Safari 13/macOS 사례이며, 현재 iPad의 동일 결함을 입증하지 않는다. 아래 그래픽 변경은 예방적 단순화이며 원인 확정 또는 강제 종료 해결로 표현하지 않는다.

## 변경

- 기존 빨간 원/빗금의 거친 질감·색·위치를 유지하면서, 실행 중 SVG 필터 계산을 미리 렌더링한 투명 PNG 두 장으로 대체했다. `scripts/build-ox-grade-marks.cjs`가 원래 SVG를 로컬 Chrome에서 한 번 렌더링한다. 108×108px 이미지 두 장은 합계 11,429바이트이며 서비스 워커에 미리 저장한다. 템플릿과 생성된 학습 모듈을 함께 반영했다.
- OX 이탈·로그아웃 시 기존 컨트롤러를 파기해 문서 이벤트와 MutationObserver가 재진입마다 누적되지 않게 한다.
- 로그인한 수강생이 OX 화면을 보고 있는 동안 Screen Wake Lock을 요청한다. 전역 설정은 변경하지 않으며 이탈·숨김·로그아웃 시 해제한다. 기기가 요청을 거부하는 경우에도 학습은 계속된다. 이 항목은 자동 잠금 방지이며 앱 강제 종료 해결책이 아니다.
- 공통 앱, OX 모듈과 서비스 워커의 캐시 버전을 맞췄다. 열린 앱을 강제 새로고침하지 않는다.

채점·답안 저장·오답노트·이용 권한 및 DB 스키마는 변경하지 않는다. 다른 수강생 탭과 교사·관리자 UI는 변경하지 않는다.

## 검증

- `npm.cmd run test:criminal-law-ox` 전체 통과. 화면 이탈/로그아웃/재진입 20회의 이벤트·감시자 해제 검증 포함.
- 최종 `npm.cmd test` 전체 통과. 기존 Windows CRLF 소스 추출 테스트 호환을 위해 `.tmp/normalize-test-newlines.cjs`를 NODE_OPTIONS로 사용했다. 테스트 단언과 제품 소스는 정규화 어댑터로 변경하지 않는다.
- `student-wake-lock`, `criminal-law-ox-loading` 32건, `release-safety` 2건 통과. 앞선 수정에서 수강생 유형과 스터디카페 생명주기·실시간 갱신 테스트도 통과했다.
- 로컬 Chrome에서 가상 기록을 사용해 수정 전후 각각 동일 화면에서 100회 연속 재풀이·채점·결과 이동을 완료했다. 두 버전 모두 JS 예외나 브라우저 종료가 없었다. 이는 iPad 재현 테스트가 아니다.
- 세 수강생 테마·320/390/768px 화면, 이력·필터·재조회·재풀이를 검증했다. 정답/오답 화면의 변경 전후 PNG를 직접 비교했다.
- 브라우저 진단은 기존 `scripts/ox-history-ui-qa.cjs`를 기반으로 `.tmp/ox-repeat-diagnostic.cjs`에서 실행했다. 기존 제목 기대값에 누락된 ` · 오답노트`를 현재 UI에 맞춰 수정했다. 최종 거친 질감 복원 결과는 `.tmp/ox-render-textured`에 있으며, `.tmp/ox-render-before`가 원래 화면이다. 실제 PNG 로딩과 오프라인 캐시 포함도 검증한다.
- 격리 폴더의 테스트 설정으로 production 모드 `npm.cmd run build` 통과. 실제 `config.js`는 변경하지 않았다. 생성 스크립트, JS 구문 검사, `git diff --check` 통과.

## 반영 후 확인

승인된 변경을 배포한 후, 신고한 아이패드의 앱을 다시 실행하여 답 선택·다음 문제 이동 시 종료가 재발하는지 확인해야 한다. 재발하면 발생 시각, iPadOS 버전과 해당 기기의 WebKit/시스템 종료 진단 기록을 확보해 원인을 좁힌다. 학생에게 사이트 데이터 삭제나 앱 삭제를 요구하지 않는다.

기존에 수정되어 있던 `docs/releases/20261012-supabase-503-incident.md`는 이번 작업에서 변경하지 않았다.
