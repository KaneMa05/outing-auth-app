# OX 기수 명단 확인·선택

상태: 2026-09-22 사용자 배포 승인. 운영 DB 변경 2건 적용 완료, 앱 배포 진행.

- OX 이용권 일괄 지급에서 기수를 선택하면 사유 입력 전에 명단을 조회. 바깥 목록에서 선택한 숫자 기수도 이어받음.
- 첫 선택은 0명. 기수 전체 선택·전체 해제·개별 선택/제외, 이름·학생 번호·인강 아이디 검색, 30명씩 페이지 이동 지원. 검색·페이지 이동 중 선택 유지, 기수 변경 시 선택 초기화.
- 지급 진입 시 기존 수강생 검색·목록과 문항 관리 UI를 숨기는 전용 작업 화면. 관리로 돌아가면 원래 화면 복원. PC는 왼쪽 학생/직렬/현재 이용 표와 오른쪽 지급 설정으로 구성하고 모바일은 세로 배치. 선택 도구는 명단 상단, 이력·복귀는 제목 우측, 지급 확인은 설정 하단으로 통일.
- 선택 인원과 최종 명단 확인 후 지급. 조건 다시 선택 시 선택 명단과 입력 내용 유지.
- 명단 조회는 읽기 권한만 필요하며 지급 건을 생성하지 않음. 기존 구매·이용권·OX 전체 중지 상태 표시.
- 서버는 선택 ID의 중복·빈 값·존재 여부·오프라인 재원·기수를 검증. 확인 후 선택 학생의 기수/재원 변경·계정 삭제 시 지급 거절. 신규 재원생은 기존 선택에 추가하지 않음.
- 지급 명단은 형사법 응시 직렬로 한정하며 직렬을 함께 표시. 기존 직렬 별칭과 직렬별 과목 설정을 반영하고, 설정이 없으면 앱에서 형사법 응시가 확인된 기본 직렬만 포함. 직렬 미등록·미확인 및 필기 미응시 직렬 제외. 명단 조회·최종 확인·지급 시 모두 검증하며 기존 구매 권한이나 이미 지급한 이용권을 임의 회수하지 않음.
- 직렬별 과목의 명시적 비활성 설정을 기본값보다 우선 적용. 직렬/과목 설정 변경 후 지급 차단, 별칭 처리, 사용자 정의 직렬의 명시적 과목 설정을 DB 테스트로 확인.
- 기존 일괄 지급 이력은 all 방식 유지. 새 화면의 지급은 selected 방식으로 저장. 실제 구매 권한과 학생 학습·기기 정책 유지.

검증: 전체 npm test(LF 격리 사본), OX DB/API 테스트 13건, 실제 API/SQL 브라우저 흐름, 운영 모드 격리 빌드 통과. 관련 없는 final-scope-data.js 변경은 보존·제외.

추가 UI: 학생별 작업 버튼은 ‘관리’ 하나로 접어 표시. 일반 수강생 관리의 기수 옆에 직렬 필터(전체·정규 명칭·미지정)를 추가하고 학생 행에도 직렬 표시. 직렬은 기수·검색·구매 필터와 교차 적용하며 서버에서 총인원 계산과 30명 페이지 분리 전에 필터링. 기존 직렬 별칭은 같은 정규 명칭으로 묶음. 필터 변경은 권한·지급 대상을 변경하지 않음.

직렬 추가 검증: 별칭·미지정·기수 교차·검색·30명 초과 페이지·잘못된 입력·학생 권한 차단 DB 테스트 및 PC/모바일 실제 API 브라우저 QA, 운영 모드 격리 빌드 통과.

기수→직렬 연동: 일반 목록의 직렬 선택지는 해당 기수 기준으로 제공하고 기수 변경 시 직렬을 초기화. 일괄 지급에도 기수 옆 직렬 필터를 추가하고, 바깥 목록의 선택을 이어받음. 기수·직렬 변경 시 이전 학생 선택 초기화. ‘조건 전체 선택’은 이름 검색과 무관하게 선택 기수·직렬 전체에만 적용. 검색/페이지 이동 중 명시적으로 선택한 학생은 유지하며 명단 새로고침 시 직렬에서 벗어난 학생 선택은 제거. 이 동작과 기존 지급·회수 흐름을 가상 데이터 브라우저 QA로 검증.

운영 적용 완료: `20260922060528_ox_grant_recipient_selection.sql`, `20260922061015_ox_member_track_filter.sql` 순서로 적용. 앱은 main 푸시로 배포. 마이그레이션 자체는 실제 이용권을 지급하지 않음.

운영 적용 검증: 답안 221건, 진도 214건, 메모 7건, 교재 권한 9건, 기기 465건 유지. 이용권 지급 건 0건. 18기 목록 109명 및 형사법 응시 재원생 지급 대상 61명 조회 성공. 익명·학생의 관리자 RPC 직접 실행 차단 유지. 보안 점검에 신규 경고 없음(기존 서버 전용 테이블의 RLS 정책 없음 INFO 56건 유지). 직렬 마이그레이션은 운영과 비교해 수강생 목록 외 함수 본문이 동일함을 확인하고, 사전 검증용 해시 조건을 추가함. 학습 조회 함수 재정의는 제외.
