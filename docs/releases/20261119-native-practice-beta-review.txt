요청에 따른 동작
- 이용 중인 면접 패키지 수강생의 직무(전공)·인성만 베타 공개한다.
- 기존 실제 네이티브 준비·면접·기록 화면을 정식 경로로 승격했다.
  분야·지역·문항 수 선택, 질문 선택·즐겨찾기, 음성 표시, 녹음·재생·기록을 제공한다.
- 베타 표시는 준비 화면 타이틀 위쪽 왼쪽에 표시한다.
- iOS: 기존 WKWebView와 로그인은 유지하고, SwiftUI 연습 화면을 UIKit navigation
  controller로 우측에서 push한다. 닫으면 기존 목록으로 돌아온다.
- Android: 기존 Chrome/TWA 런처와 로그인은 유지한다. 패키지를 지정한 일회용
  실행 코드로 실제 native Activity를 열고, 우측 전환 애니메이션을 적용한다.
  브라우저의 앱 열기 제한을 고려하여 연결 화면의 '연습 화면 열기'를 한 번 더 누른다.
- 새 앱만 native capability를 사용한다. 기존 앱과 일반 브라우저는 기존 웹 연습을
  유지하므로 웹/API 배포가 기존 설치 앱에 미치는 영향을 제한한다.
- 마이크 허용 및 실제 입력 장치 준비 성공 전에는 준비 화면에서 시작하지 않는다.
  입력 확인 전의 무음은 다음 문항으로 진행하지 않는다. 지속 입력 후 4초 무음만
  자동 완료하며, 8초 무입력 안내와 120초 무입력 중단을 적용한다.
- 기존 웹 녹음은 삭제·이동하지 않는다. 네이티브 기록의 '기존 웹 기록 보기'에서
  원래 계정·모드·origin의 저장소를 사용하는 기존 웹 기록 화면을 연다.
  이 경로는 질문 목록을 새로 읽거나 연습 시작 버튼을 노출하지 않는다.
- 이 베타의 연습에 채점·유료 AI 호출은 연결하지 않았다.

인증 및 데이터
- iOS는 기존 로그인 request closure를 제한된 메모리 세션으로 사용한다.
  화면 전환 메시지에는 모드와 세션 UUID만 포함한다.
- Android 실행 코드는 60초 만료/일회용이며 기존 원자적 코드 레지스트리를 재사용한다.
  코드 해시·토큰 audience를 기존 Live/test 경로 및 직무·인성별로 분리했다.
- API는 기존 베타 이용 권한을 실행/교환/목록/저장 시 재확인한다.
  native bearer는 계정·모드에 한정하고 관리자·AI·다른 모드에 사용할 수 없다.
- 새 DB migration은 필요하지 않다. 운영 DB는 함수 권한과 advisor 메타데이터만
  읽었다. 운영 학생 기록 생성·변경, 대규모 부하검사, 유료 분석 호출은 수행하지 않았다.
- 공개 질문 음성만 문구·파일명·바이트 수·SHA256을 대조하여 캐시한다.
  PC bridge 설정과 debug 테스트 자산은 Android 검토/Release 바이너리에 포함하지 않았다.

재검토 및 수정 (사용자 요청: 수정사항 있는지 재확인)

  녹음 파일 누락·손상·저장 실패 시 다음 문항으로 넘어가거나 완료 처리하지 않는다.
