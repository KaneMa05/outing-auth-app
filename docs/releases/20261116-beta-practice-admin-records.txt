베타 면접 연습 기록 관리자 연동

구현
- 관리자 면접반 메뉴에 베타 연습 현황 추가. 이름·학생 ID·수험번호 검색, 직무/인성/실전 필터, 페이지 이동.
- 연습 일시, 직렬, 분야, 지역, 질문 수, 답변 수, 답변 시간, 완료/중단 여부, 녹음 전송 수를 표시.
- 모든 답변의 질문과 녹음을 답변별로 열람. 관리자 역할 + interview.read 권한 필수.
- iOS 베타가 각 답변 저장과 연습 종료 시 이력을 동기화하고, 녹음은 기기 WAV를 유지한 채 AAC 32kbps M4A로 압축하고 비공개 Storage에 서명된 URL로 직접 전송. 압축은 UI/녹음 actor 밖에서 실행.
- 연습 화면 시작/복귀 시 미전송 기록 자동 재시도. 수동 재전송 버튼은 제거. 계정별 기기 저장 기록도 같은 계정으로 로그인 후 연동.
- 전송 실패는 연습/기기 재생을 차단하지 않으며, 미전송 녹음은 관리자 전송이 끝나기 전에 기기 기록에서 삭제할 수 없음.
- 기기 기록 삭제는 관리자 보관 기록에 영향 없음. 서버에 계정 삭제로 DB 행이 지워지는 경우에도 Storage 실물 파일은 별도 정리 필요.
- 초기 베타 직무·인성 AI 피드백 보류는 유지. 관리자 아카이브 전송과 AI 분석 요청은 별개.
- 학생 면접 준비 화면과 개인정보 처리 안내에 모든 답변 녹음의 관리자 전송을 안내.

1. supabase/migrations/20261116083526_interview_practice_admin_records.sql 적용.
   ip_owners / ip_student_directory 기반 신규 RLS 테이블 ip_practice_runs / ip_practice_turns, 서비스 역할 전용 RPC, 비공개 interview-practice 버킷.

   기존 녹음은 해당 계정으로 앱의 연습 화면을 다시 열고 동기화가 끝난 뒤 조회 가능.

2026-11-16 용량 검토 후 압축 보완
- 원본 WAV를 서버에 누적하는 방식을 중단하고, 서버에는 16kHz mono AAC 목표 32kbps M4A만 전송하도록 변경.
- 기기의 원본 WAV와 기존 다시 듣기는 유지. 파생 M4A는 소스 해시로 캐시해 재시도 때 같은 파일/해시를 재사용.
- 비공개 버킷 허용 MIME audio/mp4, 단일 파일 상한 16MiB. 녹음 본문은 DB에 넣지 않으며 DB에는 질문·시간·압축파일 크기·해시 등 메타데이터만 저장.
- 압축은 별도 utility 작업에서 실행하고 파일 마무리 후 원자적으로 저장. 불완전 압축 파일을 업로드하지 않음.
- 시뮬레이터 2분 샘플 실측: 원본 3,840,044 bytes → M4A 394,787 bytes, 120.0초 유지, 89.72% 절감. 테스트 신호이므로 발화 내용별 실제 크기/청감은 다를 수 있음.
- 관리자 브라우저에서 실제 AAC 디코딩/재생과 이전 답변 정지 검사 통과.
- Supabase 현재 조직 Pro 확인. 앱 프로젝트 등록 Storage 파일 합계 592,423,059 bytes(약 0.592GB); 타 프로젝트 파일 합계/청구월 평균 사용량은 이 수치에 포함되지 않음.
- 가정: 하루 10답변, 답변 2분, 30일. WAV는 100명 115.2GB / 300명 345.6GB / 1,000명 1,152GB. 목표 32kbps AAC는 각각 약 14.4GB / 43.2GB / 144GB + 컨테이너 오버헤드.
- Pro Storage 포함량 100GB는 조직 내 프로젝트 간 공유. 초과 저장 비용은 GB·시간 기준(월 환산 $0.0213/GB), 관리자 재생 다운로드 트래픽은 별도 사용량으로 집계.
- 참고: https://supabase.com/docs/guides/platform/manage-your-usage/storage-size / https://supabase.com/pricing
- 영구 무제한 보관은 계속 누적됨. 수강 기간 및 종료 후 보관 기간을 정하는 것을 권장. 이번 작업에서 자동 삭제나 기존 녹음 삭제는 시행하지 않음.
- 서버 반영 확인 질문에 사용자가 파일 크기를 우려하여 운영 DB/API/웹 배포는 계속 보류. 원본 WAV 업로드 버전 대신 압축 버전으로 테스트앱을 다시 빌드.

준비 화면 정리 (사용자 후속 요청)
- 기본 화면은 빠른 연습 카드의 주 버튼 1개와 질문 골라 연습 / 연습 설정 / 내 면접 기록 메뉴로 구성.
- 분야·지역·문항 수와 기존 설정 연습 시작은 연습 설정 화면으로 이동. 시작 기능/기존 조건은 유지.
- 질문 목록/즐겨찾기는 질문 골라 연습 화면 안의 전체 질문 / 즐겨찾기 탭으로 통합.
- 관리자 기록 다시 전송 버튼 전면 제거. 전송 대기 상태는 기록 화면의 작은 안내로만 표시하고 연습 화면 시작/복귀 시 자동 재시도를 유지.
- 실전 모의면접 및 비포털 연습 준비 UI는 기존 경로 유지.
- 실제 기기 기존 분야 선택 검사의 고정 문구(형사법·수사절차)가 현재 승인 문항의 유일 공개 분야(해양경찰 직무·경찰학)와 달라 처음 실패했으며, 현재 공개된 허용 분야를 고르는 검사로 수정. 질문이나 공개 범위는 변경하지 않음.
