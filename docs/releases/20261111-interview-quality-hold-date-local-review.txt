2026-11-11 테스트앱 면접 품질·판정 보류 로컬 수정 검토

상태: 로컬 수정/회귀 검사 완료. 사용자 최종 확인 전이므로 푸시, 서버 배포, 실제 아이폰 업데이트는 하지 않음.
대상: 테스트앱 실전 모의면접의 발화 연결/보관 종료 표시 및 테스트앱 직무 연습 판정.
일반앱: 기존 모델·추론·발화 종료 대기·연습 판정 유지. 날짜 표시와 직무 화면 개선은 iOS DEBUG에 한정.

1. 꼬리질문 신뢰성
가벼운 모델(Sol)과 low reasoning으로 바꾸던 미배포 수정은 취소했다.
기존 환경의 followupModel과 기존 추론 설정/출력 한도, 답변 근거 인용·반복 방지·최신 답변 버전 검사·발화 종료 대기를 유지한다.
테스트앱은 질문 검증과 저장 후 '네, 감사합니다. '+질문을 한 번에 전달한다.
즉, 감사 이후 끊김을 줄이는 변경이며 전체 생성 지연 감소나 생성 질문의 의미적 적절성을 실제 음성으로 검증한 상태는 아니다.
새 모델 품질 비교나 유료 질문 생성 재검증은 이번 턴에 실행하지 않았다.
관리자 사용량 이벤트에 test request generationMs 계측을 추가했다. 학생 비용 표시 없음.

2. 직무 판정 보류
수정 전 실제 아이폰 직무 3답변은 두 독립 음성 인식의 전문용어/일부 단어 차이 때문에 모두 review_required였다.
기존 전체 문자열 일치 조건을 일반앱에는 유지한다.
테스트앱 연습은 문장부호·반복 공백만 정규화하며 단어 경계·부정·숫자·기호를 보존한다.
직무의 실제 녹음 두 전사가 다를 때 각 전사를 따로 동일 기준으로 평가하고, 정확한 인용을 검증한 항목 중 두 판정이 같은 항목만 반영한다.
판정이 다르거나 인용이 잘못된 항목만 uncertain으로 남긴다. 확정되지 않은 항목을 임의로 O/partial/X로 바꾸지 않는다.
전체 요약은 차이가 있다는 안내로 제한하고 일반 피드백 인용은 다른 전사에서도 확인되는 것만 남긴다.
원본 두 전사와 확인용 인용/판정 방법을 보존한다. 전사기에 질문/예시답변/후보 단어를 제공하지 않는다.
실제 단어 차이가 있으면 기존에는 실행되지 않던 평가 API가 두 번 병렬 호출된다. 비용이 없는 수정은 아니며 실제 재검증 시 추가 사용량을 확인해야 한다.
음질 불량/빈 전사/인성의 의미 차이/일반앱은 전체 보류 유지. 저장된 이전 보류 결과를 유료로 자동 재처리하지 않는다.
iOS 직무 결과는 일부만 확인될 때 '일부 항목 확인', 확인된 항목 수, 각 항목의 상태와 근거를 표시한다.

3. 보관 종료
테스트앱 실전 모의면접 결과의 보관 종료는 한국 시간 기준 yyyy-MM-dd만 표시한다.
UTC 날짜 경계, 밀리초, 타임존, 날짜 문자열, 값 없음/잘못된 값 검사를 통과했다.
Release 원래 표시와 저장/삭제 시각 계산은 바꾸지 않는다.
