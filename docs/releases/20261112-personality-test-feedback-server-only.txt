인성 보류 개선
기존 테스트앱 인성 답변은 두 전사가 전체 문자열로 일치해야 피드백이 생성됐다.
이제 테스트앱의 실제 인성 녹음에 한해, 두 전사가 달라도 공통으로 확인되는 전체 문장에만 근거해 피드백을 만들 수 있다.
한 전사의 일부 문장을 잘라 다른 문장과 합치지 않는다. 질문·예시답변·외부 지식으로 전사를 보정하지 않는다.
각 피드백은 첫 전사의 정확한 인용과 두 번째 전사의 대응 인용을 검증한다.
문장부호·대소문자·반복 공백을 제외한 단어·부정·조건·숫자·정정이 다른 근거는 허용하지 않는다.
모델은 두 전사의 전체 맥락에서 모순·철회·정정도 확인하며 uncertain 항목을 제외한다.
공통 문장이 없으면 추가 피드백 모델 호출을 생략하고 보류한다. 근거가 부족하거나 음질이 나빠도 보류를 유지한다.
점수, O/△/X, 성격·진실성·합격 전망 판정을 추가하지 않는다.
새로 제출하는 인성 답변부터 적용한다. 기존 보류 결과를 유료로 자동 재분석하거나 운영 기록을 고쳐 쓰지 않는다.
일반앱은 기존 전체 전사 일치 정책을 유지한다.
