# Apple 심사용 실기기 녹화 안내

2026-10-28 · 대상 앱: 론박스터디 · Apple ID 6827374000

사용자가 직접 iPhone 녹화 가능하다고 확인했습니다. 촬영 파일은 아직 없습니다.
계정 삭제·콘텐츠 차단 보완을 운영 앱에 반영하고 확인한 뒤 최종 영상을 촬영합니다.
사용자 최종 확인상 심사용 계정에서 면접반은 열리지 않습니다. 이번 영상은 일반 수강생 기능을
대상으로 하며, 면접반을 시연했다고 설명하지 않습니다.
시뮬레이터 영상, 기존 스토어 이미지, 로컬 화면을 실기기 증빙으로 제출하지 않습니다.

## 촬영 준비

1. 설정 → 일반 → 소프트웨어 업데이트에서 최신 **정식** iOS인지 확인합니다.
2. TestFlight에서 심사 대상 빌드를 설치합니다. 현재 제출 기록은 **1.0.0 (4)**입니다.
   새 빌드가 제출됐다면 영상도 그 빌드를 사용해야 합니다.
3. 기종·OS 버전·앱 버전·빌드를 별도로 기록합니다. 일련번호·Apple ID는 촬영하지 않습니다.
4. 전용 테스트 계정을 준비합니다. 다른 수강생의 실제 이름·전화번호·성적은 화면에 노출하지 않습니다.
5. 알림을 잠시 숨겨 개인 메시지가 녹화에 끼어들지 않게 합니다.
6. 제어 센터의 화면 기록을 시작한 후 홈 화면의 앱 아이콘을 눌러 앱을 실행합니다.
   Apple이 요구한 시작점은 앱 실행입니다. 로그인된 내부 화면에서 시작하지 않습니다.

## 기본 영상 순서

영상은 동작과 결과를 읽을 수 있을 만큼 천천히 진행합니다. 권장 길이는 약 3~6분이며 Apple의 고정 제한이 아닙니다.

| 순서 | 보여줄 내용 |
|---|---|
| 1 | 홈 화면 → 앱 아이콘 → 앱 실행과 초기 화면 |
| 2 | 발급된 등록번호 조회 → 비밀번호 입력 → 로그인 성공. 비밀번호는 노출하지 않음 |
| 3 | 해당 계정의 홈과 주요 기능을 실제로 조작하고 저장·재조회 결과 확인 |
| 4 | 사용자 콘텐츠가 있다면 테스트 게시글·댓글·메시지의 신고와 작성자 차단, 차단 후 결과 |
| 5 | 마이 → 계정 및 데이터 삭제 → 삭제 범위·기간 확인 → 확인 문구 입력 → 접수 완료 |

계정 유형별 추가 영상은 각각 앱 실행부터 시작해 해당 유형의 흐름을 보여주면 됩니다.

| 유형 | 주요 기능 예시 |
|---|---|
| 오프라인 | 홈 → 출석 → 외출 신청·상태 확인 → 성적 → 마이 |
| 온라인 관리반 | 홈 → 스터디카페 입장·타이머 시작/종료 → 성적 → 마이 |
| 인터넷 수강생 | 홈 → 플래너 작성·완료 → 스터디카페 → 게시판 → 마이 |

실제로 접근할 수 없는 기능을 실행된 것처럼 설명하지 않습니다. 모든 기능이 무료라는 사용자 확인에 따라
유료 기능 구매 장면은 해당하지 않는다고 답변합니다.

## 가입과 삭제

- 가입 신청이 앱에 제공된다면 신청 과정도 별도 테스트 계정으로 보여줍니다.
  승인 대기가 있는 서비스라면 그 사실을 설명하고 Apple에는 이미 승인된 데모 계정을 줍니다.
- 별도 면접반 신규 가입 경로가 실제로 열려 있다면 그 사실을 추가로 확인해야 합니다.
  현재 심사 계정에서 면접반 기능이 열리지 않는 것과 앱 안의 가입 경로 존재 여부는 별개입니다.
- 삭제 시연은 **폐기 가능한 별도 테스트 계정**으로 합니다. Apple이 계속 사용할 심사 계정은 삭제하지 않습니다.
- “삭제 요청 접수”는 “실제 삭제 완료”와 다릅니다. 수동 처리가 필요하면 처리 기간과 결과 안내 방식이 보여야 합니다.
  실제 삭제 후에는 데이터·파일·로그인 불가까지 확인한 결과를 별도로 남깁니다.
- 개인 휴대전화 인증번호, 비밀번호, Apple/Kakao 계정 정보는 영상에 노출하지 않습니다.

iPad도 지원하는 앱이므로 iPad 실기기에서도 해당 빌드의 레이아웃·로그인·주요 기능을 확인합니다.
현재 이 프로젝트에서 실기기 검증을 수행했다고 기록하지 않습니다.
