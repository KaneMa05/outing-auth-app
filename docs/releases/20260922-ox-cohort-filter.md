# OX 교재 구매 관리 기수 필터 · 인강 아이디 검색

상태: 로컬 구현 및 검증 완료. 이번 변경의 운영 DB 적용·푸시·배포는 아직 하지 않음.

- 교재 구매 · 이용 수강생 관리에 전체 기수 / 기수별 / 인터넷 수강생(기수 없음) / 기수 미지정 필터 추가.
- 기수 목록은 기존 조회 대상 전체에서 생성하고 이름·교재·이용 상태·등록 여부와 조합해 서버에서 페이지 분할 전에 필터링.
- 학생 목록과 구매 등록 창에 기수 표시. 기수 변경 시 첫 페이지로 이동.
- 학생 목록과 구매 등록 창에 인강 아이디 표시. 기존 검색창에서 이름·학생 ID·인강 아이디로 검색 가능.
- 승인된 수강 신청의 approved_student_id 및 성적 관리의 student_id로 연결된 아이디만 조회. 동일 이름으로 추정해 연결하거나 외부 응시자·미승인 신청 아이디를 포함하지 않음.
- 연결된 여러 아이디는 모두 표시·검색하고 정규화한 동일 아이디는 중복 제거. 인강 아이디 부분 검색은 대소문자·공백·전각 영문 차이를 정규화하며 기존 기수·교재·이용 상태 검색과 함께 적용.
- 연결된 인강 아이디가 없으면 미등록 표시. 관리자 조회만 확장하며 학생용 응답에는 인강 아이디를 추가하지 않음.
- 기존 학생 관리와 동일하게 명시된 기수 우선, 기존 숫자 학생 ID의 기수 추론을 보조로 사용. 인터넷 수강생은 추론하지 않음.
- 새 마이그레이션은 ox_service의 admin_members 분기만 변경. 구매 권한·학습 기록·그 밖의 함수 분기는 유지.

## 검증

- 기존 OX SQL/API 4개 및 교재 권한 테스트 2개 통과.
- 새 기수 테스트 2개 통과: 페이지 분할, 복합 필터, 명시적 기수 우선, 기존 ID, 인터넷/미지정, 권한 및 입력 검증, 목록 외 함수 불변.
- 로컬 가상 데이터 브라우저 검증 통과: 기수 선택, 학생 표시, 검색 결과 없음, 기존 교재 등록·중지·이력과 학습, 390px/1100px 가로 넘침 없음.
- 인강 아이디 출처별 검색·중복 제거·별칭·기수/교재 조합·미승인 및 외부 응시자 제외·HTML 이스케이프·긴 아이디 줄바꿈 검증 통과.
- LF로 정규화한 격리 작업 사본에서 npm test 통과. 관련 없는 작업 중 final-scope-data.js 수정은 검증 사본에서 HEAD로 대체.
- 격리 디렉터리에서 운영 모드 build-config.js 빌드 통과. 실제 작업 폴더 config.js 유지.

2. 이번 변경 파일만 커밋·푸시하고 Vercel 자동 배포 확인. final-scope-data.js 등 다른 작업은 포함하지 않음.
