# 회독 플랜 회차 전환 스크롤 수정

상태: 로컬 수정·검증 완료. 푸시·배포 전 최종 확인 대기.

회차 선택 시 전체 화면을 다시 그려 회차 목록의 스크롤이 0으로 초기화된 뒤 선택 회차까지 부드럽게 이동하던 문제를 확인했다. 실제 로컬 앱의 320px 온라인 관리반에서 4회 선택 직전 scrollLeft 58 → 선택 직후 0, 버튼 재생성과 포커스 손실을 재현했다.

`selectFinalScopeRound`가 현재 회차 목록과 버튼을 유지하면서 시험 범위 내용만 교체하도록 변경했다. 선택 표시·aria-pressed를 갱신하고 현재 위치에서 가로 목록만 이동한다. 동작 줄이기 설정에서는 애니메이션을 생략한다. 회독 데이터, 시험 범위, 접근 권한, 다른 화면은 변경하지 않는다. app.js 자산 버전과 서비스워커 캐시를 갱신했다.

검증:
- 로컬 실제 앱에서 두 수강생 유형 × 320/390/768px × 4·5·12·11·2회 선택: 동일 목록·스크롤 위치·포커스 유지, 올바른 선택 표시와 시험 범위 제목 확인.
- 4 → 5 → 12회 빠른 연속 선택 이후 12회 유지 확인.
- `node tests/final-scope-plan.test.js`, `node tests/release-safety.test.js`, JS 구문 검사 통과.
- `.tmp/final-scope-scroll-build`의 격리된 로컬 `npm run build` 통과. 운영 설정은 변경하지 않았다.
- 브라우저 검증은 `.tmp/final-scope-scroll-qa/verify.cjs`에서 HTTPS와 운영 API를 차단한 예시 계정으로 수행했다. 관리반 390px 캡처 확인.

기존 미완료 성적 관련 변경과 `final-scope-data.js` 변경은 이 수정에 포함하지 않는다.
