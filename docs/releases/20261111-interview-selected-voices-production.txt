남은 기기 작업
iPhone 실제 테스트는 사용자 계획대로 맥북에서 진행한다.
docs/interview-live-selected-voices-mac-handoff-20261111.txt 에 Debug 브랜치,
Xcode 실행, 표식/아바타 신원, 6문답, 종료·비용·비밀정보 처리 순서를 남겼다.
서버 키의 동일 OpenAI 프로젝트/음성 사용 권한도 맥북 첫 실제 세션에서 확인한다.

Android 앱 실행은 USB/ADB 기기 미인식으로 미완료다.
사용자가 USB 연결·디버깅 활성화를 확인했지만, 기존 ADB 인증 경로 사용과
서버 재시작 뒤에도 devices 목록이 비어 있었다. Windows PnP 조회는 정상
(168개 장치)이나 휴대폰/ADB 인터페이스는 식별하지 못했다.
장치가 인식되면 실제 설치된 테스트 패키지부터 확인하여 실행해야 한다.
기기 내 연습/브리지 화면과 실제 OpenAI Live 음성 테스트를 구분한다.
기존 Debug 진입점 소스 기준은 com.ronpark.study.nativepreview 패키지의
com.ronpark.interview.InterviewPreviewActivity이다. 기기가 device 상태로 인식되고
해당 패키지가 실제 설치된 것을 확인했을 때만 이 Activity를 실행한다.
정식 com.ronpark.study 앱을 지우거나 테스트용 APK로 덮어쓰지 않는다.
