iPhone 북마크 웹앱 완전 종료 시작/하단 탭 보완 — 배포·실제 아이폰 재검증 완료

사용자 확인
일반 실 프로덕트의 iPhone 홈 화면 북마크 웹앱(PWA). 네이티브 앱 문제가 아님.
앱 전환기에서 완전 종료 후 홈 아이콘으로 열어야 증상이 보인다고 사용자 안내.
미러링에서 완전 종료 뒤 홈 아이콘 재실행 시 흰 전체 화면 다음 면접반 홈 표시를 관찰.
이전 복귀 화면 관찰을 완전 종료 검증으로 간주하지 않음.

확인한 코드 경로
manifest 시작 URL은 /index.html#home.
이 페이지의 app-startup.js/css는 20261028 주소를 유지하고 있었고 기존 SW는 정적 자원을 캐시 우선으로 제공.
면접반 복귀 사용자는 학생용 시작 화면/로그인 확인 후 /interview?app=1로 이동.
기존 인터넷 학생 정보가 있으면 학생용 어두운 시작 테마가 면접반 복귀 전에 적용될 수 있음.
iOS 시스템이 표시하는 웹 페이지 이전 launch surface는 일반 CSS 검사로 검증할 수 없음.

로컬 수정
index/면접반 시작 파일 참조를 20261113-pwa-cold-start로 갱신.
SW v569: 시작 JS/CSS만 네트워크 재검증 우선, 오프라인에서는 저장 파일 사용.
열려 있는 화면 강제 이동/자동 새로고침 없음. API 캐시 및 로그인 데이터 변경 없음.
면접반 복귀 신호가 있는 공통 시작 화면은 면접반과 같은 팔레트를 사용.
이때 이전 인터넷 학생의 어두운 시작 테마를 초기에 적용하지 않음.
명시적 기존 학생 화면 진입과 로그인 실패 후 일반 학생 테마 갱신은 유지.
면접반 HTML 최초 배경·color-scheme과 PWA 상태바 메타데이터 정리.
iPhone 12개 화면 크기의 가로/세로 PNG 시작 이미지 24개(단색 #f2f5f7, 약 250KB).
면접반 HTML에 적용하며 공유 index에서는 복귀 사용자에게만 template의 시작 이미지 링크를 활성화.
다른 학생 페이지에는 전역 시작 이미지나 강제 밝은 테마를 적용하지 않음.
하단 불투명 배경은 bottom:0 유지, 버튼 아래 여백은 최소 24px/safe-area+12px로 증가.
본문 하단 여백도 16px 늘려 마지막 내용 가림을 방지.
모의면접, 평가, 음성, DB, 사용자 녹음 변경 없음.

실제 아이폰 관찰 (중요)
대상은 사용자가 확인한 홈 화면 북마크 '론박스터디', 네이티브 테스트앱 아님.
자동 미러링 카드 종료가 동작하지 않아 사용자가 앱 전환기에서 종료를 도와줌.
배포 직후 첫 완전 종료 재실행: 초기 흰 화면이 여전히 관찰됨. 하단 버튼은 올라간 것 확인.
새 자원을 불러온 뒤 사용자가 다시 완전 종료, 두 번째 재실행 수행.
두 번째 재실행에서는 #f2f5f7 계열 배경의 R 로고/학습 화면 준비 로딩을 확인했고, 같은 배경의 면접반 홈으로 이어짐.
하단 불투명 배경은 화면 끝까지 유지하며 버튼과 홈 표시줄 사이 여백이 늘어난 것 확인.
이는 실제 관찰 결과이며 고속 프레임 녹화로 모든 iOS 시스템 프레임을 검사한 것은 아님.
설치 직전·캐시 갱신 직후의 OS 시작 표면을 모든 iPhone/iOS 버전에서 제거했다고 단정하지 않음.
관련 보고: https://bugs.webkit.org/show_bug.cgi?id=311569 (유사 cold start 흰 프레임, 원인 동일하다고 확정하지 않음).
