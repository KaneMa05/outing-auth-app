적성 모의고사 상위 비율 표시 준비 (2026-11-16)

상태: 로컬 구현/검증 완료, 운영 웹 배포 전.
사용자 요청: 등수 아래에 백분위 표시. 1·2등급 합산 기준은 상위 33% 이내.

표시
- 면접반 수강생 성적 조회의 등수 바로 아래에 '상위 29.51%'처럼 소수점 두 자리로 표시한다.
- 계산은 기존 공동등수 / 기존 전체 응시자 수 × 100이다. 이전 기수가 등록된 회차는 기존 API의 합산 인원을 그대로 사용하며 동점자는 같은 비율이다.
- 예시: 18 / 61명 → 상위 29.51%.
- 성적 카드 아래에 '1·2등급 기준: 상위 33% 이내'와 '기준 이내/기준 밖'을 표시한다. 개별 1등급과 2등급을 나누지는 않는다.
- 기준 판정은 반올림 전 등수 × 100 <= 전체 인원 × 33을 사용한다. 표시가 33.00%여도 실제 비율이 33%를 넘으면 기준 밖이다.
- 유효한 등수/인원이 없으면 상위 비율과 기준 판정을 만들지 않는다.
- 기존 결과 공개 정책과 본인 답안/해설 조회 흐름은 그대로 사용한다. DB/API 변경과 추가 조회는 없다.
- 이전 기수가 있는 회차는 등수 변동 안내에 이전 기수를 포함한다고 명시한다.
- 정적 파일 및 전체 면접 진입 경로의 버전을 20261116-aptitude-percentile로 갱신하고 SW 캐시 버전은 v570-interview-aptitude-percentage로 준비했다. 사용 중인 화면의 강제 이동/새로고침은 추가하지 않았다.
