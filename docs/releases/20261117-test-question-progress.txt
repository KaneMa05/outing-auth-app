테스트앱 질문별 연습 현황 표시

- iOS 질문 골라 연습 및 Android Debug InterviewBetaPracticeActivity의 각 질문 카드에 표시.
- 미연습: 아직 연습하지 않음 · 0회 · 최근 연습 없음
- 답변 있음: 답변 완료 · N회 · 최근 yyyy.MM.dd (한국 날짜)
- 현재 계정의 같은 모드 기록에서 questionID/questionId로 집계. 질문 문구로 추측 연결하지 않음.
- 저장된 WAV가 헤더 44바이트보다 커야 포함. 질문을 열기만 하거나 녹음 파일이 없으면 제외.
- 회차당 같은 문항은 한 번만 집계하며, 중도 종료 회차도 저장된 답변은 포함.
- 최근 연습일은 해당 문항에 답변한 가장 최근 회차의 시작일을 한국 시간으로 표시.
- 현재 기기에 남아 있는 계정별 기록 기준. 기기 기록 삭제 시 해당 회차도 집계에서 제외.
- 질문 목록을 열 때 다시 집계하며 전체/즐겨찾기/분야 목록에 같은 현황 적용.
- 서버 API/DB/Release 경로 변경 없음.

검증
- Android Debug APK 빌드 및 Lint 성공, 단위 테스트 43개 통과.
- iOS 저장 파일 기반 계정/모드 분리·누락 녹음·중복·횟수/날짜 집계 검사 통과.
- iPhone Debug 빌드 성공.
- iOS 시뮬레이터 UI 검사 통과: 질문별 현황 표시, 즐겨찾기 유지, 분야 변경, 선택 문항 연습 시작.
- 연결된 iPhone 16에 업데이트 설치 및 기본 실행 완료. 기존 테스트앱 데이터 유지.
- Android는 기기 설치 없이 최신 테스트 APK 생성 완료.
