적용 범위와 선택
서버가 testApp=true로 표시하고 서명한 테스트앱 실전 모의면접 세션만 변경한다.
- interviewer-woman: voice_6af3fd211ea081918dc2e8e94f946587 (여성 최초 샘플)
- interviewer-man-1: voice_6af4003787988191b9708350269ed872 (남성 3차)
- interviewer-man-2: voice_6af4003787988191b9708350269ed872 (남성 3차)
이전 테스트앱에서 면접관 정보가 없으면 승인한 여성 음성을 기본으로 사용한다.
일반 앱은 기존 noeul 기본값과 원래 면접 지침을 그대로 사용한다.
직무·인성 연습모드의 기존 녹음·화면·동작은 변경하지 않는다.
새 세션 시작 시 음성을 정하며, 진행 중인 세션의 음성은 교체하지 않는다.

구현
lib/interview-live-test-voices.cjs: 서버가 관리하는 승인 ID와 원래 생성 프롬프트.
lib/interview-live-policy.js: 승인한 {id: voice_...}만 허용하며 원래 음성 설명을
전달한다. 실제 질문 진행·대기·정답/힌트 차단·AI 고지 지침은 유지한다.
lib/interview-live-engine.js: 서명된 actor의 테스트앱 면접관에 맞춰 음성을 선택.
클라이언트 입력 voice/voiceId/prompt/instructions는 계속 거부한다.
임의 ID와 채택하지 않은 남성 1·2차 ID도 등록 음성으로 허용하지 않는다.
최초 질문과 두 꼬리질문은 같은 세션·같은 목소리를 사용한다.
질문 2개 × (메인 1 + 순차 꼬리 2) = 총 6문답 흐름을 유지한다.
비용은 관리자 전용 API와 화면에서만 제공하며 기존 원장을 변경하지 않는다.
음성 생성 API 호출을 앱 경로에 추가하지 않는다.

배포 시 확인할 조건
선택한 voice ID는 생성한 OpenAI 프로젝트에 속한다.
실서버 키가 같은 프로젝트에서 승인 음성을 사용할 권한을 가져야 한다.
운영 Secret을 내려받거나 추출하지 않는다. 권한/프로젝트가 다르면 신규
테스트 세션 시작이 거부될 수 있으므로 배포 후 첫 테스트 세션에서 확인한다.
기존 일반 앱의 세션과 연습모드에는 이 음성 변경을 적용하지 않는다.
