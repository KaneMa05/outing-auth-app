# 관리자 데이터 분석 — 형사법 OX

관리자 사이트의 운영 도구에 `데이터 분석`을 추가했다. 선택한 기간의 날짜별 수강생·교사 이용자 수, 각각의 풀이 횟수, 기간 전체의 중복 제외 이용자 수를 조회한다. 기본 조회는 최근 30일(최초 기록일 2026-09-17 이후)이며 최근 7일, 이번 달, 직접 날짜 선택을 지원한다. 일별 추이 그래프와 최신 날짜순 표를 제공한다.

## 집계와 권한

- 한국시간 00:00부터 다음 날 00:00 전까지 저장된 `ox_attempts` 기준. 단순 접속은 제외한다.
- 하루에 여러 번 답안을 저장해도 이용자는 1명이다. 기간 합계도 계정 중복을 제거한다. 일별 인원 합계와 다르다.
- 모든 콘텐츠 버전과 재풀이를 포함한다. 비활성 계정의 보존된 기록도 포함하며, 수강생·교사 구분은 현재 `students.account_type`을 따른다.
- 이용 기록 없는 날짜는 0으로 채운다. 오늘은 집계 시점까지의 부분 집계다.
- 한 요청은 최대 366일이며 미래 날짜는 거부한다. 진입 또는 사용자의 조회 요청 시에만 집계하고 자동 갱신하지 않는다.
- `analytics.read` 권한을 UI 및 API에서 검사한다. 기존 관리자 `*`는 사용할 수 있고, 학생 기기 인증이나 OX 관리 읽기 권한만으로는 사용할 수 없다.
- RPC는 `SECURITY INVOKER`, `STABLE`, 빈 search_path를 사용한다. PUBLIC/anon/authenticated 실행 권한을 제거하고 service_role에만 부여한다. 계정 ID와 이름은 반환하지 않는다. [Supabase 함수 권한 지침](https://supabase.com/docs/guides/database/functions)을 따랐다.

## 변경 범위와 반영 순서

- 새 UI: `data-analytics-admin.js`, `data-analytics-admin.css`. 관리자 HTML에만 로드한다.
- 기존 OX API에 읽기 전용 `admin_analytics` 추가. 기존 수강생 RPC와 저장 동작은 변경하지 않는다.
- CLI로 생성한 `20261001140723_ox_usage_analytics.sql`은 집계 RPC와 시간 인덱스만 추가한다. 기록을 수정하거나 삭제하지 않는다.
- 사용자 최종 승인 후 DB 마이그레이션을 먼저 적용하고 관리자 프런트/API를 배포한다. DB 적용 전 분석 요청은 실패 안내를 보여주며 다른 OX 요청은 기존 경로를 사용한다.
- 서비스 워커는 새 자산 버전만 추가한다. 강제 화면 이동은 추가하지 않는다.
- 구현 시 작업 폴더에 있던 성적·회독 플랜 등의 별도 변경은 유지했다. 배포할 때 이번 변경과 기존 미배포 변경의 범위를 분리해 검토해야 한다.
- 현재 운영 DB 적용, 푸시, 배포는 수행하지 않았다.

## 검증

- `npm run test:data-analytics`: 한국시간 자정 경계, 날짜·기간별 중복 제거, 교사 분리, 0명 날짜, 비활성 기록, 읽기 전용, RPC 실행 권한, 위조 actor, API 권한 및 날짜 검증 통과.
- `npm run test:criminal-law-ox`: 기존 학습·이용권·기기 인증 회귀 전체 통과.
- `npm test`: Windows CRLF를 가정하지 않는 기존 `grade-ranking-groups.test.js`의 소스 추출 정규식에서 작업 폴더 실행이 중단됨. 같은 소스를 LF로 정규화한 `.tmp/data-analytics-validation`에서 pretest/test/posttest 전체 통과. 기존 소스나 테스트 의미는 변경하지 않았다.
- `npm run build`: 로컬 빌드 통과. 배포 환경의 실제 설정 값 확인은 배포 시 별도로 필요하다.
- 로컬 PGlite와 실제 API/렌더러를 연결한 합성 데이터 브라우저 검증: 기본 기간, 이번 달, 날짜 직접 입력, 0건 표시, 390px 반응형 배치 정상. 브라우저 오류 로그 없음.
- 로컬 미리보기의 숫자는 합성 테스트 데이터이며 운영 실적이 아니다.
