기능
- 앱의 기존 마이에 나의 자료와 AI 역할별 지침을 추가했다. 웹에는 마이 메뉴를 추가했다.
- DB 복사 버튼을 누를 때만 기존 본인 인증 API의 life_get / diagnosis_get을 조회한다. 마이 진입과 지침 선택·복사는 추가 DB 조회나 AI 호출을 하지 않는다.
- 본인 DB에는 저장된 이력·경험과 진단 보완 문답만 포함한다. 지침은 별도로 선택·복사한다.
- 경험 정리 코치 / 답변 구성 코치 / 실전 면접관 / 평가·첨삭 코치 / 사실 확인 도우미의 다섯 역할을 제공한다.

- 화면 종료 시 개인 텍스트를 비우고 늦게 도착한 조회를 무시한다. 복사 자료를 로그·localStorage·별도 DB에 보관하지 않는다.
