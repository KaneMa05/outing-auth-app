## 관리자 화면

기존 `teacher.html` 안에서 **통합 관리 / 면접반**을 전환한다. 면접반에서는 다음 전용 메뉴를 표시한다.

| 메뉴 | 기능 |
|---|---|
| 면접반 홈 | 등록·작성 현황 확인과 주요 관리 화면 진입 |
| 학생 등록·첨삭 | 기존 학생에게 면접 이용 등록, 인성 준비 노트 확인·피드백 |
| 인성 준비 항목 | 작성 항목·필수 여부·순서·사용 여부 관리 |
| 핵심인성 30제 | 제공 교재 문항, 교재 기준 요소 분석, 원문 해설 확인·질문 편집·공개 |
| 인성 기출 관리 | 인성 질문 생성·조회·수정·삭제 또는 보관 |
| 질문 요소 분석 | 세부 평가 요소, 분석 근거 및 검토 상태 관리 |
| 직무 기출 관리 | 인성과 분리된 직무 질문 관리 |

모드와 마지막 면접 메뉴는 같은 브라우저에서 관리자 계정별로 기억한다. 명시적인 주소가 있으면 해당 주소를 우선하며, 주소 없이 다시 접속하면 저장된 모드를 복원한다. 관리자 역할과 `interview.read` 권한을 확인한 뒤 표시한다. 작성 중인 관리자 폼을 이동할 때는 저장하지 않은 변경을 확인한다.

학생의 전용 앱 모드·하단 탭 전체 전환은 이 변경 범위에 포함되지 않는다. 기존 테스트 허용 대상과 면접 이용 등록 검사는 유지한다.

## 학생에게 묻는 방법

**공통 저장 구조는 유지하되, 화면 질문은 준비 항목별로 구체화**한다. 상황·역할·행동·결과·배운 점이라는 기본 구조는 경험을 재사용하기 좋지만, 모든 요소에 같은 질문을 표시하면 어떤 행동을 써야 하는지 모호해진다.

- 협동심: 공동 목표, 맡은 역할, 동료에게 제공한 도움, 함께 만든 결과를 묻는다.
- 소통·갈등: 서로 달랐던 입장, 상대의 말을 확인한 방법, 제시한 대안과 합의 과정을 묻는다.
- 책임감: 맡은 의무와 기한, 문제 발생 시 보고·수습 행동을 묻는다.
- 공직관: 중요하게 생각하는 공적 가치, 그 근거, 실제 실천 기준을 묻는다.

13개 준비 항목의 기본 질문을 각각 바꾸고, 31개 세부 요소별 확인 질문을 펼쳐 볼 수 있게 했다. 하나의 경험에 여러 요소가 드러나면 같은 경험을 보완할 수 있다. 요소마다 별도 경험이나 반복 답변을 강제하지 않는다.

기존 답변의 필드 키와 저장 내용은 유지한다. 작성률은 기존 13개 준비 항목의 제출 상태 기준이며, 확인 질문을 읽었다는 이유로 31개 요소를 충족했다고 표시하지 않는다. 학생 개인 DB는 계속 인성 전용이다.
