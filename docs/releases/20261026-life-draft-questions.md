# 인생그래프 내용 기반 꼬리질문

학생이 경험 내용을 작성하고 ‘꼬리질문 2개 받기’를 누르면 PC 실행기가 해당 본문만 읽고 서로 다른 질문 두 개를 생성한다. 질문 근거는 본문에서 정확히 인용해야 하며, 실패 시 공통 질문으로 대체하지 않는다. 키워드만 적거나 본문이 비어 있으면 질문 영역을 숨긴다.

동일 학생·동일 본문의 결과는 서버에서 재사용한다. 생성 횟수는 학생당 최근 24시간 10건이며, 학생당 동시 요청은 한 건이다. 자동 재생성 없이 작업 임대 만료 시 실패 처리한다. 작성 내용 변경·화면 종료 후 늦게 도착한 응답은 화면에 반영하지 않는다. 입력과 저장은 생성 여부와 무관하게 동작한다.

운영 설정은 `INTERVIEW_DRAFT_QUESTIONS_ENABLED=true`이다. 기존 `INTERVIEW_CORE25_WORKER_TOKEN`을 서버 인증에 재사용하고, PC에서 `scripts/start-draft-questions-worker.ps1`로 별도 실행기를 시작한다. 로컬 비밀 설정 `.env.core25-worker.local`은 버전 관리에서 제외한다. PC가 켜져 있고 로그인되어 있어야 새 질문을 생성할 수 있다. 실행기는 기존 핵심인성 진단 실행기와 별도 프로세스이며 같은 계정 사용량을 소비한다.

새 테이블과 함수는 서버 전용이며 익명·일반 인증 역할의 직접 접근을 허용하지 않는다. 학생 신원은 웹/기기 인증에서 얻으며 클라이언트가 지정할 수 없다. 기존 프로필과 답변 데이터 구조는 변경하지 않는다.

함께 반영: PC 앱 너비 1,180px, 핵심인성 문항 진입 시 요약서 펼침, 저장 시 수동 접힘 상태 유지.

검증: 대기열 권한·캐시·한도·임대, API 인증·출처 검증, 실제 모델로 가상 경험의 두 질문 생성, 브라우저 작성·저장·모바일·입력 포커스, 기존 핵심인성 진단 및 서비스 워커 배포 안전성.
