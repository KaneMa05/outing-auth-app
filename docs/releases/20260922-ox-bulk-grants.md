# OX 이용권 일괄 지급

상태: 사용자 배포 승인(2026-09-22). 운영 DB 마이그레이션 4건 적용 완료, 앱 배포 진행. 실제 이용권 지급은 하지 않음.

## 최종 이용 조건

- 구매 확인된 교재 또는 유효한 별도 이용권이 있는 영역만 학습 가능.
- 구매 내역과 지급 내역을 별도 테이블로 보관. 미구매자를 구매자로 등록하지 않음.
- 전체 학습 설정과 학생별 OX 전체 중지는 기존대로 적용. 일괄 지급으로 수동 중지를 해제하지 않음.

## 관리자 사용 방법

형사법 OX 관리 → 교재 구매·이용 수강생 관리 → OX 이용권 일괄 지급·이력.

1. 오프라인 재원생 전체 또는 특정 기수 선택. 실제 대상은 활성 오프라인 학생 계정이며 교사·비활성·온라인 관리반·인터넷 학생 제외.
2. 형법·수사·증거·공판 중 지급 영역 선택.
3. 오프라인 재원 기간 또는 종료일 지정. 지정일은 한국 시간 당일까지 이용하며 오프라인 재원 상태도 확인.
4. 지급 사유 입력 후 대상 확인. 명단은 30명씩 표시하며 기존 구매·유효한 이용권·전체 중지 여부를 함께 확인.
5. 확인한 명단에 일괄 지급. 명단 변경 또는 10분 경과 시 다시 확인. 동일 지급 요청 재전송은 중복 지급하지 않음.
6. 지급·회수 이력에서 명단을 다시 확인하고 사유를 남겨 해당 지급 건 전체 회수 가능. 다른 지급 건이나 구매 권한은 유지.

현재 명단에 한 번 지급하는 기능이며, 이후 신규 재원생에게 자동 지급하지 않음. 지급 이력이 있어도 현재 오프라인 활성 상태가 아니거나 종료일이 지나면 해당 혜택으로 학습 불가.

## 서버·검증

- `ox_grant_batches`, `ox_grant_recipients` 추가. RLS 활성화 및 public/anon/authenticated 직접 접근 차단. 관련 RPC는 security invoker, 빈 search_path, service_role 실행만 허용.
- 읽기는 criminal_ox.read, 미리보기 생성·지급·회수는 criminal_ox.write 권한 필요. 사용자 제공 actor는 무시.
- 구매 전용 확인 함수와 학습 가능 영역 확인 함수를 분리. 이용권이 있어도 실제 교재 구매 등록 가능하며, 구매 취소로 별도 이용권을 회수하지 않음.
- OX 상태·일반/요약 초기화·문제 조회·해설·답안·메모·학습 세션의 모든 경로에 같은 이용 조건 적용.
- DB 테스트: 35명 페이지 구분, 기수 추정 규칙, 중복 요청, 대상 변경, 확인 만료, 중지 유지, 기간 만료, 범주 변경, 구매 권한·다른 지급 건 유지, 기록 복원, 미지급자 차단, 권한 격리 통과.
- 실제 관리자 화면/API/SQL의 대상 확인·지급·회수·읽기 전용 UI 및 390/1100px 표시 검증 통과.
- 전체 테스트는 LF 격리 사본에서 통과. 관련 없는 final-scope-data.js 원본은 보존. 운영 모드 빌드는 config.js를 변경하지 않는 격리 디렉터리에서 수행.

## 최종 확인 후 반영

기존 미적용 마이그레이션(기수/인강 → 통합 기기 → 구매 확인)에 이어 `20260922044821_ox_bulk_access_grants.sql` 적용 후 앱 배포.
마이그레이션 자체는 이용권을 지급하지 않음. 운영 대상은 관리자가 명단을 확인하고 지급해야 함.
승계 구매 권한 9건의 구매 확인 잠금은 유지되며, 필요하면 별도 이용권을 명시적으로 지급하여 지원.
