# 면접반 전체화면 로그인 통합

기존 `/interview` 로그인에 해양경찰 시안의 배경과 카카오 버튼을 적용했다. 첫 화면의 회원가입 설명/별도 버튼은 제거하고, 같은 카카오 인증 진입점에서 기존 계정 연결과 신규 신청을 계속 처리한다.

- 변경: interview.html, interview-portal.js, interview-login.js, interview-login.css, assets/interview-login/coast.png
- 인증 API, 쿠키, OAuth 콜백, 승인 정책, DB 스키마는 변경하지 않았다.
- 로그인 전용 클래스와 컴포넌트를 사용한다. 인증 후에는 전용 클래스와 모션 이벤트를 해제한다. 다른 수강생 유형, 교사·관리자 화면에는 새 CSS를 로드하지 않는다.
- 배경은 브라우저 영역 전체를 채운다. 낮은 데스크톱 높이에서는 헤더·타이포 간격을 줄이며, 모바일은 자연스럽게 세로 배치한다.
- 카카오 미설정·서비스 미개방 상태에서는 버튼을 비활성화하고, 세션 확인 실패 시 재시도를 제공한다. 에러 안내는 필요할 때만 노출한다.
- 이미지 출처: docs/login-coastguard 시안의 내장 image_gen 생성 이미지. 해당 시안 README에 생성 프롬프트가 보존되어 있다.

## 검증

- `node tests/interview-auth.test.cjs`: 통과. 실제 외부 인증/운영 DB 없이 기존 인증·가입·계정 연결·승인·세션 흐름 검사.
- 변경 JS와 QA 서버 구문 검사: 통과.
- `.tmp/interview-build`에서 배포 환경 형식의 로컬 설정 빌드: 통과. 빌드 전용 공개 자리표시자를 사용했으며 루트 config.js는 덮어쓰지 않았다.
- 기존 통합 빌드 검증 스크립트는 이 실행 환경에서 자식 프로세스 시작 결과가 null이라 중단되어, 위와 같이 직접 구문 검사와 격리된 설정 빌드로 확인했다.
- 기존 QA 서버의 실제 인증 핸들러 + 메모리 DB + 로컬 카카오 대체 인증으로 브라우저 확인: 카카오 시작, 기존 계정 연결 폼, 신규 신청, 승인 대기, 기존 등록 학생의 학습 화면 표시, 로그아웃 복귀.
- 인증 후 로그인 배경/전용 body 클래스 제거 확인. 브라우저 콘솔 오류 없음.
- 데스크톱 콘텐츠 영역 1440×857 및 1280×677에서 화면과 문서 크기 일치(불필요한 스크롤 없음). 모바일 390px에서 가로 넘침 없음.
- 확인 화면: ../login-coastguard/integrated/desktop.png, ../login-coastguard/integrated/mobile.png

실제 카카오 서비스와의 인증은 별도 운영 설정을 사용하므로 이번에는 로컬 대체 인증으로 검증했다. 푸시·배포는 진행하지 않았다.

로컬 통합 미리보기 실행: `node scripts/interview-prep-ui-qa.cjs --serve` 후 출력되는 `/interview` 주소 사용. 이 서버는 운영 데이터와 분리된 임시 데이터만 사용한다.
