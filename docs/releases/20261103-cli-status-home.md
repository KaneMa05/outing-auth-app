# 면접반 홈 전체 CLI 상태

면접반 관리자 홈의 운영 현황 바로 아래에 핵심 25제 진단, 경험 질문 생성, 답변 초안 생성 CLI를 각각 표시한다. 기존에는 경험 질문 생성기만 표시되어 다른 CLI의 실행 여부를 홈에서 확인할 수 없었다.

각 항목에서 서버 접속 신호, 작업기별 기능 설정, 유효한 처리 중·대기 건수, 마지막 접속과 최근 완료·실패 시각을 확인한다. 접속 신호 기준은 각각 60초, 45초, 120초다. 답변 초안 작업기는 접속 기록을 분당 한 번만 갱신하므로 별도 기준을 사용한다. 연결 상태는 실제 CLI 진행률이나 생성 성공을 보장하지 않는다.

홈에 들어올 때 한 번 조회하고 이후에는 상태 새로고침을 눌렀을 때만 조회한다. 시간 경과나 탭 복귀만으로 다시 조회하지 않는다. 상태와 마지막 접속 신호는 표시된 확인 시각 기준이다. 작업기 하나의 조회가 실패해도 다른 작업기의 상태는 표시하며, 전체 조회 실패 시 이전 정상 상태를 유지하지 않는다.

`admin_cli_status`는 기존 관리자 세션과 `interview.read` 권한으로 접속·작업 메타데이터만 읽는다. 핵심 25제는 현재 엔진 버전, 답변 초안은 유효한 작업기 등록을 기준으로 한다. 학생 자료, 질문 본문, 토큰, 배정 인증값은 반환하지 않는다. 작업 배정, 생성 요청, DB 스키마·권한 변경, 작업기 재시작은 수행하지 않는다. 기존 상태 API도 유지한다.

검증 명령:

```powershell
node tests/interview-cli-status.test.cjs
node tests/interview-cli-status-db.test.cjs
$env:CHROME_EXECUTABLE='C:/Program Files/Google/Chrome/Application/chrome.exe'
node tests/interview-draft-worker-status-browser.cjs
```

관련 홈 집계, 메뉴 이동, 기존 작업기 상태·생존 신호, 배포 안전성 검사와 격리 빌드도 확인한다. 사용자 최종 확인 전에는 푸시·배포하지 않는다.
