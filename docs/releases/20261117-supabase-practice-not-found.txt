- 기존 RPC가 예외를 발생시키는 상태에서도 API가 동작하므로 API부터 반영 가능.
- 추가 DB 조회, AI 실행, 결과 재생성, 테이블 변경 없음.

- 마이그레이션은 현재 함수에서 해당 get 블록만 교체하며, 예상 정의가 없으면 중단.
- CREATE OR REPLACE로 기존 함수 소유자, 실행 권한, SECURITY INVOKER 설정 보존.
