정식 앱·웹 테스트 승인 계정 전용 연습 기능 운영 반영

승인
- 사용자가 실제 앱과 관리자 페이지 반영을 요청하고, '정식 앱·웹에서도 테스트 승인 계정만 사용' 범위를 명시했다.
- 신규 일반 수강생 공개나 테스트 승인 계정 추가는 하지 않음.

범위
- 기존 mock_status의 서버 검증을 통과한 테스트 승인 계정만 직무/인성 웹 연습을 사용.
- 현재 승인된 계정: 테스트(18120), 마테스. 기존 enabled/mock_test_enabled/이용 기간/면접 패키지/전체 활성화 확인을 유지.
- 기존 회원·적성·스터디카페 등 일반 학생 기능의 소스는 보존. 일반 계정은 메뉴와 직접 아카이브 API/DB 접근 모두 차단.
- 실전 AI 면접의 기존 공개 범위를 확대하거나 유료 분석을 자동 실행하지 않음.

학생 기능
- 분야/지역별 승인 질문, 즐겨찾기, 바로 연습(최대 3문항), 문항 수 설정, 단일 질문 연습, 기기 기록/재생.
- 저장된 답변이 있는 문항만 답변 완료·횟수·최근 연습일 표시. 기기의 계정/모드별 IndexedDB 기록 기준.
- 질문 목록을 시작 직전에 서버에서 다시 확인. 녹음 시작 준비 중 취소/백그라운드/계정 전환 후 늦은 녹음 시작 차단.
- 브라우저 지원에 따라 목표 32kbps AAC/MP4 또는 Opus/WebM/OGG 사용. 원본 Blob은 기기에 유지하고 비공개 저장소에 모든 답변을 전송.
- 전송 완료 전 기기 기록 삭제 차단, 재진입 시 계정별 미전송 답변 자동 재시도. 학생 수동 재전송 버튼/전송 안내 푸터 없음.
- 기존 네이티브 M4A 업로드 프로토콜은 audioMime 미지정 시 audio/mp4 기본값으로 유지.
