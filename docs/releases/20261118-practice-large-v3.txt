관리자 녹음 기록 · Whisper large-v3 전사

기능
- 녹음 전송 완료 시 전사 대기열 생성. 기존 업로드 자료도 최초 적용 시 대기열에 포함.
- PC의 faster-whisper/Whisper large-v3로 한국어 전사. 유료 전사 API 자동 대체 없음.
- 관리자 목록의 전사 개수, 답변별 원본 재생, 문장 구간 재생, 원문·수정본 분리 저장.
- 검수 저장은 interview.write 권한 필요. revision으로 동시 수정 충돌 방지.
- 작업 임대, 주기적 연장, 중단 복구, 최대 3회 자동 재시도 및 수동 재시도.
- 기존 운영의 MP4/WebM/Ogg 형식과 학생 인증·이용 권한 검사 유지.

운영 반영 전 상태
- 원격 main c2e938dd를 기준으로 .tmp/practice-admin-release에 전사 관련 파일만 합친 반영본 준비.
- 기존 베타 브랜치 전체를 배포하지 않는다. 별도의 네이티브 앱/학생 UI 변경을 포함하지 않는다.
- 운영 DB 변경, 푸시, 배포, 운영 대기열 소비는 사용자의 최종 확인 전까지 수행하지 않는다.

최종 확인 후 반영 순서
1. 원격 main 변경 여부를 재확인하고 반영본의 파일 목록·해시를 점검한다.
2. 20261118064306_interview_practice_transcriptions.sql 적용 후 서비스 전용 권한/RLS와 대기 건수를 확인한다.
3. scripts/interview-practice-asr-worker.cjs --import <기존 results.json>으로 검수용 9개를 등록한다.
   실제 저장소 파일의 크기·SHA256을 다시 검증하며, 이미 완료된 자료는 덮어쓰지 않는다.
4. 검증한 운영 main 기반 변경만 커밋·푸시·배포한다.
5. PC에서 scripts/start-practice-asr-worker.ps1 -EnvFile <서버 전용 env 경로>로 실행한다.
   .tmp/practice-asr/config.json의 python/modelDirectory/modelRevision/cudaLibraries를 사용한다.
   PC 실행 파일·모델·설정이 있는 작업 폴더는 작업 중 삭제하지 않는다.
6. 실제 관리자 로그인으로 녹음·전사 조회 및 검수 저장을 확인한다.

운영 특성
- PC가 꺼지면 새 작업은 DB에서 대기한다. 재실행하면 처리 가능한 순서대로 이어간다.
- 모델은 프로그램당 한 번 로드한다. 무음·인식 누락도 사람 검수 대상으로 표시한다.
- 모델/API 전사 요금은 없으나 PC 전력, 저장소, 네트워크 및 기존 사이트 운영비는 별도다.
- 채점·정오답 판정은 이번 변경에 포함하지 않는다.
- 모델과 학생 녹음/전사 결과, 서버 비밀키, PC 전용 도구는 웹 배포 자료에 포함하지 않는다.
