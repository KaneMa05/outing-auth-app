예상 생성 방향: ‘공유 체크리스트’를 선택한 이유나 구체적인 사용 방식.

D-A02 P1 꼬리질문 1
예상 질문: 공유 체크리스트의 진행 상황은 어떻게 확인했나요?
응답자: 매일 저녁 여덟 시에 담당자가 준비 상태를 표시하도록 했습니다. 저는 빈 항목을 확인하고 해당 담당자에게 진행이 어려운 이유를 물었습니다.
예상 다음 근거: ‘매일 저녁 여덟 시’, ‘빈 항목’, ‘어려운 이유’ 중 실제 발화.

D-A03 P1 꼬리질문 2
예상 질문: 진행이 어려운 담당자가 있으면 어떻게 조정했나요?
응답자: 혼자 해결하기 어려운 준비물은 다른 팀원과 나눠 맡도록 제안했습니다. 마감 전에 모두 준비할 수 있는지 담당자에게 다시 확인하고 변경된 역할을 체크리스트에 적었습니다.
확인: 이제 P2로 이동한다. P1 꼬리질문은 정확히 2개이며 세 번째 꼬리질문을 하지 않는다.

D-A04 메인 P2
응답자: 조별 발표에서 제가 통계 자료의 출처를 빠뜨렸습니다. 제 책임을 설명하고 자료를 수정했습니다. 이후 출처 대조표를 만들고 다음 발표 전에 확인하는 절차를 정해 같은 누락을 줄였습니다.
예상 생성 방향: 출처 대조표를 확인하는 구체적인 행동.

D-A05 P2 꼬리질문 1
예상 질문: 출처 대조표의 정확성은 누가 어떻게 확인했나요?
응답자: 두 명이 교차 검토했습니다. 한 명이 슬라이드의 수치와 원문을 비교하고 다른 한 명은 링크와 작성 날짜가 들어 있는지 확인했습니다.
예상 다음 근거: ‘두 명이 교차 검토’, ‘수치와 원문 비교’, ‘링크와 작성 날짜’.

D-A06 P2 꼬리질문 2
예상 질문: 두 사람의 확인 결과가 다르면 어떻게 처리했나요?
응답자: 의견이 다른 수치는 원문을 함께 다시 열어 확인했습니다. 근거를 확인할 수 없는 항목은 발표에서 제외하고 제외한 이유를 팀에 공유했습니다.
확인: 실제 말한 검토 행동을 근거로 질문한다. ‘교수님에게 칭찬받았나요?’처럼 언급하지 않은 결과를 전제하면 실패다.

D-A07 메인 P3
응답자: 행사의 목적과 꼭 필요한 활동부터 확인하겠습니다. 안내 인쇄물은 줄이고 참여자 응대에 인력을 먼저 배치하겠습니다. 담당자에게 조정안을 보고하고 각자의 역할과 시간을 정하겠습니다.
예상 생성 방향: 무엇을 줄이고 무엇을 남기는지 판단한 기준.

D-A08 P3 꼬리질문 1
예상 질문: 인쇄물을 줄여도 안내가 충분한지는 어떻게 확인하겠습니까?
응답자: 안내판이 필요한 위치를 확인하고 참여자가 길을 찾을 수 있는지 사전 동선 점검을 하겠습니다. 안내가 부족한 곳에는 응대 인력을 두고 혼선이 줄어드는지 확인하겠습니다.
예상 다음 근거: ‘사전 동선 점검’, ‘안내가 부족한 곳’, ‘응대 인력’.

D-A09 P3 꼬리질문 2
예상 질문: 동선 점검 후에도 혼선이 예상되면 어떻게 하겠습니까?
응답자: 담당자에게 문제를 보고하고 프로그램 규모와 시간을 다시 조정하겠습니다. 기본 운영을 유지할 수 없다면 원래 계획대로 무리하게 진행하지 않겠습니다.
확인: 종료 후 메인 3개·꼬리질문 6개·답변 9개의 순서와 상위 질문 연결을 확인한다.

E. 실전 모의면접 B — 안내판·오답 기록·프로그램 축소 분기, 총 9문답
A와 같은 메인 질문으로 진행한다. 아래 답변을 사용했을 때 A의 꼬리질문을 그대로 반복하면 실패다.

D-B01 메인 P1
응답자: 동아리 행사에서 처음 온 사람이 장소를 찾기 어렵다는 의견을 들었습니다. 저는 긴 글 대신 그림 안내판을 만들었습니다. 행사장 입구와 갈림길에 설치하고 참가자에게 길을 쉽게 찾았는지 물었습니다.
예상 생성 방향: 그림 안내판을 설계·검증한 방법. 체크리스트나 매일 저녁 여덟 시를 전제하지 않는다.

D-B02 P1 꼬리질문 1
예상 질문: 어떤 그림이 이해하기 쉬운지는 어떻게 확인했나요?
응답자: 행사에 참여하지 않은 친구 세 명에게 안내판 시안을 보여주고 목적지를 찾아보게 했습니다. 두 명이 같은 방향을 헷갈려 해서 화살표 방향과 위치를 바꿨습니다.
예상 다음 근거: ‘친구 세 명’, ‘두 명이 같은 방향을 헷갈려’, ‘화살표 방향과 위치’.

D-B03 P1 꼬리질문 2
예상 질문: 화살표를 바꾼 뒤에는 다시 확인했나요?
응답자: 수정한 안내판으로 같은 경로를 다시 찾아보게 했습니다. 세 명 모두 추가 질문 없이 목적지를 찾았고 그 시안을 행사에 사용했습니다.

D-B04 메인 P2
응답자: 공부 계획을 너무 많이 세워 복습을 끝내지 못한 경험이 있습니다. 양을 늘리는 것보다 틀린 이유를 살펴야겠다고 생각했습니다. 그래서 오답 기록을 만들고 다음 주 계획에 다시 확인할 항목을 넣었습니다.
예상 생성 방향: 오답 기록의 작성·활용. 발표 자료나 통계 출처를 전제하지 않는다.

D-B05 P2 꼬리질문 1
예상 질문: 오답 기록에는 어떤 내용을 남겼나요?
응답자: 틀린 원인을 개념 이해 부족, 문제를 잘못 읽음, 시간 부족으로 나눠 기록했습니다. 원인에 따라 복습 방법을 다르게 정했습니다.
예상 다음 근거: ‘개념 이해 부족’, ‘문제를 잘못 읽음’, ‘시간 부족’, ‘복습 방법’.

D-B06 P2 꼬리질문 2
예상 질문: 원인별로 복습 방법을 어떻게 다르게 정했나요?
응답자: 개념이 부족하면 기본 설명을 다시 정리했고 문제를 잘못 읽었으면 조건에 표시하며 풀었습니다. 시간이 부족한 문제는 제한 시간을 두고 다시 연습했습니다.

D-B07 메인 P3
응답자: 예산과 인력이 부족하면 프로그램 수를 먼저 줄이겠습니다. 행사의 핵심 목적에 가까운 활동 두 개만 남기는 안을 담당자에게 제안하고 필요한 인력과 시간도 함께 설명하겠습니다.
예상 생성 방향: 남길 활동을 고르는 기준과 합의 방법. 인쇄물·안내판을 전제하지 않는다.

D-B08 P3 꼬리질문 1
예상 질문: 어떤 기준으로 두 활동을 선정하겠습니까?
응답자: 행사의 핵심 목적에 얼마나 직접 연결되는지, 현재 인원으로 운영할 수 있는지, 준비 시간을 맞출 수 있는지를 함께 비교하겠습니다. 담당자와 기준을 먼저 합의하겠습니다.
예상 다음 근거: ‘기준을 먼저 합의’, ‘현재 인원’, ‘준비 시간’.

D-B09 P3 꼬리질문 2
예상 질문: 담당자가 원래 프로그램을 모두 유지하자고 하면 어떻게 하겠습니까?
응답자: 필요한 인원과 시간을 표로 정리해 현재 조건으로 어려운 부분을 설명하겠습니다. 인력을 더 지원받거나 시간을 늘리는 방안을 함께 제시하고 승인된 계획에 맞춰 준비하겠습니다.
확인: A와 B는 메인 질문은 같지만 각 꼬리질문의 근거와 내용이 달라야 한다.

F. 음성·흐름·연결 예외 — 별도 실행

F01 답변 중 잠깐 멈춤
[메인 답변 중 1초 정도 멈춘 뒤 이어 말한다.]
응답자: 저는 공유 체크리스트를 만들었습니다. [잠깐 멈춤] 그리고 준비 상태를 행사 전날까지 확인했습니다.
확인: 단순 전사 조각만으로 답변을 완료하거나 꼬리질문 2개를 한꺼번에 말하지 않는다.

F02 질문 반복 요청
응답자: 방금 질문을 다시 한 번 말씀해 주시겠습니까?
확인: 현재 질문을 반복한다. 다음 메인으로 넘어가거나 이 요청을 내용 있는 답변으로 저장해 꼬리질문을 소모하지 않는다.

F03 녹음된 답변 없음
[침묵 상태에서 답변 완료를 누른다.]
확인: 아직 인식된 답변이 없다는 안내를 한다. 자동 모범답안을 생성하지 않는다.

F04 구체적 경험이 기억나지 않음
응답자: 지금은 구체적인 경험이 떠오르지 않습니다. 제가 직접 했다고 말씀드릴 수 있는 내용은 없습니다.
확인: 존재하지 않는 사건·인물·역할을 전제하지 않는다. 최신 발화를 근거로 구체화하거나 확인하는 질문을 만들 수 있는지 본다.

F05 생성 중 답변을 이어 말함
[답변 완료 후 다음 질문이 나오기 전에 말을 추가한다.]
응답자: 추가로 말씀드리면 체크리스트를 만든 사람은 저이고, 현장 확인은 다른 팀원이 맡았습니다.
확인: 이전 답변 버전으로 만든 질문을 폐기한다. 갱신한 답변을 유지하고 사람의 역할을 섞지 않는다.

F06 생성 실패·타임아웃
[로컬 모의 제공자의 응답을 실패시킨다. 운영 API를 반복 호출해 장애를 만들지 않는다.]
확인: 현재 질문·답변을 유지하고 다시 진행하도록 안내한다. 꼬리질문을 생략하거나 정해진 대체 질문을 내면 실패다.

F07 생성 중 종료 / 화면 닫기
[꼬리질문을 준비하는 중 종료 버튼을 누른다.]
확인: 마이크·카메라를 즉시 정리한다. 늦게 도착한 생성 결과가 면접 화면을 다시 열지 않는다.

F08 통신 단절
[별도 실행에서 네트워크를 끊은 뒤 복구한다.]
확인: 종료·저장 상태를 안내하고 중복 유료 세션을 자동 생성하지 않는다. 복구된 기록의 미완료 답변 표시를 확인한다.
