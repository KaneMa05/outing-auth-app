적성 모의고사 성적관리: 과목별 답안지 초기화 (2026-11-18)

상태
- 사용자의 '반영' 승인 후 운영 DB 적용·푸시·배포 완료. 상세: docs/releases/20261118-aptitude-answer-reset-production.txt.
- 기존 작업 폴더의 다른 미커밋 변경을 보존했다. 이 폴더 전체를 배포 입력으로 사용하지 않는다.

동작
- 쓰기 권한이 있는 면접반 관리자의 성적관리 표 맨 오른쪽에 '답안지 초기화' 버튼을 표시한다.
- 학생·회차를 확인하는 창에서 전체 과목 또는 5개 과목 중 원하는 과목을 선택한다.
- 처음에는 아무 과목도 선택되지 않는다. 과목 선택 후 '선택한 과목 초기화'로 실행한다.
- 선택 과목의 답안만 0(미응답)으로 바꾸고 나머지 과목의 답안은 보존한다.
- 제출·채점 정보를 비우고 임시저장 상태로 전환한다. 재제출 전까지 성적·등수 집계에서 제외된다.
- 응시 기간·회차 설정·정답표는 변경하지 않는다. 응시 기간 밖에서는 재입력·재제출할 수 없다는 안내를 표시한다.
- 초기화 이전·이후 답안과 선택 과목, 관리자 ID는 기존 ip_aptitude_audit에 기록한다.
- 읽기 전용 관리자는 기존 조회·검색·CSV 기능을 이용한다. 미제출자와 이전 기수 성적은 초기화 대상에서 제외한다.

동시 사용 보호
- 학생 저장·제출과 같은 회차 잠금 순서를 사용하고, 성적 조회 당시 attemptRevision을 검사한다.
- 학생이나 다른 관리자가 먼저 변경한 경우 409로 거절하고 최신 성적을 다시 조회한다.
- 초기화 시 revision을 증가시켜 기존 기기의 오래된 답안·임시 백업이 되살아나지 않도록 한다.
- 응답을 확인할 수 없는 경우 같은 초기화를 자동 반복하지 않고 최신 상태를 확인하도록 안내한다.
