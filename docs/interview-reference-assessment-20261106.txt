면접 결과 자동 표시·공개 예시답변 기준 연습 판정

사용자 확정
- 공개 문항의 기존 예시답변으로 ○·△·× 연습 판정 복원.
- 결과 화면에서 진행 상태와 완료된 판정을 즉시 자동 갱신. 정상 처리에 확인 버튼 불필요.
- 녹음은 또렷하고 글만 잘못 인식된다고 사용자가 확인.
- 100명 규모로 문항별 분석 한도를 넉넉하게 요청. 적용안: 1인 100답변/일, 전체 10,000답변/일(KST).

확인한 현황
- 운영 최근 3답변 중 2개는 transcript_disagreement로 review_required, 1개는 일반 피드백.
- 검토 완료 공식 채점 기준 0개, 기존 초안 2,519개.
- 공개 직무 문항 1,456개 중 1,455개에 원문 해설 20자 이상 존재.
- 기존 서버는 원문 예시답변을 받지 않고 일반 말하기 피드백만 생성. 앱은 서버의 assessment를 전달하지 않았음.
- 결과는 5초마다 확인하고 네트워크 실패 후 수동 확인 버튼에 의존.
- 현재 전사 모델 gpt-transcribe는 한국어 언어 힌트를 사용하나 첫 패스에 녹음 문맥이 없었음.
- 실제 최신 WAV 3개: 9.0초/-32.7dBFS, 5.7초/-32.4dBFS, 2.7초/-41.2dBFS. 16kHz PCM, 파형 클리핑 없음.
- 로컬 Whisper와의 비교에서도 일부 단어 인식 차이 확인. 이 결과만으로 어느 전사가 정확한지 확정하지 않음.

수정
- 제출 시점의 서버 원문 해설과 출처 ID를 비공개 질문 스냅샷에 고정.
- 전체 예시답변을 최대 3개 핵심 항목으로 나누어 의미 충족 여부 평가. 외부 새 정답을 만들지 않음.
- O/partial은 실제 답변의 연속 인용 필수. 누락·중복·위조 인용·인식 불확실은 uncertain으로 보류.
- 결과는 ○ 전체 충족, △ 일부 충족, × 충족 없음, — 판정 보류. 공식 grade/score는 null 유지.
- 일반 피드백과 기준별 판정을 한 번의 분석 요청에서 생성.
- 두 독립 전사는 병렬 처리. 기존 엄격한 인식 일치 확인은 유지.
- 한국어 녹음 문맥을 전사에 제공. 모델에 맞춰 languages[] 또는 language 필드를 사용.
- 원본을 바꾸지 않는 최대 4배/피크 0.9 이내의 제한적 선형 음량 보정. 무음·클리핑은 증폭하지 않음.
- 모델·원본 해시·기준 해시·보정 수치를 비공개 감사 정보에 저장.
- iOS가 assessment를 저장하고 기존 ○·△·× 판정 UI로 전달.
- 결과 진입 시 자동 조회/업로드 복구, 2초 간격 갱신, 진행 표시와 구체적 보류 사유.
- 정상 결과에서 분석 확인 버튼 제거. 연결 실패인 경우에만 연결 다시 확인 제공.
- 20문항을 고정 10분 안에 강제 종료하지 않도록 직무 연습은 실제 문항 수에 맞춰 시간 상한 확장.
- 기존 로그인·계정 격리·일반 학생 UI·공식 채점·질문 음성·기록 원본은 보존.

검증
- 서버 회귀 30개, 새 한국어 요청·전체 56마이그레이션+5시드 검증 5개, 최신 API/용량 검사 11개 통과.
- iOS 정책 검사 22개, 실제 결과 UI의 ○·△·×와 진행 표시 검사 통과.
- 유료 전사 A/B 정확도 검증은 미실행. 전체 운영 비밀값 다운로드가 자동 보안 검토에서 차단됨.
- 운영 후속 SQL 적용도 별도 최종 배포 확인이 없다는 이유로 자동 승인 검토에서 차단됨.
- 사용자 최종 승인 후 SQL 20261106083856·20261106084214 운영 적용. 기존 완료 기록은 자동 유료 재채점하지 않음.

추가 요청: 결과에서 예시답변 학습
- 직무·인성 결과에서 서버 원문 예시답변을 펼쳐 보기로 제공.
- 분석 진행 중에도 조회·기기 저장 가능하며, 예시답변 조회는 AI를 호출하지 않음.
- 기존 기록도 현재 공개 문항과 원문이 일치할 때 원문 해설을 조회. 다른 계정·다른 문항으로 확대하지 않음.
- 인성 예시답변을 직무 지식 ○·△·× 기준으로 오용하지 않음.
- 추가 DB 변경도 사용자 별도 최종 승인 완료, 운영 적용 완료.
- 최종 서버 회귀 35개, 전체 57마이그레이션+5시드, iOS 판정·예시답변 UI 검사 통과.
