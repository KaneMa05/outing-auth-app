관리자 사용 방법
면접 관리의 학생·이용 관리에서 이름으로 계정을 검색하고 등록·수정을 연다.
모의면접 테스트 허용을 체크해 저장한다. 이용 허용과 유효한 수강 기간도 필요하다.
사용자는 해당 카카오 계정으로 앱에 로그인한 뒤 새로고침한다.
허용 계정만 전공·인성·실전 모의면접 메뉴가 표시된다.
체크 해제는 기존 로그인·네이티브 토큰에도 다음 요청부터 적용된다.
모든 기존 계정의 기본값은 비허용이다. 일반 면접 준비 자료에는 영향을 주지 않는다.
전체 공개는 이번 변경에 포함되지 않는다. 추후 별도 공개 정책으로 전환한다.

운영 반영 순서 (아직 실행하지 않음)
1. 사용자 최종 확인 후 20261030140517_interview_mock_test_access.sql 적용.
2. 관리자/학생 웹 UI, API, WebSocket 배포. 캐시 버전 변경 포함.
3. 아이폰 앱 재설치: 일반 Debug 실행에 있던 로그인 없는 연습 버튼 제거.
4. 관리자에서 실제 테스트 계정 허용 후 허용/비허용 두 계정으로 확인.

범위와 제한
이 권한은 운영 사이트의 계정 기반 전공·인성·실전 API와 네이티브 handoff에 적용한다.
Mac 로컬 AI 브리지 및 명시적인 개발자 실행 인자의 독립 연습 화면은 운영 기능으로 배포하지 않는다.
기존 로컬 연습 화면/모델을 운영 계정 기반 서비스로 옮기는 작업은 이 접근 제어 변경과 별도다.
서비스 활성화 환경변수와 AI 서버 준비 상태가 충족되어야 실제 모의면접을 실행할 수 있다.
테스트 계정 지정만으로 AI 제공자나 유료 호출을 새로 활성화하지 않는다.
