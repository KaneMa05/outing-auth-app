# 기본 이력 저장 및 입력 항목 정리

- 기본 이력과 인생그래프의 간편 편집 화면에서 `저장`은 `life_save`의 `draft` 저장을 실행한다. 종전에는 `submitted`를 보내 보이지 않는 인생그래프까지 완성해야 저장할 수 있었다. 전체 제출을 제공하는 기존 상세 화면은 유지한다.
- 기본 이력의 `성과·역량`과 중복 `소속 이력` 입력 영역을 제거한다. 기존 저장 내용은 삭제하지 않는다.
- 자격·어학의 구분에 `어학`, `외국어`, `언어`가 포함되면 발급기관 입력란을 숨긴다. 기본 이력 완성도 검사에서도 해당 어학의 발급기관을 요구하지 않는다. 기존 기관 값은 보존한다.
- `성과·역량`은 새 자료에서 없어도 저장되며, 기존 값이 있으면 기존 형식 검증을 유지한다. 소속 이력은 전체 제출 및 AI 자료 완성도 조건에서 제외한다.

## 검증

격리 Postgres의 이력 저장/API, 추가 질문, AI 자료 완성도 테스트와 실제 Chrome의 저장 실패 후 재시도, 불완전한 이력 저장, 재조회, 기존 소속 기록 보존, 어학 필드 숨김을 검증한다. 운영 학생 데이터는 변경하지 않는다.

## 반영 순서

사용자 배포 승인 후 `20261024130513_simplify_basic_history_save.sql`을 먼저 적용하고 프런트엔드를 배포한다. 현재 UI에 필요한 7개 기본 이력 필드와 새 검증 규칙을 함께 배포해야 한다. 같은 작업 폴더의 다른 미배포 변경이 섞이지 않도록 최신 운영 파일을 기준으로 배포 묶음을 구성한다.
