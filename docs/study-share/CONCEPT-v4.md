# 일간·주간·월간 플래너 인증

사용자 요청에 따라 일간·주간·월간을 모두 기획 범위에 포함한다. 적용 수강생 유형은 미확정이다.

## 공통 화면

인증 화면 상단에서 일간 / 주간 / 월간 선택 → 날짜 또는 기간 선택 → 플래너 이미지 미리보기 → 공개 항목·스타일·회고 문구 설정 → 이미지 저장 / 공유.

모눈 종이, 손글씨, 파스텔 형광펜, 완료 체크의 디자인을 공통으로 사용한다. 앱의 기록 데이터를 템플릿에 자동 반영하는 기능으로 제안한다.

## 기간별 구성

| 기간 | 중심 내용 | 요약 지표 | 회고 |
| --- | --- | --- | --- |
| 일간 | 과목별 할 일과 완료 체크 | 하루 순공시간, 할 일 달성률 | 오늘의 한 줄 |
| 주간 | 월~일 공부시간과 완료/계획 수 | 주간 순공시간 합계, 주간 할 일 달성률 | 이번 주 돌아보기 |
| 월간 | 공부한 날을 색칠한 달력 | 월간 순공시간 합계, 월간 할 일 달성률, 공부한 날 수 | 한 달 돌아보기 |

## 집계 원칙

- 할 일 달성률 = 해당 기간 완료 수 / 해당 기간 전체 할 일 수 × 100. 일별 퍼센트의 단순 평균으로 계산하지 않는다.
- 전체 할 일이 0개면 달성률을 생략한다.
- 달력의 색칠은 공부 기록이 있는 날을 의미하며, 할 일 달성률과 별개다.
- 이번 주·이번 달이 진행 중이면 ‘9월 15일까지’ 같은 집계 시점을 함께 표시하고, 지표는 해당 시점까지의 학습일에 배정된 할 일과 저장된 공부 기록을 기준으로 제안한다. 미래 날짜는 미도래 상태로 구분한다.
- 완료된 과거 기간은 해당 기간 전체 기록으로 집계한다. 학습일 경계는 구현 시 기존 앱과 맞춘다.
- 할 일 내용 공개와 회고 문구는 사용자가 선택하며, 미리보기와 출력에 동일하게 반영한다.

## 예시 데이터 검토

- 일간: 9월 15일 7시간 30분, 6/8 = 75%.
- 주간: 9월 14~20일 42시간 30분, 34/40 = 85%. 화요일 기록은 일간 예시와 일치한다.
- 월간: 9월 156시간, 120/150 = 80%, 공부한 날 26일. 달력은 2026년 9월 배치이며 6·13·20·27일을 제외한 26일을 색칠한다.
- 모든 수치는 디자인 설명용 가상 데이터이며 주간·월간은 기간 종료 후를 가정한 예시다.
