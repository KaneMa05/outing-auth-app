# 공부 기록 공유 구현

## 반영 내용

- 기존 타이머 접근 범위를 유지하며 통계 제목 오른쪽에 `기록 공유` 버튼을 표시한다.
- 선택한 일간·주간·월간 기록을 미리보기로 열고, 같은 PNG 파일을 이미지 저장 또는 기기 공유 메뉴에 전달한다.
- 일간 집중 횟수 문구를 삭제하고 선택일을 단일 날짜로 표시한다.
- 주간 막대와 월간 달력의 시간은 `7:30`, `12:05`처럼 표시하며 `공부시간 (시간:분)` 안내를 추가한다.
- 기존 통계의 선택 기간과 스크롤 위치를 유지한다.
- 공유 이미지에 이름, 수험번호, 기기 인증정보를 포함하지 않는다.
- 서버 확인이 안 된 임시 기록이나 공부시간이 없는 기간은 공유를 비활성화한다.
- 할 일 달성률은 선택 기간의 오늘까지 완료 수 / 전체 수로 계산한다. 할 일이 없으면 생략하고, 조회 실패 시 안내 후 공부시간을 공유한다.
- 파일 공유를 지원하지 않는 기기는 이미지 저장 후 원하는 앱에서 공유하도록 안내한다. 공유 취소는 미리보기를 유지한다.
- API·DB 스키마를 변경하지 않고 기존 통계 및 월별 할 일 요약 API를 사용한다.

## 검증

- `npm.cmd test`: 전체 통과. 신규 모델 검증, 기간별 달성률, 날짜 표시, 공유 버튼 상태 테스트 포함.
- `node --check app.js`, `node --check study-record-share.js`, `git diff --check`: 통과.
- 격리된 임시 폴더에서 `npm.cmd run build`: 통과. 개발용 빈 설정 생성 경로를 확인했으며 실제 로컬 설정 파일과 운영 환경은 변경하지 않았다.
- `node scripts/study-record-share-qa.cjs`: Chrome에서 실제 렌더 함수와 예시 데이터로 검증. 운영 API를 호출하지 않는다.
  - 320px·390px 화면에서 주간·월간 시간 표시가 잘리지 않음. `12:05`, `24:00` 포함.
  - 일간 날짜 및 불필요한 문구 제거, 세 기간의 1080px PNG 생성 확인.
  - PNG 다운로드, 미리보기 종료 시 스크롤 유지 확인.
  - 기기 공유 API를 모의 호출하여 파일 전달, 취소 및 오류 처리를 검증.
  - 할 일 조회 실패, 생성 중 닫기, 타이머 모드 및 오프라인 수강생 접근 제한 확인.

실제 모바일 OS의 공유 메뉴 및 인스타그램 게시 완료까지의 기기 검증은 수행하지 않았다. 2026-09-17 공부 인증과 등록 수강생 전용 OX를 함께 운영 배포했다. [배포 기록](../releases/20260917-study-share-ox-members.md). Git 푸시는 하지 않았다.
