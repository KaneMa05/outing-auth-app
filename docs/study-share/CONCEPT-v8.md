# 기록 공유 버튼을 통계 제목 오른쪽으로 이동

2026-09-16 사용자 요청 반영. 기존 디자인과 집계 원칙은 CONCEPT-v7.md를 유지하며 아래 위치 변경을 우선 적용한다.

- ‘타이머 통계’ 제목 오른쪽에 작은 테두리 ‘기록 공유’ 버튼을 배치한다.
- 통계 탭에서만 노출하는 기능으로 기획한다. 시안은 통계 탭 상태를 표시한다.
- 일간·주간·월간 모두 상단의 같은 위치에서 선택 기간을 공유한다.
- 기존 과목별 통계 아래에 있던 하단 진입 버튼은 제거한다.
- 공유 미리보기의 이미지 저장·공유하기 버튼과 뒤로가기 동작은 유지한다.
- 기존 통계의 그래프·카드·글꼴·색상을 유지한다.
- 일간 시간 아래의 공부 횟수 문구는 표시하지 않는다. 통계와 공유 미리보기에서 해당 줄을 제거해 여백도 함께 정리한다. 기록이 없는 상태의 안내는 유지한다.
- 일간 요약 카드의 날짜는 ‘2026년 9월 15일’처럼 하루만 표시한다. 주간·월간 요약의 기간 표시는 유지한다. 통계와 공유 미리보기에 같은 날짜 규칙을 적용한다.
- 주간 그래프 위 시간은 ‘7:30’처럼 시간:분으로 표시하고 ‘공부시간 (시간:분)’ 단위를 안내한다. 한 시간 단위도 ‘6:00’으로 통일해 분이 말줄임되지 않게 한다. 통계와 공유 미리보기에 동일하게 적용한다.
- 월간 달력의 날짜별 공부시간도 ‘7:30’, ‘6:00’처럼 시간:분 형식으로 통일한다. 단위를 달력 상단에 안내하며 통계와 공유 미리보기 모두 좁은 화면에서 분까지 표시한다. 날짜별 공부량에 따른 기존 색상은 유지한다.
