# 타이머 → 통계 → 기록 공유

## 사용자 의도

러닝 기록을 공유하는 경험처럼 공부 기록도 자연스럽게 확인하고 공유하고 싶다는 요청. 앞선 플래너 감성과 일간·주간·월간 범위를 유지하면서 실제 앱 이용 흐름을 구체화한다.

사용자가 선택한 진입점은 **타이머 → 통계 하단의 ‘기록 공유’**다. 공부한 기록을 확인한 뒤 같은 기간의 기록을 한 장으로 공유하는 흐름으로 정리한다.

## 기존 앱에서 확인한 연결 지점

app.js의 과목 타이머에는 타이머/통계 전환과 통계의 일간/주간/월간 선택이 있다. 기존 통계 콘텐츠 아래에 공유 진입 버튼을 추가하는 방향이다. 수강생 유형별 노출 범위는 구현 전 확정한다.

## 선택한 흐름

1. **통계에서 기록 확인**: 타이머의 통계 탭에서 일간·주간·월간과 날짜/기간을 선택한다.
2. **기록 공유**: 통계 콘텐츠 하단에 가로형 ‘기록 공유’ 버튼을 둔다. 페이지 콘텐츠의 마지막에 배치하고 하단 내비게이션과 겹치지 않게 여백을 둔다. 고정 배치 여부를 별도 요구로 해석하지 않는다.
3. **공유 미리보기**: 보고 있던 기간 유형과 날짜 범위가 그대로 넘어가며 기본 카드가 완성된 상태로 열린다. 예를 들어 월간 9월 통계에서 누르면 9월 월간 카드가 나온다. 기간을 다시 선택하거나 문구를 입력할 필요 없이 바로 공유할 수 있다. 기록/플래너/사진 스타일과 표시 항목은 선택적으로 변경한다.
4. **이미지 저장 또는 공유**: 저장하거나 기기 공유 메뉴에서 공유할 앱을 선택한다. 취소하면 미리보기로 돌아오고 기록과 선택 설정은 유지한다. 게시 완료 여부를 확인할 수 없으면 게시 완료 문구를 표시하지 않는다.
5. **통계로 복귀**: 미리보기에서 뒤로 가면 기존 기간과 통계 스크롤 위치를 유지한다.

이전 시안의 과목 종료 후 인증 안내와 ‘오늘 기록 보기’ 추가 동선은 이번 기획에서 제외한다. 공유 진입점은 통계 하단으로 정리한다.

## 공부를 시각적으로 표현하는 방식

일간의 중심 그래픽으로 **공부 타임라인**을 제안한다. 실제 공부 구간은 과목별 색으로, 휴식 구간은 비워서 하루 동안 공부한 흐름을 보여준다. 기록을 한눈에 알아보게 만드는 공통 시각 요소로 사용한다.

세부 시작·종료 구간을 복원할 수 있는 데이터가 있는지는 이번 UI 확인만으로 확정하지 않았다. 구현 전 데이터 가용성을 확인해야 한다. 총시간만 존재하면 과목별 누적시간 막대를 사용하고 실제 시간대처럼 표현하지 않는다. 시안의 구간 폭은 디자인 예시이며 구현 시 확정 기록에 비례해 그린다.

## 일간·주간·월간

| 기간 | 주요 그래픽 | 요약 |
| --- | --- | --- |
| 일간 | 공부 구간 타임라인 | 순공시간, 할 일 달성률, 과목별 시간 |
| 주간 | 월~일 공부시간 막대 | 주간 합계, 완료/계획 수, 한 주 회고 |
| 월간 | 공부한 날 달력 | 월간 합계, 완료/계획 수, 공부한 날 수 |

주간·월간도 같은 ‘기록 확인 → 공유 미리보기’ 흐름을 사용한다. 공유를 위해 기간을 매번 새로 고르지 않도록 보고 있던 기간을 그대로 가져온다. 진행 중인 주·월은 집계 시점을 표시한다. 달성률은 기간 내 완료 수 / 계획 수로 계산하고 계획이 없으면 생략한다.

## 스타일

- **기록(기본)**: 시간·공부 흐름·달성률 중심. 얇은 모눈과 작은 손글씨 문구로 플래너 감성을 살린다.
- **플래너**: 앞서 그린 과목별 할 일과 완료 체크 중심. 주간에는 요일별 정리, 월간에는 달력으로 확장한다.
- **사진(선택)**: 사용자가 고른 책상·책·노트 사진 위에 같은 기록을 읽기 쉽게 배치한다. 사진 없이도 기본 공유가 완성된다.

표시 항목 설정은 한 곳에 접어 두고 마지막 선택을 기억한다. 닉네임과 구체적인 할 일 내용은 기본 숨김을 제안한다. 회고 한 줄은 선택 입력이다. 브랜드는 작게 둔다. 저장 미리보기와 출력은 같은 데이터와 레이아웃을 쓴다.

## 기존 사용 흐름 확인 사항

- 통계에 표시한 기간과 공유 이미지의 기간·확정 기록을 일치시킨다.
- 기록을 불러오는 중이거나 불러오기에 실패했으면 공유용 데이터가 준비된 뒤 카드 생성을 허용한다.
- 공유 화면 진입이 측정 중인 타이머를 종료시키지 않게 한다. 외부 공유 앱 이동 시 기존 자동 일시정지 정책과 복귀 동작을 검증한다.
- 날짜 기준은 기존 앱의 학습일 경계에 맞춘다. 화면상 현재 기록 시점과 출력 시점을 맞춘다.
- 기존 통계 콘텐츠 하단에서 연결하며 기존 하단 내비게이션과 겹치지 않게 한다.
