# 플래너 인증 스타일 · v3

사용자 피드백: 인스타에서 플래너를 인증하는 것 같은 표현을 원함.

## 디자인

모눈 종이, 손글씨, 파스텔 형광펜, 완료 체크를 활용해 하루 플래너를 찍은 듯한 공유 이미지로 구성한다. 과목별 할 일 목록을 중심에 두고 상단에는 순공시간과 할 일 달성률, 하단에는 오늘의 한 줄을 배치한다. 브랜드는 하단에 작게 표시한다.

## 데이터 및 기능 제안

- 실제 플래너의 과목·할 일·완료 여부와 공부 기록을 카드에 자동 반영한다.
- 예시: 7시간 30분, 할 일 8개 중 6개 완료(75%).
- 할 일 내용 공개는 미리보기에서 사용자가 선택할 수 있게 한다. 일부를 숨겨도 달성률은 오늘 전체 할 일 기준임을 유지한다.
- 오늘의 한 줄과 종이·형광펜 스타일은 사용자가 선택하거나 수정한다.
- 초기 출력은 4:5 세로형 구성으로 제안하며, 긴 할 일은 줄바꿈하고 항목이 많으면 여러 장으로 나누는 방식을 검토한다.
- 숫자와 할 일은 예시이며 적용 수강생 범위는 미확정이다.
