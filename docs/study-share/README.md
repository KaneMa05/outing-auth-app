# 공부 기록 공유 시안

최신 디자인 방향은 [CONCEPT-v8.md](CONCEPT-v8.md)를 기준으로 한다.

**타이머 → 통계 → 제목 오른쪽 기록 공유 → 선택 기간의 미리보기 → 이미지 저장 / 공유**

기존 통계 UI를 유지하며 일간·주간·월간을 모두 지원하는 기획이다. 이전 버전의 꾸밈과 추가 진입점은 과거 검토 자료다.

- [클릭 가능한 시안](existing-stats-preview-v8.html)
- [통계 화면 비교](study-share-existing-stats-v8.png)
- [공유 미리보기 비교](study-share-previews-v8.png)

시안은 예시 데이터다. 실제 앱에는 v8 방향을 기준으로 기록 공유, PNG 저장, 기기 공유 기능을 로컬 구현했다. 푸시·배포는 진행하지 않았다.

- [구현 범위 및 검증 결과](IMPLEMENTATION.md)
