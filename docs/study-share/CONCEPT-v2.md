# 공부 인증 SNS 공유 · 검토 시안

## 방향

오늘 공부한 성과를 한 장으로 표현한다. 순공시간을 가장 크게, 할 일 달성률을 두 번째로 보여준다. 모든 숫자는 예시다. 적용할 수강생 유형은 이번 요청에서 지정되지 않았으므로 이 문서는 공통 디자인 제안이며 적용 범위는 미확정이다.

## 화면과 흐름

오늘 기록의 ‘공부 인증하기’ → 인증 카드 미리보기 → 스타일·공개 항목 선택 → 이미지 저장 또는 공유.

- 앱 인증 화면: 미리보기, 블루·화이트 스타일 선택, 닉네임 표시와 과목별 시간 표시 옵션, 저장·공유 버튼.
- 공유 이미지: 날짜, 순공시간, 할 일 달성률, 완료 수, 선택한 과목별 시간, 짧은 응원 문구, 작은 브랜드 표시.
- 닉네임은 기본 숨김으로 제안한다.
- 시간과 달성률은 기록에서 가져온 값으로 표시하고, 카드에서 직접 수정하는 항목으로 두지 않는다.

## 지표 정의 제안

- 순공시간: 휴식을 제외한 오늘의 공부 기록 합계.
- 할 일 달성률: 오늘 완료한 할 일 수 ÷ 오늘 전체 할 일 수 × 100. 예: 6/8 = 75%.
- 시간 목표 달성률을 추가할 경우 ‘공부시간 목표 달성률’로 별도 표시해 할 일 완료율과 구분한다.
- 할 일이 없으면 달성률은 생략한다. 미완료가 있어도 공유할 수 있다.
- 각 수강생 유형에 실제로 존재하는 지표와 학습일 기준은 구현 전에 확인한다.

## 첫 버전 제안

세로 공유 이미지, 두 가지 스타일, 닉네임·과목 표시 설정, 이미지 저장과 기기 공유 메뉴를 포함한다. SNS 게시 위치는 사용자가 선택한다. 사진 배경·캐릭터·연속 공부일은 후속 확장 후보로 둔다.
