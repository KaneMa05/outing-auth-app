# 스터디카페 통계 진입·공유 기간 선택 누락 수정

2026-09-17: 운영 배포에는 타이머 내부 통계·기록 공유만 포함되었고,
스터디카페의 통계 바로가기는 `cafe-stats-local.js` 시안에만 존재했다.

- 실제 스터디카페의 순공 랭킹 옆에 작은 `통계` 버튼을 추가했다.
- 개인 스터디룸에서도 같은 통계 바로가기를 제공한다.
- 좌석 착석 여부와 관계없이 이용 가능하며, 현재 공부일의 일간 통계로 바로 이동한다.
- 기존 타이머 접근 조건을 유지하고 좌석·타이머 상태를 변경하지 않는다.
- 통계 화면에서도 하단 스터디카페 탭 선택이 유지되며 기존 기록 공유를 이용한다.

기록 공유의 기간 선택도 로컬 시안에만 존재했던 누락을 수정했다.

- 공유 화면 상단에 일간·주간·월간과 이전·다음 기간 선택을 추가했다.
- 선택한 기간을 기존 통계 API로 조회해 공유 PNG를 다시 생성한다.
- 사진 인증의 사진·비율과 기간별 표시 항목 설정을 유지한다.
- 조회 중·기록 없음·조회 실패 시 이전 이미지를 숨기고 저장·공유를 비활성화한다.
- 빠른 기간 전환 시 오래된 응답을 무시하며 실패 시 다시 불러오기를 제공한다.
- 공유 화면을 닫으면 기존 통계 화면의 기간·날짜·스크롤 위치를 유지한다.
- 앱·스타일·공유 모듈의 캐시 버전을 `20260917-study-share-fixes`로 맞췄다.

검증: 로컬 실제 앱과 예시 데이터로 320px·390px, 일반룸·랭킹룸,
착석·미착석, 개인 스터디룸을 확인했다. 통계로 직접 이동하고 공유 버튼이
표시되며 좌석 상태가 보존되는 것을 확인했다. 버튼 추가로 인한 가로 넘침은 없다.
운영 기준 버전에 수정분을 반영한 별도 검증 폴더에서 전체 npm test와
격리된 production 모드 빌드가 통과했다. 실제 서비스/API는 변경하지 않았다.

공유 화면 브라우저 검증: 320px·390px에서 상단 기간·날짜 버튼과 하단 저장·공유
버튼 표시, 일간·주간·월간 PNG, 빠른 전환의 응답 순서 역전, 로딩·실패·빈 기록,
재시도, 사진·3:4 비율 유지, 미래 기간 차단, 조회 중 닫기를 확인했다.
실제 PNG 다운로드와 모의 네이티브 공유·취소·실패도 통과했다.
날짜 단위 테스트는 주 경계·연도 경계·윤년·월말 이동을 포함한다.

2026-09-17 사용자가 지금까지의 사항에 대해 커밋·푸시·배포를 승인했다.
기존 운영 릴리스의 전체 이력과 이 수정분을 main에 반영하고 연결된 Vercel
자동 배포로 적용한다. OX 학습 사용 설정과 등록 수강생 목록은 변경하지 않는다.
