# 기존 통계 화면을 유지하는 기록 공유

## 최신 방향

사용자 피드백: 이전 시안은 너무 꾸며져 있으므로 기존 화면에서 크게 벗어나지 않게 한다.

기존 타이머 통계의 배치·글꼴·색상·카드·그래프를 사용하고, 통계 콘텐츠 마지막에 ‘기록 공유’를 추가한다. 공유 미리보기에도 같은 통계 컴포넌트를 사용한다. 손글씨, 모눈 종이, 응원 문구, 별도 스타일 선택은 최신 시안에 포함하지 않는다.

## 일간·주간·월간

- 일간: 기존 순공시간, 집중 횟수, 최대 집중시간, 시작·종료시간.
- 주간: 기존 월~일 막대그래프와 날짜·공부시간 표시.
- 월간: 기존 일요일 시작 달력과 공부시간별 파란색 농도, 날짜별 공부시간.
- 공통: 기존 총 순공시간 / 공부한 날 / 하루 평균 / 최고 기록의 요약과 과목별 순공시간.

기존 통계의 이 순서를 유지한 후 하단 버튼을 추가한다. 공유 미리보기는 탭과 날짜 이동 버튼을 덜어내고 브랜드·기간·통계 기록을 담는다. 화면 하단에서 이미지 저장 또는 공유를 선택한다. 통계의 선택 기간을 그대로 전달하고 뒤로 가면 해당 통계로 복귀한다.

원래 요청한 할 일 달성률은 공유 카드 하단의 작은 한 줄로 제안한다. 기존 통계 화면의 요약 지표를 변경하지 않는다. 이 항목은 현재 통계 데이터와 별도로 해당 기간 플래너의 완료/계획 수를 연결해야 하는 추가 기능이다. 시안에서는 가상 데이터를 사용했다.

## 제작 방식과 검토

- app.js의 실제 통계 렌더 함수와 shared.js의 DOM 도우미, styles.css와 프로젝트 글꼴을 사용한 독립 HTML 시안이다.
- 앱 본체나 API를 실행하지 않고 예시 데이터로 렌더링했다. 운영 데이터 접근·수정은 없다.
- 코드에 존재하는 student-online-mode의 타이머 스타일을 사용한 디자인 참조이며 적용 수강생 범위는 별도 미확정이다.
- 화면 외곽과 비교용 배치는 검토용이다. 실제 앱 공통 헤더·하단 내비게이션은 이번 비교 이미지에서 생략했다.
- 브라우저에서 세 기간의 렌더링을 확인하고 기간 합계와 과목 합계, 미리보기/뒤로가기 동작을 확인했다.
- 기존 컴포넌트의 긴 시간 문자열 말줄임도 반영되어 있다. 실제 공유 이미지 구현 시 출력 규격에 맞춰 숫자가 생략되지 않도록 조정해야 한다.
- 월간 예시는 일간·주간과 날짜별 시간을 맞춘 156시간 / 27일이며, 주간 42시간 30분 / 7일, 일간 7시간 30분 / 1일과 일치한다.
