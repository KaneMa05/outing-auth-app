# 주간·월간 화면 상세 시안

사용자가 선택한 진입점 ‘타이머 → 통계 하단 기록 공유’를 유지한다. 주간과 월간 각각 통계 화면과 공유 미리보기를 구체적으로 표현한다. 이번 작업은 시안과 기획 문서이며 앱 코드는 변경하지 않는다.

## 주간

- 상단: 타이머/통계 전환, 일간/주간/월간 선택, 주간 날짜 이동.
- 요약: 주간 순공시간 합계, 전체 할 일 중 완료 비율과 완료/계획 수.
- 중심 그래픽: 월~일 공부시간을 막대그래프로 표시한다. 실제 값에 비례해 높이를 정하며 미도래 날짜는 0시간 기록과 구분한다.
- 상세: 요일별 완료/계획 표와 선택 입력인 한 주 회고.
- 통계 콘텐츠 마지막: ‘기록 공유’ 버튼.
- 공유 카드: 선택한 날짜 범위, 주간 시간 합계, 7일 막대그래프, 달성률과 회고를 담는다. 구체적인 할 일 내용은 기본 카드에 포함하지 않는다.
- 예시: 2026년 9월 14~20일, 42시간 30분, 34/40 = 85%. 요일별 시간 합계와 완료/계획 합계를 확인했다.

## 월간

- 상단: 같은 탭 구성과 월 이동.
- 요약: 월간 누적 순공시간과 할 일 완료율.
- 중심 그래픽: 해당 월의 실제 요일 배치에 맞춘 공부 달력. 공부 기록이 있는 날짜를 색칠한다.
- 상세: 공부한 날 수, 과목별 누적시간 막대, 선택 입력인 한 달 회고.
- 통계 콘텐츠 마지막: ‘기록 공유’ 버튼.
- 공유 카드: 선택한 월, 누적 순공시간, 공부 달력, 공부일 수, 할 일 달성률과 회고.
- 예시: 2026년 9월, 156시간, 120/150 = 80%, 공부한 날 26/30일. 과목별 62+54+40 = 156시간. 달력은 9월 1일 화요일, 30일 수요일이며 6·13·20·27일을 제외한 날짜를 색칠한다.
- 공부일 수와 할 일 달성률은 서로 다른 지표로 명확하게 구분한다.

## 공통 동작

보고 있던 기간을 공유 미리보기로 그대로 전달한다. 기록 스타일을 기본으로 두고 플래너·사진과 표시 항목은 선택 변경이다. 이미지 저장과 기기 공유 메뉴를 제공한다. 뒤로 가면 기존 통계의 기간과 스크롤 위치로 복귀한다. 진행 중인 주·월에는 집계 시점을 표시하며, 시안 수치는 기간 종료 후를 가정한 가상 데이터다.

기간별 카드의 숫자·그래프는 같은 확정 기록으로 구성한다. 총 계획이 없으면 달성률을 생략한다. 글자 길이·그래프 비율·접근성·스크롤과 실제 출력 규격은 구현 단계에서 검증한다. 현재 그림은 화면 방향 검토용이다.
