# 오늘의 공부 인증 · SNS 공유 기획

2026-09-15 · 인터넷 수강생(`lecture`) 대상 · 초기 디자인 시안

## 방향

**오늘의 공부를, 한 장으로.** 오늘 쌓은 순공시간을 가장 크게 보여주고, 할 일 달성률과 과목별 기록을 함께 담는다. 기록이 적거나 목표를 모두 채우지 못한 날에도 공유할 수 있다.

사용자가 1차 적용 대상으로 인터넷 수강생을 선택했다. 기존 홈·플래너·스터디카페에서 진입하는 별도 인증 화면으로 제안한다.

## 시안

- `study-share-concept.png`: 왼쪽은 앱 인증 화면, 오른쪽은 SNS 공유 이미지.
- 모든 숫자와 과목별 시간은 예시 데이터다.
- 기존 앱의 파란색 계열을 사용한다. 블루·화이트 두 가지 공유 스타일을 제공한다.
- 이미지는 방향 검토용이다. 실제 구현에서는 선택한 스타일과 과목 표시 설정이 미리보기와 저장 이미지에 동일하게 반영되어야 한다. 시안 왼쪽의 요약 미리보기는 축약 표현이다.

## 사용 흐름

1. 홈의 오늘 공부 요약, 플래너 또는 공부 종료 안내에서 **오늘 공부 인증하기**를 누른다.
2. 순공시간과 할 일 완료 현황을 불러와 카드로 보여준다.
3. 공유 스타일, 닉네임 표시, 과목별 시간 표시를 선택한다.
4. **이미지 저장** 또는 **공유하기**를 누른다.
5. 공유 시 지원되는 기기의 기본 공유 메뉴를 열고, 사용자가 앱과 게시 위치를 선택한다. 직접 SNS에 자동 게시하는 기능은 1차 범위에 포함하지 않는다.

새 하단 탭은 추가하지 않는다. 공부 종료 후 진입도 선택 행동으로 둔다.

## 카드 구성

| 항목 | 예시 | 규칙 |
| --- | --- | --- |
| 공부 날짜 | 2026.09.15 | 기존 학습일 기준 |
| 오늘 순공시간 | 7시간 30분 | 가장 크게 표시, 휴식 제외 |
| 할 일 달성률 | 75% | 완료 6개 ÷ 전체 8개 × 100 |
| 완료 수 | 8개 중 6개 완료 | 달성률 바로 아래 표시 |
| 과목별 시간 | 해양경찰학 3시간 / 해사법규 2시간 30분 / 항해학 2시간 | 표시 여부 선택 |
| 응원 문구 | 나와의 약속을 지킨 하루 | 1차는 준비된 짧은 문구 선택 |
| 브랜드 | 론박스터디 | 하단에 작게 표시 |
| 닉네임 | 선택한 경우에만 표시 | 기본 숨김, 실명·등록번호 표시 안 함 |

달성률의 1차 정의는 기존 플래너와 같은 **할 일 완료율**이다. 과목 목표시간은 현재 코드에서 ‘목표시간 내 완료’ 여부에도 쓰이므로, 단순히 공부시간을 목표시간으로 나눈 값을 동일한 달성률로 표시하지 않는다.

## 첫 출시 범위

- 오늘 기록으로 인증 이미지 만들기.
- 블루·화이트 스타일 선택.
- 닉네임과 과목별 시간 표시 선택.
- 저장용 세로 이미지 1080 × 1920을 목표 규격으로 제안. 주요 내용은 가장자리에서 충분히 떨어뜨린다.
- 이미지 저장과 기기 공유 메뉴 연결. 파일 공유 지원 여부는 구현 시 대상 기기에서 확인하고 미지원 환경에는 이미지 저장을 제공한다.
- 기록이 동기화된 시점의 값을 고정해 미리보기와 결과 이미지가 일치하도록 한다.

사진 배경, 기존 캐릭터·불꽃 삽입, 정사각형 카드, 과거 날짜 선택, 연속 공부일은 후속 확장 후보로 둔다.

## 기록 상태별 처리

- **할 일 없음:** 달성률을 0%로 단정하지 않고 해당 영역을 생략한다. 앱에는 ‘등록된 할 일이 없어요’를 표시한다.
- **할 일 미완료:** 0%를 정상 표시한다. 공유를 막지 않는다.
- **순공 기록 없음:** 앱에 ‘오늘의 첫 공부를 기록해보세요’를 표시하고 시간 중심 카드 생성은 비활성화한다.
- **측정 중:** 마지막으로 저장이 확인된 시점까지의 기록을 사용하고 앱에 집계 시점을 안내한다. 인증 화면 진입만으로 타이머를 종료하지 않는다.
- **동기화 실패:** 확인되지 않은 시간을 새 인증 기록으로 만들지 않고 재시도를 제공한다.
- **공부 날짜:** 기존 앱의 한국시간 오전 4시 경계와 학습일을 사용한다. 자정 이후 날짜가 기기 달력과 다를 때 앱에 짧게 설명한다.
- **공유 취소:** 작성 화면과 설정을 유지한다. 실제 SNS 게시 완료를 확인하지 못한 경우 ‘게시 완료’라고 표시하지 않는다.
- **외부 앱 이동:** 기존 순공 타이머의 자동 일시정지 정책과 충돌하지 않게 확인한다.

## 구현 전 확인할 항목

- 인터넷 수강생에게만 진입 버튼이 표시되는지.
- 카드의 총시간·과목별 합계·달성률이 기존 화면의 확정 기록과 맞는지.
- 긴 닉네임, 많은 과목, 큰 시간 값에서도 이미지가 잘리지 않는지.
- 선택 옵션과 미리보기·저장 이미지가 일치하는지.
- iOS·Android의 실제 저장과 공유 동작, 한글 글꼴과 이미지 선명도.
- 인증 화면 진입·복귀가 기존 타이머와 플래너 조작을 방해하지 않는지.

## 현재 결과

기획 문서와 이미지 시안, 클릭 가능한 독립 미리보기(`index.html`)를 작성했다. 운영 앱 기능 구현·빌드·푸시·배포는 진행하지 않았다.

미리보기 실행: 프로젝트 루트에서 `node docs/study-share/serve.cjs` 실행 후 `http://127.0.0.1:4318` 접속. 홈 진입 버튼, 카드 스타일·정보 선택, PNG 저장, 공유 메뉴 예시를 제공한다. 공유 메뉴는 실제 SNS로 연결하지 않는 시뮬레이션이다. 브라우저에서 홈 → 카드 → 공유 메뉴 → 홈 복귀와 옵션 변경을 확인했다.

생성 도구: 내장 ImageGen. 최종 생성 프롬프트는 `imagegen-prompt.txt`에 보관한다.
