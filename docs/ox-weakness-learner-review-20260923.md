# 취약단원 기획 재검토 — 학습자가 다음에 풀 문제를 판단하도록

2026-09-23 / 검토용 제안. 기존 시안·앱은 변경하지 않았다.

> 이 문서는 중간 검토안이다. 사용자 의도를 재확인한 [취약 이력 유지 기획](ox-weakness-history-direction-20260923.md)이 이를 대체한다. 시간 간격 재확인은 현재 요구의 필수 범위에서 제외하며, HTML 시안은 최신 방향으로 수정했다.

## 권장 방향

취약단원의 주 정보는 ‘복습 우선순위와 확인할 문항 수’로 바꾼다. 과거 오답은 복습 대상 선정과 이력에 반영하고, 최근의 개선은 상태 전환으로 인정한다. 현재 정답률은 보조 정보로 남긴다. 누적 오답률을 현재 실력이나 실패 확률을 나타내는 ‘취약률’로 부르지 않는다.

초기안은 과거 기록을 찾을 수 있게 하지만, 현재 정답률 100%·양호가 먼저 보이면 학습자가 더 복습할 필요가 없다고 받아들일 수 있다. 이력을 따로 보러 가야 한다는 점도 남는다. 이에 과거 오답과 현재 복습 상태를 단원 한 행에서 함께 보여주는 안으로 수정한다.

## 방식 비교

| 방식 | 장점 | 학습자 관점의 한계 | 판단 |
| --- | --- | --- | --- |
| 마지막 답변 정답률 | 방금 개선한 결과가 즉시 보임 | 해설 직후 재정답도 장기 기억과 구분하지 못함 | 보조 수치 |
| 전체 오답 횟수 / 전체 풀이 횟수 | 과거 기록을 반영하고 산식이 쉬움 | 예전 오답이 오래 남고 특정 문항을 반복한 횟수에 따라 단원 수치가 달라짐 | 상세 이력용, 대표 지표로 제외 |
| 첫 풀이 오답률 | 처음 어려웠던 단원을 비교하기 좋음 | 학습 후 개선을 반영하지 못하며 최초 기록이 필요함 | 추후 진단 정보 |
| 문항별 복습 상태 + 오답 이력 | 왜 다시 풀어야 하는지, 어떻게 개선했는지 드러남 | 시간이 지난 재풀이를 구분할 기록이 필요함 | 권장 |

단순 누적률의 예: 처음 10문항 중 4개를 틀리고 그 4개를 다시 맞히면 4/14=28.6%다. 이는 누적 제출 중 오답의 비율이지, 지금 28.6%를 모른다는 뜻은 아니다. 같은 4개를 계속 맞히면 새로운 문항을 풀지 않아도 수치가 낮아진다.

## 문항 상태

틀린 적 있는 문항을 다음 세 상태로 나눈다. 각 문항은 한 상태에만 속한다.

1. **다시 풀기 필요**: 마지막 답변이 오답. 지금 복습할 대상이다.
2. **시간 두고 재확인**: 오답 후 다시 맞혔으나, 간격을 둔 확인이 충분하지 않다. 즉시 정답을 낸 성취는 인정하되 학습을 끝내지 않는다.
3. **재확인 통과**: 정해진 간격을 두고 다시 맞혔다. 우선 복습 목록에서는 내려가지만 과거 이력에 계속 남는다. ‘완전 숙달’이나 ‘다시는 안 틀림’으로 표현하지 않는다.

다시 틀리면 어느 상태에서든 ‘다시 풀기 필요’로 돌아온다. 반복 오답은 누적 3회 이상이라는 이력 배지이며 상태와 독립적이다. 통과 문항을 반복 오답 횟수만으로 미통과 문항보다 위에 올리지 않는다.

처음부터 맞힌 문항은 ‘오답 이력 없음’이다. 자동으로 재확인 통과로 간주하지 않는다. 미학습 문항도 별도 집계하며, 단원의 모든 내용을 검증했다는 표현을 쓰지 않는다.

## 시간 간격 규칙 — 검토용 초기 운영안

- 현재 버전 문항에 대해 마지막 오답 이후, 정답·해설을 마지막으로 확인한 때부터 최소 24시간 지난 재풀이 정답 1회를 재확인 통과로 인정하는 안을 제안한다.
- 풀이·해설 열람 시점을 추적할 수 있는지 구현 전에 확인한다. 조회 시점을 확인할 수 없다면 제출 시각 기반으로 제한하고 측정의 한계를 명시한다.
- 날짜만 바뀐 23:59 → 00:01 풀이는 간격을 둔 복습으로 인정하지 않는다.
- 그 전에 다시 풀어도 학습은 허용한다. 정답이면 대기 상태이며 새 오답이면 다시 풀기 필요로 돌아간다.
- 최근 노출로 인해 아직 확인 시점이 오지 않았다면 ‘재확인 대기’, 시점이 오면 ‘재확인 가능’으로 안내한다. 버튼이 없거나 접근을 막는 방식은 사용하지 않는다.
- 이 24시간·1회는 단순한 초기 제품 규칙이다. 연구로 검증된 최적 간격이나 숙달 기준이 아니다. OX는 추측 정답이 가능하므로 이를 실력 인증으로 사용하지 않는다.
- 시험 직전에는 대기 중인 문항도 바로 복습할 수 있다. 자동 푸시·일정 알림은 이번 범위에서 제외한다.

## 단원 화면

취약단원 기본 목록에서 다음을 한 번에 보여준다.

```text
형법의 적용범위                         시간 두고 재확인
틀린 적 있는 8문항
다시 풀기 필요 0 · 재확인 대기 8 · 재확인 통과 0
최근 답변 정답률 100% · 20 / 50문항 학습
[이전 오답 8문항 보기]
```

간격을 둔 확인 뒤에는 `다시 풀기 필요 0 · 재확인 대기 0 · 재확인 통과 8`로 바뀐다. ‘지난 오답 8문항을 재확인했어요’라고 성취를 알리고, 이력에서 언제든 재풀이할 수 있게 한다.

목록 우선순위:

1. 마지막 답변이 오답인 문항이 있는 단원.
2. 재확인 가능 시점이 된 문항이 있는 단원.
3. 아직 재확인 시점 전인 문항이 있는 단원.
4. 모두 재확인 통과한 단원은 ‘재확인한 단원’에서 조회.

동일한 그룹에서는 해당 그룹 대상 문항 중 반복 오답 문항 수 → 해당 그룹 대상 문항 수 → 목차 순서로 정렬한다. 이 정렬은 학습 우선순위이며 통계적 단원 난이도 순위가 아니다. 단원 크기의 영향을 피하려고 임의의 가중 점수를 만들지 않는다.

오답 이력은 상세 확인과 시험 전 모아 풀기의 경로로 유지한다. 모든 오답을 최신 정답으로 바꿨다는 이유만으로 기본 화면에서 바로 사라지지 않는다.

## 수동 완료 처리

기존 ‘복습 완료’는 학습자가 목록을 정리하는 표시다. 시스템의 ‘재확인 통과’와 분리한다. 수동 완료만으로 통과 수나 실력 지표를 올리지 않는다. 기본 취약단원 집계에는 실제 풀이 상태를 사용하고, 과거 수동 완료 항목도 이력을 확인할 수 있게 한다.

## 단계별 적용

### 먼저 적용할 범위

- 과거 오답·최신 정답·완료 여부로 ‘다시 풀기 필요 / 다시 맞힘’을 함께 표시한다.
- 큰 100%·양호 표현 대신 남은 복습 문항과 과거 오답을 앞에 배치한다.
- 과거 오답 문항을 단원 안에서 직접 조회·재풀이한다.
- 검증 전 기록을 임의로 재확인 통과로 분류하지 않는다.

### 기록 확인 후 적용할 범위

- 개인별 풀이 시각과 정답·해설 노출 기록을 확인해 간격을 둔 재확인 상태를 도입한다.
- 기존 기록으로 판정할 수 없는 문항은 ‘다시 맞힘 · 재확인 기록 없음’으로 표시한다.
- 문항 버전·이용 권한·비공개 정책을 유지한다. 기존 기록을 초기화하지 않는다.
- 새 취약 우선순위 적용 후, 반복 오답 문항의 재오답과 복습 진입·완료 흐름을 살펴 규칙을 조정한다. 교육 효과 수치를 사전 보장하지 않는다.

## 근거와 해석 범위

- [Roediger & Karpicke, 2006, Test-enhanced learning](https://pubmed.ncbi.nlm.nih.gov/16507066/): 산문 학습 실험에서 직후 평가와 지연 평가의 결과가 달랐으며, 지연 평가에서 회상 연습의 이점이 나타났다.
- [Karpicke, 2009, Metacognitive control and strategy selection](https://pubmed.ncbi.nlm.nih.gov/19883131/): 외국어 학습 실험에서 한 번 회상한 문항의 연습을 중단하는 경향과 반복 인출의 학습상 이점을 다뤘다.

이를 바탕으로 즉시 재정답을 장기 숙달로 취급하지 않고, 간격을 둔 재확인 경로를 마련하는 제품 방향을 제안한다. 이 연구들이 형사법 OX의 위 산식·24시간 규칙·화면 설계를 직접 검증한 것은 아니다.
