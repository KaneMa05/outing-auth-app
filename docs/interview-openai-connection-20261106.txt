면접반 iPhone 테스트앱 OpenAI 연결 — 2026-11-06

현재 상태
사용자가 전공·인성·AI 세 모드를 모두 OpenAI로 연결하도록 지정했습니다.
서버 구현과 로컬 설정을 완료했습니다. 푸시, 운영 환경변수 변경, DB 적용, 배포는 아직 하지 않았습니다.
기존 서버용 OPENAI_API_KEY를 재사용합니다. 새 키를 발급하거나 키 값을 앱·브라우저·문서에 넣지 않았습니다.

모드별 연결
전공: /api/interview-job-exam → 음성 전사 2회 → 검토된 기준의 독립 모델 판정 → 기존 결과·녹음 저장.
인성: /api/interview-personality → 음성 전사 2회 → 답변 구조·근거 인용 피드백 → 기존 결과·녹음 저장.
AI: /api/interview-native → 기존 인증된 실시간 음성 면접 → 꼬리질문 → /api/interview-live의 종합 분석 및 기록 조회.
실시간 음성은 기존 네이티브 프로토콜과 호환되는 GPT Live /v1/live/sessions를 사용합니다.
종합 분석은 /v1/responses를 사용하며 저장된 학생 답변의 실제 인용을 서버에서 검증합니다.
한 면접 기록당 한 번 생성하고, 재조회·동시 요청은 기존 결과를 반환합니다.
응답 유실·유효하지 않은 근거·미확인 실행은 unknown으로 보존하며 자동 유료 재실행하지 않습니다.

모델과 설정
기본값: 음성 gpt-live-1, 전사 gpt-transcribe, 전공 판정 gpt-6.1-sol / 검증 gpt-6-astra,
인성 및 종합 피드백 gpt-6.1-sol. 기존 꼬리질문 모델 gpt-6-astra 설정은 보존했습니다.
모델은 서버 환경변수로만 선택하며 클라이언트의 모델·지시문·성적 주입을 받지 않습니다.
환경변수 이름 및 기본값: .env.example
로컬 설정: npm run setup:interview-openai (기존 .env.local의 서버 키 필요)
설정 검사: npm run check:interview-openai
원격 읽기 전용 검사: node scripts/check-interview-openai.cjs --remote
개별 기능의 명시적 false는 INTERVIEW_OPENAI_ENABLED보다 우선합니다.
설정 스크립트는 키·다른 설정·기존 PC 토큰을 보존하고 로컬 면접 플래그만 구성합니다.
운영 서버에는 OPENAI_API_KEY, 모델 설정, 각 면접 활성화 플래그, CRON_SECRET,
INTERVIEW_LIVE_WORKER_SECRET, 기존 Supabase 서버 설정을 안전하게 등록해야 합니다.
키를 Git에 커밋하거나 config.js에 넣지 않습니다.
