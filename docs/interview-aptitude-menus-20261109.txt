적성 모의고사 학생 메뉴 개편 - 2026-11-09
상태: 로컬 구현/검증 완료, 사용자 최종 배포 확인 전

학생 메뉴
- 적성 모의고사 진입 시 타이머 / 답안 입력 / 성적 조회의 세 메뉴를 표시한다. 기본 메뉴는 타이머다.
- 타이머: 하프/본시험과 영역을 선택하고 시작, 일시정지, 계속, 초기화를 사용한다. 종료 후 다음 영역으로 이동할 수 있다.
- 하프 제한시간: 언어이해 8분, 언어비판 10분, 수열추리 5분, 도형추리 8분, 문제해결 15분. 총 46분.
- 본시험 제한시간: 15분, 20분, 10분, 15분, 30분. 총 90분. 기존 시험지/서버 round_json의 minutes와 같은 순서다.
- 시간은 MM:SS로 표시한다. 경과시간을 반복해서 빼는 방식 대신 종료 시각을 보관하므로 화면을 떠났거나 브라우저가 백그라운드에 있어도 돌아왔을 때 남은 시간을 다시 계산한다.
- 타이머는 계정별 로컬 저장소에 보관하고, 같은 계정의 다른 탭에서 일시정지/초기화한 값도 반영한다. 저장 실패 시 현재 타이머는 계속 동작하며 기기 보관 실패를 표시한다.
- 진행한 타이머를 초기화하거나 다른 유형/영역으로 바꿀 때 확인한다. 시간 종료 시 화면에 알리고 자동으로 다음 영역을 시작하거나 답안을 제출하지 않는다.
- 답안 입력에서는 같은 시험 유형과 과목에 해당하는 타이머만 작게 표시한다. 해당 표시를 누르면 타이머 메뉴로 돌아간다. 성적 조회에는 타이머를 표시하지 않는다.
- 답안 입력: 기존 유형/회차/과목/10문항 페이지/임시저장/최종 제출을 유지한다. 세 메뉴 사이를 오가도 답안과 타이머는 보존한다.
- 성적 조회: 제출 전에는 미제출 안내, 공개 전에는 공개 대기를 표시한다. 공개 후 정답 수/정답률/등수, 과목별 정답 수, 읽기 전용 답안 및 해설지를 제공한다.
- 타이머 진입 시 회차 상세를 미리 가져오지 않는다. 학생에게 공개된 회차가 없어도 타이머를 사용할 수 있다.
- 처음 본시험 타이머를 선택했다면 답안 입력도 본시험 회차로 진입한다. 이미 작성하던 답안이 있으면 그 회차를 보존한다.

범위와 보안
- 학생용 메뉴를 추가했으며 관리자 회차/정답/파일/성적 관리 흐름은 유지했다.
- 새 DB 테이블/RPC/권한 변경은 없다. 운영 회차, 정답, 응시 개방 및 결과 공개 상태는 변경하지 않았다.
- 성적/정답/해설의 공개 및 회원 접근 조건은 기존 서버 API가 계속 판정한다. 새 타이머는 유료 AI나 음성 API를 호출하지 않는다.
- 타이머는 개인 풀이 보조 기능이며 서버가 강제하는 응시 시간 제한과는 별도로 동작한다.
- 타이머 역할과 aria-live=off를 사용해 매초 남은 시간이 반복 안내되지 않도록 했고, 시작/정지/종료 상태만 상태 영역에서 안내한다.
- 연결 모듈/스타일 버전은 20261109-aptitude-menus, SW 캐시는 v562-interview-aptitude-menus로 준비했다.

UI 정리 (추가 사용자 요청, 2026-11-09)
- 타이머/답안 입력/성적 조회는 진한 버튼 박스 대신 밑줄로 선택을 표시하는 가벼운 메뉴로 정리했다.
- 세 화면 모두 같은 위치에 하프/본시험 선택과 과목 또는 회차 선택을 배치했다. 기존 선택값과 답안 보존 동작은 유지한다.
- 타이머 과목은 시계 위의 선택 메뉴에서 고른다. 각 선택지에 해당 과목의 제한시간을 함께 표시하며, 전체 시간 합계와 아래쪽 과목 카드 5개는 제거했다.
- 시작 동작을 강조하고 초기화는 보조 동작으로 낮췄다. 과목을 연속해서 바꿔도 선택 메뉴의 포커스를 유지하며, 시간 초기화를 취소하면 이전 과목으로 되돌린다.
- 과목 목록은 하나의 묶음으로 정리하고 반복 테두리/여백을 줄였다. 학생 화면의 버튼은 최소 44px로 유지했고, 관리자 버튼 스타일은 분리했다.
- 답안 입력의 작은 타이머는 현재 시험 유형/과목에 맞는 경우에만 표시한다. 다른 유형/과목 또는 제출 완료 답안에는 표시하지 않는다. 타이머 자체는 메뉴를 떠나도 보존한다.
- 성적 조회에서는 타이머를 완전히 제거했다. 본시험 타이머와 하프 성적이 함께 나타나는 혼동을 해소했다.
- 과목 선택에 포커스가 있어도 하단 메뉴가 보이도록 기존 회차 선택과 같은 예외를 적용했다.
- 세 화면 각각을 5개 크기에서 확인했다(총 15개 조합). 가로 넘침 없음, 모든 표시 버튼/선택 메뉴 높이 44px 이상, 선택 영역 상단 위치 동일(검증 화면 178px), 성적 조회의 타이머 요소 0개를 확인했다.
- 사용자 제공 데이터와 운영 DB는 변경하지 않았다. 검사 35개 통과 후 최종 UI 변경에 관련된 28개 검사 및 격리 빌드를 다시 확인했다. 브라우저 콘솔 오류 없음.
- 위 내용은 로컬 수정안이며, 푸시/운영 배포는 사용자 확인 전이다.
