# 론박스터디앱 기능 기획안: 나의 DB ‘AI용으로 복사하기’

Nov 9, 2026 · @용

## 개요

나의 DB 화면에 **‘AI용으로 복사하기’** 버튼을 추가합니다. 버튼을 누르면 수강생이 저장한 기본 이력·인생그래프·보완 답변이 신상 정보가 빠진 상태로, 외부 AI(ChatGPT·Claude·Gemini)에 바로 붙여넣을 수 있는 형식으로 복사됩니다.

**배경.** 론박스터디앱은 DB 정리, AI 초안, 강의 기반 진단까지 제공합니다. 음성 모의면접·꼬리질문 연습은 앱에서 개발 중이지만, 답변 간 일관성 점검이나 AI 문체 점검처럼 수강생이 외부 AI에서 따로 하는 작업은 계속 남습니다.

**문제.** 지금은 앱에 DB 내보내기 기능이 없어 수강생이 칸마다 직접 복사합니다. 이 과정에서 세 가지 문제가 생깁니다.

- 경험이 많을수록 옮기는 데 시간이 오래 걸리고, 일부만 옮겨 AI가 맥락을 놓칩니다
- 이름·생년월일·수험번호 같은 신상 정보가 그대로 외부 AI에 들어갑니다
- 형식이 제각각이라 AI가 경험을 지어내거나 섞어 쓰기 쉽습니다

## 목표와 비목표

한 번의 클릭으로, 안전하고 AI가 오해하지 않는 형식의 DB를 수강생에게 주는 것이 목표입니다.

**목표**

- 저장된 DB 전체 또는 일부를 1회 클릭으로 복사
- 이름·생년월일·수험번호 등 신상 정보는 기본으로 제외
- 앱의 칸 이름을 그대로 쓴 고정 형식으로 출력해 AI가 구조를 정확히 이해
- 내 정보 아래에 AI 지침을 함께 붙여, 붙여넣기만 해도 AI가 정해진 규칙대로 동작

**비목표 (이번에 하지 않는 것)**

- 외부 AI 서비스와의 직접 연동(API 연결, 자동 전송)
- 음성 모의면접·꼬리질문 연습 (앱에서 별도 개발 중)
- 자기소개·지원동기 등 작성한 답변까지 복사(2단계에서 검토)

## 현재 앱 구조와 외부 AI가 필요한 지점

앱은 DB → AI 초안 → 핵심 25제 진단 → 교사 제출로 이어집니다. 신규 버튼은 이 흐름을 바꾸지 않고, DB에서 외부 AI로 나가는 길 하나만 더합니다.

외부 AI는 음성 모의면접처럼 앱에 없는 연습에만 쓰고, 답변 작성과 진단은 앱으로 돌아와 마무리합니다.

## 기능 상세

버튼은 ‘나의 DB 정리하기’ 상단 배너 오른쪽에 두고, 누르면 복사 범위를 고르는 창이 열립니다.

| 항목 | 내용 | 기본값 |
| --- | --- | --- |
| 버튼 위치 | 나의 DB 정리하기 상단 배너 오른쪽 | 항상 표시 |
| 복사 범위 | 기본 이력 / 인생그래프 경험(개별 선택) / 보완 답변 | 전체 선택 |
| 신상 정보 | 이름 · 생년월일 · 수험번호 · 성별 | 제외(해제 불가) |
| 학교·회사명 | ‘OO대학’ ‘OO회사’로 치환 | 치환 켜짐(해제 가능) |
| 지침 문구 | 맨 위 안내 1줄 + 내 정보 아래 하단 지침 블록 | 포함 |
| 출력 방식 | 클립보드 복사 / .txt 파일 저장 | 클립보드 |

**출력 형식.** 맨 위에 안내 한 줄, 가운데에 내 정보, 맨 아래에 AI 지침이 붙습니다. 내 정보는 앱의 칸 이름을 그대로 제목으로 쓰고, 빈 칸은 생략합니다.

```markdown
※ 아래 [나의 면접 DB]를 읽고, 맨 아래 [AI 지침]에 따라 도와주세요.

[나의 면접 DB]
지원 직렬: 해양경찰 공채
기본 이력: OO대학 졸업 / 수상안전요원 자격 / 봉사 1년

[경험 1]
나이·만족도: 23세 · -10점
키워드: 야간 편의점 취객 민원 응대
내용: (앱 ‘내용’ 칸)
면접관에게 어필할 점: (앱 ‘어필할 점’ 칸)

[보완 답변]
지원 계기: ...
공직 가치: ...

[AI 지침]
1. 역할: 너는 해양경찰 면접 코치다.
2. 근거: 위 [나의 면접 DB]에 있는 경험만 쓰고, 없는 경험·수치·자격은 지어내지 마라.
3. 질문 먼저: 필요한 정보가 DB에 없으면 추측하지 말고 나에게 먼저 물어라.
4. 말투: 답변 예시는 존댓말로, 실제 면접에서 말하기 좋은 문장으로 써라.
5. 개인정보: 내 이름·연락처·수험번호 같은 신상 정보를 묻지 마라.
6. 사실 확인: 기관명·제도·일정은 해양경찰청 공식 공고로 확인하라고 안내해라.
7. 시작: 이해했으면 ‘준비됐습니다’라고 답하고, 이 DB로 할 수 있는 연습 3가지를 제안해라.
```

**하단 지침 설계.** 지침은 내 정보 뒤, 맨 마지막에 둡니다. 긴 자료를 먼저 읽힌 뒤 마지막에 규칙을 주면 AI가 자료 전체에 규칙을 적용하기 쉽고, 수강생도 내 정보와 지침을 한눈에 구분할 수 있습니다.

| 지침 항목 | 막으려는 문제 |
| --- | --- |
| 역할 | 일반적인 조언으로 흐르는 답변 |
| 근거 | 없는 경험·수치를 지어내는 것 |
| 질문 먼저 | 빈칸을 추측으로 채우는 것 |
| 말투 | 글말투, 반말, 가벼운 표현 |
| 개인정보 | AI가 신상 정보를 되묻는 것 |
| 사실 확인 | 틀린 기관명·제도·일정 |
| 시작 | 붙여넣은 뒤 무엇을 할지 모르는 상황 |

지침 문구는 앱에 고정하지 않고 운영자(교사)가 관리 화면에서 고칠 수 있게 하는 것을 제안합니다. 3단계에서는 용도별 지침(25제 경험 매칭 / 답변 일관성 점검 / AI 문체 점검)을 골라 붙일 수 있게 넓힙니다.

## 화면 흐름

수강생은 세 번의 클릭으로 복사를 끝냅니다.

1. ‘나의 DB 정리하기’에서 **AI용으로 복사하기** 버튼을 누른다
   - 저장하지 않은 변경 내용이 있으면 ‘먼저 저장해 주세요’ 안내를 띄운다
   - 저장된 경험이 0개면 버튼을 비활성화하고 ‘인생그래프를 먼저 작성하세요’를 보여 준다
2. 복사 범위를 고른다: 기본 이력 / 경험별 체크박스 / 보완 답변
3. **미리보기**로 복사될 내용을 확인한다 (제외된 신상 정보는 ‘제외됨’으로 표시)
4. **복사하기** 또는 **파일로 저장**을 누른다
5. 완료 안내에 다음 행동을 보여 준다: ‘ChatGPT·Claude의 프로젝트, Gemini의 스킬에 붙여넣으세요’ + 강의 안내 링크

## 개인정보·보안 정책

앱은 복사할 텍스트만 만들고, 외부로 아무것도 전송하지 않습니다. 붙여넣는 것은 수강생 본인의 선택입니다.

- **항상 제외:** 이름, 생년월일, 수험번호, 성별, 계정 정보
- **기본 치환:** 학교명·회사명·단체명 → ‘OO’ (수강생이 해제 가능)
- **자유 입력 칸 경고:** ‘내용’ 칸에 전화번호·이메일 형식이 있으면 미리보기에서 강조 표시
- **안내 문구:** 복사 창 하단에 ‘외부 AI에 입력한 내용은 학습에 활용될 수 있습니다. 설정에서 학습 활용을 끄거나 임시 채팅을 사용하세요’ 표시
- **기록:** 복사 횟수만 집계하고, 복사한 내용은 저장하지 않음

## 강의 연계 방안

‘AI 면접 답변 활용 전략’ 강의 5파트(앱 밖에서도 쓰는 AI 활용법)에 슬라이드 1장을 추가해, 버튼 하나로 설명합니다.

| 강의 장면 | 버튼으로 하는 일 |
| --- | --- |
| 핵심 25제 준비 | DB 복사 → ‘25문항에 내 경험을 매칭하고 빈 문항을 알려 줘’ |
| 답변 일관성 점검 | DB + 완성 답변 붙여넣기 → 서로 다른 내용·DB에 없는 내용 찾기 |
| AI 문체 점검 | DB + 완성 답변 → 하단 지침대로 DB 밖 표현·AI 상투어 찾기 |
| 개인정보 교육 | ‘신상 정보는 버튼이 알아서 빼 줌’으로 설명 단순화 |

## 성공 지표

목표값은 출시 후 첫 기수의 사용 데이터를 보고 정합니다.

| 지표 | 측정 방법 |
| --- | --- |
| 버튼 사용률 | 경험 3개 이상 저장한 수강생 중 복사를 1회 이상 한 비율 |
| 반복 사용 | 수강생 1인당 복사 횟수 (DB를 고친 뒤 다시 복사하는지) |
| 개인정보 사고 | 신상 정보 노출 문의 · 제보 건수 (목표 0건) |
| 만족도 | 면접반 수강 후 설문 ‘외부 AI 활용이 쉬워졌다’ 문항 |
