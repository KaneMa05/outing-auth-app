# 신규 수강생 웰컴포인트와 3일 공부 루틴 챌린지

## 동작

- 기능 적용 후 실제 앱 가입(`app_registered_at`)을 완료한 수강생만 대상이다. 명단 생성 날짜와 구분한다.
- 첫 홈 방문 시 웰컴포인트 100P를 자동 지급한다. 교사·관리자·운영 계정은 제외한다.
- 웰컴포인트 지급 후 환영 안내와 챌린지 소개를 한 번 보여준다.
- 지급 안내에는 코인 등장·빛 반사·색종이 효과와 약 0.9초의 금액 카운트업을 표시한다. 달성 보상에는 완료 배지가 추가된다.
- 애니메이션은 반복하지 않으며 즉시 닫을 수 있다. 동작 줄이기 설정에서는 최종 금액과 정적인 일러스트를 바로 표시한다.
- 챌린지는 한국 시간 자정 기준 연속된 3일에 각각 18,000초 이상 공부하면 달성한다.
- 3일차 5시간 달성을 서버에서 확인하면 300P를 즉시 적립한다. 공부 중에는 작은 적립 알림만 한 번 표시한다.
- 코인 애니메이션 완료 모달은 일시정지·공부 종료가 성공한 뒤 표시한다. 타이머 처리 중이거나 다른 안내창이 열려 있으면 기다린다.
- 작은 알림은 보상 확인 완료로 처리하지 않는다. 앱을 닫았다면 다음 접속 시 공부 중이 아닌 안전한 시점에 아직 확인하지 않은 완료 모달을 표시한다.
- 일시정지를 제외하고 여러 학습 구간을 합산한다. 자정에 걸친 구간은 날짜별로 나눈다.
- 기존 새벽 4시 기준 학습 기록·랭킹·순공시간 포인트의 동작은 바꾸지 않는다.
- 별도 참여 버튼, 진행 카드, 일일 진행 알림은 없다. 기한 없이 다시 도전할 수 있다.
- 계정별 웰컴/챌린지 보상은 각각 한 번이다. 기존 시간 포인트에 추가된다.
- 마이 → 포인트에서 내역과 조건을 볼 수 있다. 기존 인터넷 수강생 상점의 포인트 내역 아래에도 조건을 둔다.
- 상점 접근 권한은 기존대로 유지한다. 온라인 관리반·오프라인 수강생도 웰컴포인트는 적립되며, 챌린지는 스터디카페 학습 기록이 있어야 달성한다.

## 확정 보상액

웰컴포인트는 **100P**, 챌린지 추가 보상은 사용자 확정 금액인 **300P**다.
두 보상을 모두 받으면 총 **400P**이며 기존 학습 시간 포인트는 별도로 적립된다.
안내 문구는 서버 금액을 사용하므로 자동으로 맞춰진다.
운영 중 `challenge_points`를 NULL로 설정하면 새로운 챌린지 지급/소개를 중단할 수 있다.

## 저장과 지급

- `student_reward_enrollments`: 최초 가입 및 대상 여부. 적용 전에 가입/기기 등록한 계정은 제외 이력을 남겨 재등록으로 대상이 되지 않게 한다.
- `student_reward_focus_intervals`: 공부가 일시정지/종료되거나 기존 일자 분할이 일어날 때 서버가 확정한 활성 구간.
- `student_reward_receipts`: 보상 종류, 금액, 지급 시각, 안내 확인 시각.
- `study_cafe_point_wallets` / `study_cafe_point_ledger`: 기존 지갑과 원장에 함께 반영한다.
- 신규 RPC는 서버의 service_role만 호출한다. 기기 검증 및 현재 학생 유형 확인 뒤 자기 계정에 대해서만 호출한다.
- 영수증·원장·잔액은 하나의 트랜잭션에서 저장하고 계정/보상 고유 키 및 지갑 행 잠금으로 중복을 막는다.
- 진행 중 시간은 공개 좌석 또는 개인 방의 마지막 연결 확인 시각 + 30초까지만 인정한다.
- 활성 학습 중 최대 분당 한 번과 공부 종료/일시정지 때 보상을 확인한다. 연결이 끊겼다면 다음 접속에서 재확인한다.
- 실패한 지급은 성공 안내를 띄우지 않는다. 다음 확인에서 재처리하며 로그인/공부 API의 성공 여부에 영향을 주지 않는다.
- 안내 확인은 서버에 저장한다. 확인 요청이 실패해도 현재 기기에서는 반복 표시하지 않고 다음 동기화 때 서버에 재전송한다.

등록·보상 기록과 `student_reward_study_days`의 날짜별 공부 시간을 연결하면 달성 인원과 달성 후 학습 지속을 분석할 수 있다.
관리자 통계 화면 및 좌석 재입장 이력은 이 변경의 범위에 포함하지 않는다.

## 검증

로컬 서버에서 `http://localhost:3000/?studentMode=online#home`으로 접속하면 기존 로컬 수강생으로
웰컴 100P 안내와 챌린지 300P 소개를 확인할 수 있다. 기기 토큰이나 운영 DB는 필요 없다.
웰컴포인트는 브라우저의 로컬 상점 잔액에 한 번 더해지며, 기존 미리보기 잔액·구매 아이템은 보존한다.
**마이 → 포인트 → 로컬 보상 미리보기**에서 환영 안내를 다시 보거나 챌린지 달성 안내를 즉시 확인할 수 있다.
챌린지 버튼은 3일 학습을 기다리지 않고 달성 보상을 모의 지급하는 로컬 전용 기능이다.
타이머가 실행 중일 때 이 버튼을 누르면 작은 알림만 나오고, 일시정지·종료한 뒤 축하 모달이 나온다.
실제 시간에 따른 챌린지 판정은 서버 SQL 테스트로 검증한다. 미리보기 버튼을 여러 번 눌러도 각 보상은 한 번만 적립한다.

```powershell
npm.cmd run test:student-rewards
npm.cmd install --prefix .tmp/reward-test --save-exact --no-audit --no-fund @electric-sql/pglite@0.3.14
npm.cmd run test:student-rewards:db
npm.cmd test
```

DB 테스트는 임시 인메모리 Postgres에서 수행하며 운영 DB에 연결하지 않는다.
기존 계정 제외, 가입 초기화, 수강생 유형, 중복 호출, 5시간 경계, 자정, 일시정지,
연속 날짜/재도전, 활성 타이머, 공개/개인 방 연결 종료, 권한 차단을 확인한다.
