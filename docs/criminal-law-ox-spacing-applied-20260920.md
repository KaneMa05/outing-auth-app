# 형사법 OX 운영 DB 띄어쓰기 교정 결과

2026-09-20 사용자 요청 `DB 수정`에 따라 운영 프로젝트 RONPARK APP (`ehzrwkvuarertwvwoyus`)에 반영했다.

## 반영 범위

- 확인된 단절 패턴 1,022문항, 1,275곳을 교정했다. 지문 255곳, 상황문 70곳, 해설 950곳이다.
- 일반 해설과 HTML 해설을 함께 반영해 실제 수정 필드는 1,904개다. HTML 해설의 동일 공백은 1,275곳에 중복 집계하지 않았다.
- 문맥 판단이 필요한 추가 후보는 이번 자동 교정에서 제외했다.
- 로컬 원본 JSON/PDF와 앱 화면 코드는 변경하지 않았다. 원본 데이터에는 아직 교정 전 문구가 있으며, 재생성 시 별도 교정 반영이 필요하다.
- 푸시와 앱 배포는 하지 않았다.

## 보존 및 충돌 처리

- 운영 데이터와 교정 대상 필드의 MD5를 대조했다. 1,904개 대상 필드 모두 감사 당시 원문과 일치했다.
- 7개 짧은 트랜잭션으로 적용했다. 각 문항에 기존 관리자 저장 경로와 같은 advisory lock 및 row lock을 사용했다.
- 잠금 획득 후에도 원문 해시를 재검사했다. 다르면 해당 배치를 전체 롤백하도록 구성했다.
- 지정 위치의 공백만 제거하고, 예상 교정문 해시 및 공백 이외 문자 보존을 확인한 뒤 저장했다.
- 문항 ID, 정답, 단원, 문항 버전, 공개 상태, 검토 상태를 그대로 유지했다. 수정 충돌 감지를 위한 revision만 1 증가했다.
- 학생 풀이·진도·메모 테이블에는 쓰기 작업을 하지 않았다.
- 변경 전후 전체 문항을 기존 `public.ox_question_history`에 1,022건 보관했다. 조회 기준은 `actor = 'spacing-correction-20260920'`이다. 복원 시에는 이력 이후 관리자 수정 여부를 먼저 대조해야 한다.

## 검증

- 로컬 PGlite 검증 통과: 모든 교정문, 정답·메타데이터 유지, HTML 밑줄 유지, 재실행 시 중복 변경 없음, 동시 수정 충돌 시 배치 롤백.
- 운영 재조회: 이력 1,022건, 교정 공백 1,275개, 이력 이후 현재 문항 불일치 0건.
- 정답·문항 버전·공개 상태 등의 전체 메타데이터 해시는 반영 전후 동일하다.
- 공백 이외 문자 변경 0건, 밑줄 마크업 변경 0건, 일반 해설과 HTML 해설 불일치 0건, 대상 외 필드 변경 0건.
- 전체 문항 2,960개, 공개 문항 2,543개를 유지했다.
- 작업 중 학생의 실제 이용이 이어져 풀이/진도는 반영 직전 104건에서 검증 시 114건으로, 메모 행은 4건에서 5건으로 늘었다. 이 증가는 교정 스크립트의 쓰기 작업이 아니다.
