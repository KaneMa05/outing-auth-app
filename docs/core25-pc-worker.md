# 핵심 25제 PC 진단 실행기

PC에서 운영 서버로 HTTPS 요청을 보내 대기 중인 진단만 가져온다. PC에 공개 포트나 터널을 열지 않는다. 기존 학생 답변, 제출, 진단 보고서는 보존한다. 진단은 강의 기준에 따른 코칭이며 점수나 합격 여부를 판단하지 않는다.

## 배포 전 확인

- `20261024111313_interview_core25_pc_worker.sql`을 적용한다. 기존 진단 테이블에 대기열 표시와 일회용 실행권을 추가하며 실행기 접속 상태 테이블은 RLS 및 service_role 전용이다.
- 서버 환경: `INTERVIEW_CORE25_DIAGNOSIS_ENABLED=true`, `INTERVIEW_CORE25_DIAGNOSIS_MODE=pc`, `INTERVIEW_CORE25_WORKER_TOKEN` (32바이트 난수의 base64url, 43자). 토큰은 클라이언트 코드·로그에 넣지 않는다.
- PC `.env.core25-worker.local`에 동일 토큰, `INTERVIEW_CORE25_ORIGIN=https://app.ronparkpass.com`, 검증한 실행기 절대 경로인 `INTERVIEW_CODEX`를 설정한다. 파일은 Git과 Vercel 업로드에서 제외된다.
- PC에서 ChatGPT 로그인이 유효해야 한다. 모델과 추론 수준은 `lib/core25-worker-config.cjs`로 고정한다. 기준·실행기 버전이 바뀌면 이전 결과를 재사용하지 않는다.
- 사용자 최종 확인 후 DB 변경 및 해당 변경만 포함한 앱 배포를 진행한다. 같은 폴더에서 진행 중인 다른 작업을 합쳐 배포하지 않는다.

## 실행과 장애 처리

`powershell -File scripts/start-core25-worker.ps1`로 숨김 프로세스를 시작한다. 상태 로그는 `.tmp/core25-pc-runtime/worker.log`이며 답변·지침·토큰은 기록하지 않는다. 직접 실행은 `node --env-file=.env.core25-worker.local scripts/core25-pc-worker.cjs`이다. PC 재시작 후에는 다시 실행해야 한다.

PC는 15초마다 최대 3건을 가져온다. 연결 실패 시 최대 60초로 간격을 늘린다. 24시간 켜면 유휴 상태에도 하루 약 5,760회의 확인 요청이 발생한다. 기존 하루 한도(학생 40건, 전체 500건)와 전체 동시 3건 제한을 유지한다. 요청이 없으면 AI는 호출하지 않는다. 계정 사용량 한도는 별도로 적용된다.

실행기 접속이 60초 넘게 확인되지 않으면 새 진단 접수를 막는다. 요청 접수부터 4분이 지나면 실패로 전환한다. 모델은 최대 180초만 실행하고, 이미 실행권을 준 작업은 다른 PC에 다시 주지 않는다. 결과 전송 실패 시 같은 결과만 최대 3회 전송하며 AI를 재호출하지 않는다. 실패 후 재진단은 학생이 직접 요청한다. 답변과 제출 데이터는 변경하지 않는다.

학생은 대기 중에도 이동하거나 답변을 수정할 수 있다. 결과 화면은 최대 약 4분 30초 동안 5초마다 확인하며, 편집 중인 답변을 덮어쓰지 않는다. 화면을 떠나거나 결과가 완료되면 확인을 중단한다. 답변·지침이 바뀌면 이전 내용에 대한 결과라고 표시한다.

## 보관과 검증

PC 실행기는 답변·보고서를 파일로 기록하지 않고 메모리에서 처리한다. CLI는 ephemeral 세션을 사용하고 도구·웹·메모리를 끈다. 실행용 토큰과 DB 자격 증명은 CLI 자식 프로세스에 전달하지 않는다. 답변과 강의 기준·관리자 지침은 OpenAI 모델에 전달되며 운영 DB에는 기존과 같이 스냅샷과 결과가 보관된다.

`node tests/core25-pc-worker.test.cjs`는 외부 AI 없이 인증, 중복 요청, 일회 전달, 결과 전송 재시도, 만료, 근거 검증, 답변 보존과 RLS를 검증한다. `node tests/core25-pc-live.cjs`는 가상 답변만 실제 AI에 전달하는 명시적 연결 인수 테스트다. 기능 테스트 통과는 강사 평가와의 일치율을 의미하지 않는다.

## 롤백

PC 실행기를 중지하고 `INTERVIEW_CORE25_DIAGNOSIS_ENABLED=false`로 재배포한다. 즉시 중지할 때는 PC 실행기를 먼저 종료한다. 60초 후 신규 진단은 접수되지 않고 기존 요청은 만료된다. 핵심 25제 제출 설정은 계속 열어 두며 답변·요약서·저장·제출을 유지한다. 추가 DB 열·테이블과 기존 결과는 삭제하지 않는다.
