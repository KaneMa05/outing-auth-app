# 형사법 OX 띄어쓰기 누락 추가 교정

2026-09-20 사용자의 수사·증거 파트 누락 제보에 따라 운영 DB를 다시 점검하고 추가 반영했다.

## 원인과 범위

첫 교정의 1,022문항은 운영 DB에 정상 반영되어 있었다. 처음 검토한 정확 일치 패턴의 범위가 좁아 다른 활용형, 조사, 법률 용어의 내부 분리, 공백 누락 등이 교정 대상에서 빠졌다. 이전 검출기는 붙인 단어가 원본에서 3회 이상 등장하는 경우만 추가 후보로 수집해 단 한 번 등장하는 표현도 놓쳤다.

이번에는 보류 후보의 표현을 재검토하고, 원본에서 1회 이상 확인되는 붙인 형태와 수사·증거의 잔여 단음절 분리를 추가로 검사했다. 선택한 교정 형태는 JSON과 검토 스크립트에 명시적으로 남겼다. 정상 띄어쓰기, 법령 이름의 정식 표기, 띄어쓰기가 허용되는 복합 용어 등은 일괄 연결하지 않았다.

## 반영 결과

- 단어 내부 분리와 조사 교정: 2,338문항, 6,056곳.
- 위 교정 중 수사·증거: 580문항, 1,589곳.
- 붙은 표현, 문장부호 앞 공백, 조문 표기의 추가 정리: 348문항. 앞 단계와 중복되는 문항이 있다.
- 이번 작업 전체 중복 제거 결과: **2,383문항**, 그중 **수사·증거 590문항**.
- 예: 수사·증거 198번 `요 구하자` → `요구하자`, `이 의제기` → `이의제기`, `피의자신 문` → `피의자신문`.
- 예: 수사·증거 217번 `체포영 장을` → `체포영장을`, `출석요 구에` → `출석요구에`, `이유없이` → `이유 없이`, `있고 ,` → `있고,`.
- 예: 수사·증거 552번 `받아들여지 게` → `받아들여지게`, `피의자신 문조서의` → `피의자신문조서의`.

이 결과는 명시적으로 검토한 추가 교정분의 반영 수량이다. 모든 문장의 국어 교열이 끝났거나 다른 오류가 전혀 없다는 의미는 아니다. 원본 JSON/PDF와 별도 로컬 학습 DB는 수정하지 않았다.

## 보존과 검증

- 원문 필드의 해시를 운영 DB와 대조한 뒤 공백 위치를 교정했다. 검토 중 관리자 수정과 충돌한 항목은 없었다.
- 저장 시 문항 잠금, 원문 재검사, 수정 이력 기록을 사용했다. 정답·문항 버전·단원·공개 상태와 학생 풀이·진도·메모 기록은 유지했다.
- SQL 로컬 검증: 전체 교정문, HTML 밑줄, 메타데이터 보존, 재실행 중복 변경 방지, 관리자 수정 충돌 시 롤백을 확인했다.
- 밑줄 태그 경계를 가로지르는 공백도 원래 태그를 유지하며 처리했다. 밑줄 제거 및 엔티티 복원 후 일반 해설과 일치하는지 검사했다.
- 운영 최종 검증: 현재 문항과 최신 수정 이력의 불일치 0건, 공백 이외 문자 변경 0건, 대상 외 필드 변경 0건, 문항 메타데이터 변경 0건, 밑줄 마크업 변경 0건, HTML/일반 해설 불일치 0건.
- 전체 문항 2,960개와 공개 문항 2,543개 유지. 최종 풀이/진도 각 124건, 메모 행 5건. 해당 학생 기록 테이블에는 쓰기 작업을 하지 않았다.
- 변경 전후 전체 문항은 `ox_question_history`에 2,686건 보관했다. actor는 `spacing-correction-followup-20260920` 및 `spacing-correction-polish-20260920`이다. 같은 문항이 두 단계에서 수정된 경우 이력이 두 건이다.
