면접반 적성 모의고사 - 구현 및 검증 기록 (2026-11-09)

적용 범위
- 면접반 관리자 화면의 '적성 모의고사 관리', 면접반 앱의 '적성시험', 면접반 웹 작업공간에만 추가했다.
- 기존 오프라인/온라인/인터넷 수강생의 주간시험 화면과 해기사 앱은 변경하지 않았다.
- 활성 면접반 등록과 수강 기간, 실제 학생 계정의 활성 상태를 서버에서 확인한다. 직렬 및 음성 모의면접 테스트 계정 여부는 적성시험 응시 조건이 아니다.
- 다른 작업의 미커밋 변경을 보존하기 위해 325bc1b 기준 codex/interview-aptitude-20261109 작업트리에서 구현했다.

원본 확인
- 사용자가 제공한 '직무적성검사 대비 모의시험지(본 1회).pdf'와 '(하프1회).pdf'를 읽고 표지와 실제 문항을 렌더링해 확인했다. 원본은 수정하지 않았다.
- 언어이해 / 언어비판 / 수열추리 / 도형추리 / 문제해결의 5영역이며, 각 영역은 1번부터 시작하는 5지선다다.
- 본시험: 영역별 30문항, 총 150문항, 영역별 15/20/10/15/30분, 합계 90분.
- 하프: 영역별 15문항, 총 75문항, 영역별 8/10/5/8/15분, 합계 46분.
- PDF에 배점 규정이 없어 기본 문항당 1점과 100점 환산을 사용한다. 관리자에게 문항별 배점/동일 배점 조정 기능을 제공한다. 소수 배점은 소수점 네 자리까지 지원한다.
- 시험지 풀이시간은 안내이며 자동 타이머가 아니다. 실제 제출 가능 시간은 관리자가 설정한 한국시간 시작/마감과 회차 상태로 서버가 판정한다.

관리자 흐름
1. 하프 또는 본시험 선택 후 회차를 만들고 제목/정답/배점/응시 기간을 저장한다.
2. 정답은 각 문항에 입력하거나 공백/쉼표/세미콜론으로 구분한 75개 또는 150개를 일괄 입력한다. ①~⑤도 허용한다.
3. 모든 정답이 입력되어야 응시 가능으로 변경할 수 있다. 작성 중 회차만 삭제할 수 있다.
4. 저장된 회차에 해설지 PDF를 최대 5개, 파일당 20MiB까지 업로드한다. 파일명 및 원본 바이트를 확인하고 서버에서 헤더/종료 표시/크기/해시를 검증한 뒤 게시한다.
5. 응시·성적 현황에서 제출/임시저장/미제출과 원점수/환산/등수를 확인한다.
6. 응시 종료 및 결과 공개를 모두 설정하면 제출 학생에게 성적·정답·해설지가 공개된다.
7. 제출자가 있는 회차의 정답/배점 정정은 5자 이상의 사유가 필요하다. 정정 이력을 보존하고 제출자 전체를 같은 트랜잭션에서 재채점한다.
- interview.read만 있는 관리자는 조회만 가능하며 수정/파일 업로드/삭제는 API에서도 차단된다.

학생 흐름 및 보존
- 유형/회차/영역을 선택해 답안을 입력한다. 미응답은 0점이며 한 문항 이상 입력해야 최종 제출할 수 있다.
- 기기 임시 답안은 계정+회차별로 분리한다. 서버 임시저장을 하면 다른 기기에서도 이어서 작성할 수 있다.
- 다른 기기의 저장 버전이 앞서면 덮어쓰지 않고 서버 답안을 보여주며, 이 기기의 이전 답안을 별도로 확인할 수 있다.
- 제출 후 수정할 수 없다. 중복 요청은 동일 요청 번호+동일 답안인 경우에만 같은 결과를 반환한다.
- 제출 응답이 끊기면 입력을 보존하고 상태 확인을 요구한다. 재조회가 미제출임을 확인한 뒤에는 같은 요청 번호로 다시 제출할 수 있다. 자동 재제출은 하지 않는다.
- 최종 제출, 응시 종료, 결과 공개 조건을 모두 충족해야 본인의 점수/등수/정답/해설지를 볼 수 있다. 다른 학생의 이름이나 답안은 전달하지 않는다.
- 동점은 공동 등수이며 1,1,3 방식이다. 미제출자는 순위에서 제외한다. 과거 제출자가 수강을 종료해도 당시 제출 집계에는 포함하지만 해당 학생의 현재 접근은 차단된다.

보안과 저장소
- 신규 테이블/RPC는 RLS 활성화 및 anon/authenticated 권한 회수 후 service_role만 사용한다. 기존 관리자 쿠키 또는 면접반 웹/기기 인증으로 서버가 actor를 결정한다.
- 학생 요청의 계정 바인딩을 검사하므로 로그인 계정이 바뀐 오래된 탭이 다른 계정에 답안을 저장할 수 없다.
- /api/interview-aptitude 응답은 no-store이며 서비스워커 API 캐시 대상이 아니다. 적성 모듈은 면접반 사용 시에만 불러온다.
- 해설지 bucket interview-aptitude는 비공개다. 경로는 회차 UUID/파일 UUID.pdf이며 다운로드 서명은 60초다.
- 브라우저는 서명된 경로로 직접 업로드하고, API에는 파일 바이트를 담지 않는다. Vercel 요청 본문 제한을 피한다.
- 해설지를 삭제하면 접근은 즉시 차단된다. 기존 업로드 서명이 만료되기 전 늦은 PUT으로 파일이 재생성되는 일을 막기 위해 물리 삭제는 파일 생성 후 최소 3시간 이후 정리한다.
- 정리는 관리자 업로드 준비/중단/삭제 요청 때 최대 20개씩 수행한다. 실패 경로는 큐에 남아 다음 요청에서 재시도된다. 별도 유료 Cron은 추가하지 않았다.
