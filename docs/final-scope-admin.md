# 회독 플랜 관리

관리자 메뉴의 **회독 플랜 관리**(`teacher.html#final-scope-admin`)에서
플랜 제목, 회차 번호·시험일·회독 일정, 과목별 일차와 학습 범위를 수정한다.
회차와 단원을 추가·삭제한 후 **플랜 저장**을 누르면 서버에 저장된다.
수정 중 회차를 전환해도 초안은 유지되며 저장 실패 시에도 입력을 보존한다.
**다시 불러오기**는 확인 후 저장되지 않은 초안을 버리고 최신 서버 값을 가져온다.

- `curriculum.read`는 조회, `curriculum.write`는 수정 권한이다. 관리자 `*` 권한도 적용된다.
- 기존 온라인 관리반·인터넷 수강생에게만 제공하며 직렬별 과목 필터를 유지한다.
- 수강생 앱을 새로고침하면 수정된 플랜을 불러온다. 안내 팝업의 제목과 회독 요약도 같은 데이터를 사용한다.
- 회차는 최대 30개, 번호는 중복 없이 1~999, 각 과목의 단원은 1~24개다.
- 시험일은 `9월 21일` 등 표시할 문구를 입력한다. 회독 일정은 `12-1 ~ 12-4`, `12-1~4`, `전 범위` 또는 안내 문구를 사용할 수 있다.
- 첫 저장 전에는 기존 `final-scope-data.js`의 12회차 플랜을 기본값으로 사용한다.

기존 `/api/app-settings`와 비공개 `__app_settings__` 설정 레코드의
`finalScopePlan` 필드를 사용한다. DB 스키마 변경은 없고 출석·좌석·기존 설정을
보존한다. 저장 시 서버에서도 전체 플랜과 수정 권한을 검증한다.
과목 이름과 수강생 직렬별 매핑은 고정된 기존 데이터에서 가져온다.

검증:

```text
node tests/final-scope-admin.test.cjs
node scripts/final-scope-admin-ui-qa.cjs
npm test
```
