# OX 홈 카드 즉시 표시

기준 운영 커밋: `22622ed`. 로컬 검증 완료 후 사용자가 배포를 승인했다.
main에 반영하고 연결된 Vercel 자동 배포로 운영에 적용한다.

기존에는 OX 표시 상태를 메모리에 30초만 보관해 새로고침·앱 재실행 시
카드를 숨긴 채 서버 확인을 기다렸다. 서버에서 이용 가능하다고 확인한 상태를
같은 학생·기기용 로컬 표시 정보로 최대 7일간 보관한다.

- 재실행 시 유효한 표시 정보가 있으면 첫 렌더링부터 카드를 표시한다.
- 상태 조회는 그대로 수행하며 등록 해제·학습 중지 응답 시 즉시 숨기고 표시
  정보도 삭제한다. 일시적 네트워크 오류는 기존 표시를 유지한다.
- 최초 기기, 계정·기기 변경, 유효기간 만료 시에는 서버 확인 후 표시한다.
- 저장 항목은 학생 ID·기기 구분용 지문·확인 시각뿐이다. 인증 토큰 원문이나
  문제·정답·학습 기록은 별도로 저장하지 않는다. 기기 지문은 표시 정보의 범위를
  구분하는 용도이며 인증 수단이 아니다.
- 로컬 정보는 권한을 부여하지 않는다. OX 진입과 학습 API는 계속 서버에서
  기기·수강생·등록·공개 여부를 검증한다. 진입에서 권한 오류를 받아도 표시
  정보를 삭제한다. 등록 해제 직후에는 상태 재확인 전까지 카드가 잠시 보일 수 있다.
- 다른 계정의 늦은 응답은 현재 계정의 표시 정보를 저장하거나 지우지 않는다.
- 저장소가 차단되거나 저장 내용이 손상돼도 기존 서버 조회 방식으로 동작한다.

검증: 새 런타임에서 서버 응답 전 즉시 표시, 등록 해제 후 숨김·삭제, 계정·기기
분리, 만료, 네트워크 오류, 권한 오류, 저장소 오류를 단위 테스트한다.
실제 로컬 브라우저에서도 메모리 캐시 초기화 후 카드가 즉시 표시됨을 확인한다.
