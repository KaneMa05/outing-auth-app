# 면접 질문 분류 — 전공·법령 지식 기준

2026-11-02 사용자 기준: 전공 질문이 아니면 인성으로 구분한다. 공채의 형법·형사소송법·해양경찰 관련 법령 지식도 전공에 포함한다.

## 분류 기준

- **직무**: 항해·기관·방제·관제·통신·구급 등의 전문 지식, 장비의 원리와 운용, 전문 현장 절차, 법령·범죄 구성요건·형사절차·경찰학 이론의 설명을 요구한다.
- **인성**: 개인 경험·경력·지원동기·태도·가치관·윤리적 판단, 기관에 대한 일반 이해와 관심, 시사·정책에 대한 견해 등 전공 외 질문이다.
- 낱말만으로 결정하지 않는다. ‘디젤 실린더 균열이 왜 생긴다고 생각하는가’는 전공 지식, ‘검경 수사권 분리 찬반과 이유’는 견해 질문이다.
- 법령 내용을 **설명한 뒤** 견해도 요구하면 전공 설명이 포함되므로 직무로 두고 복합 요구를 보존한다. 일반 기관 역할·홍보·지원 적합성과 법률상 권한·의무·수사 절차는 구분한다.
- 실제 질문이나 선행 문맥이 없어 의도를 확정할 수 없는 54문항은 현재 분류를 보존하고 확인 대상으로 남긴다. 제목만 보고 질문을 만들어내지 않는다.

## 재분류안

5,128개 운영 원문과 기존 의미 검토 자료를 대조했다. 과거 분류의 경계 사례와 이번에 추가로 검토한 281개 명시적 결정을 결합한 결과다.

| 변경 | 문항 |
| --- | ---: |
| 직무 → 인성 | 393 |
| 인성 → 직무 | 37 |
| 합계 | 430 |

변경 후 호환 집계는 직무 1,775개·인성 3,353개다. 의도 확정 보류 54개는 현재 분류로 포함한다.

운영 스냅샷에서 변경 대상은 공개 승인 131개·승인 대기 296개·보관 3개다. 공개된 질문은 새 분류를 확인하고 같은 트랜잭션에서 다시 공개 승인한다. 대기·보관 상태는 유지한다. 분류 변경은 원문·해설의 품질과 최신성을 새로 승인하는 작업이 아니다.

## 원문·음성·학생 내용 보존

질문 ID·원문·출처·해설·직렬은 보존한다. 인성으로 옮길 때 기존 준비 항목 중 의미에 맞는 항목을 연결하고, 직무로 옮길 때 인성 준비 항목 연결을 비운다. 학생 노트·답변과 기존 응시 스냅샷을 고치지 않는다.

현재 관리자 화면은 카테고리의 음성 목록에서만 질문을 찾는다. 재분류 후에도 정확히 같은 ID와 원문으로 다른 카테고리의 기존 녹음을 찾도록 보완한다. 녹음·대본·파일명·저장 위치는 변경하지 않고 새 음성을 생성하지 않는다.

분류 변경은 기존 트리거에 따라 해당 질문의 채점 기준·요소 분석 승인을 무효화한다. 다른 질문의 기준과 학생 내용은 보존한다. 새 분류의 기준을 자동 검토 완료 처리하지 않는다.

## 파일과 실행

- scripts/data/interview-specialty-classification-overrides.json: 사용자 기준에 따른 281개 원문·ID별 결정.
- scripts/prepare-interview-specialty-classification.cjs: 기존 2차 분류 근거와 새 결정을 결합하는 로컬 생성기.
- supabase/seeds/interview-specialty-classification.json: 전체 분류안과 근거. 원본 import와 과거 검토 파일은 보존한다.
- scripts/interview-specialty-reclassification.cjs: revision·원문·분류·연결·직렬·출처 지문을 확인하는 트랜잭션 생성기. 네트워크·운영 쓰기를 하지 않는다.
- client/interview-question-audio.js: 카테고리가 바뀐 질문의 기존 음성을 찾는 처리.

    node scripts/prepare-interview-specialty-classification.cjs

위 명령은 분류안만 생성한다. --snapshot <운영 스냅샷 JSON> --output <결과 JSON> 옵션으로 현재 상태에 맞는 변경 목록을 생성한다. 원문이 달라지면 중단한다.

운영 반영은 음성 연결 보완 배포 후 진행한다. **푸시·배포는 AGENTS.md에 따라 최종 사용자 확인 후 실행한다.** 분류안 생성과 로컬 검증만으로 운영 DB를 바꾸지 않는다.

## 검증

    node tests/interview-specialty-classification.test.cjs
    node tests/interview-question-audio-category.test.cjs

전공·법령/견해/기관 상식 경계, 전체 원문 일치, revision·출처 충돌의 전체 롤백, 승인·보관 상태 유지, 학생 노트·출처 보존, 감사 이력, 관련 검토 승인 무효화와 재실행 안전성을 확인한다.

음성 테스트는 재분류 후에도 전체 5,128개 질문이 원래 녹음과 연결되는지, 원문 수정 시 재연결 안내가 유지되는지, 잘못된 파일 경로와 목록 장애를 처리하는지 확인한다.

기존 공개 승인 DB 테스트·면접 준비 DB/API 테스트와 격리 빌드도 확인한다.
