# 면접 질문 직무·인성 재분류 — 2차 검토

2026-10-30 질문 은행 스냅샷 **5,128문항**을 대상으로 한 운영 반영 전 분류안이다. HWPX 가져오기 자료 5,083문항과 추가 질문 45문항을 포함한다. 푸시·배포·운영 DB 적용은 하지 않았다.

## 2차 결과

| 분류 결과 | 문항 수 |
| --- | ---: |
| 직무 | 2,047 |
| 인성 | 3,027 |
| 실제 질문 내용·문맥 확인 전 분류 보류 | 54 |
| 합계 | 5,128 |

직전 분류안에서 **74문항의 1차 분류를 수정**했다. 원본 대비 운영 변경 대상은 **267문항**으로, 직무→인성 174문항, 인성→직무 93문항이다. 보류 54문항은 변경 SQL에서 제외한다.

보류 기록은 JSON의 `category`에는 호환성을 위해 원본 분류를 보존하지만, `resolved_category=null`, `classification_status=needs_context`로 기록한다. 따라서 `report.after`의 직무 2,050·인성 3,078은 보류 기록을 포함한 호환 분류 수다. 분류안 집계에는 `resolved_categories`의 직무 2,047·인성 3,027과 보류 54를 사용해야 한다. CSV에는 보류 문항을 직무·인성으로 확정 표시하지 않는다.

**2,469문항은 원문을 읽고 변경 또는 유지 결정을 남겼다.** 양 분류의 경계 사례, 법률·기술 용어와 개인 경험이 충돌하는 질문, 문맥·안부·개인 배경 기록을 포함한다. 나머지 2,659문항은 명확한 지식·경험·가치 등의 유형을 기준으로 검토했다. 전체 문항의 원문·ID 보존과 분류 일관성을 검사했지만 5,128문항 모두를 각각 별도의 사람 검수로 승인했다는 의미는 아니다.

## 바로잡은 기준

- **직무**: 법령·기관 사실·전문 지식·업무 절차·현장 대응에 대한 설명이 중심이다. `본인`, `생각`, `경험`이 있어도 실제 기술·법률 설명이 필요하면 직무다.
- **인성**: 자기이해·경험·공직 가치·지원 동기·소통·조직 적응·윤리적 선택이 중심이다. `해경`, `상사`, `법` 같은 단어 자체로 직무가 되지 않는다.
- **윤리와 법률 지식**: 공정·윤리적 소비·성인지 감수성·2차 피해에 대한 이해는 공직 윤리와 가치 판단을 중심으로 분류한다. 법정 의무, 범죄 구성요건, 수사 절차와 구분한다.
- **시사와 의견**: 미투운동의 의미 설명과 미투운동에 대한 개인적 견해를 구분한다. 주제명만 남고 사실 설명·개인 의견·경험 중 무엇을 요구하는지 없는 기록은 확정을 보류한다. 법률·정책에 대한 찬반·개선 질문은 직무 분류에 포함되더라도 단일 정답형 지식 채점과 구분한다.
- **경력과 전문 지식**: 승선 기간·실제 사용한 엔진 모델·메이커·자재는 개인 경력 확인이다. 보일러 점화 불량 대응·항법·선박에서의 구조 절차는 직무 지식·현장 대응이다.
- **완결된 배경 질문**: ‘승선기간은?’, ‘몇 번째 지원인가?’, ‘그럼 평소에 유튜브 뭐 봐요?’는 질문 자체로 답변 가능하다. `그럼`만으로 문맥 필요 판정을 하지 않는다.
- **후속 질문과 누락 기록**: 분류 자체를 확정할 수 없는 54문항과, 평가 의도는 알지만 답변에 앞선 문맥이 필요한 후속 질문 39문항을 구분한다. 안부·진행 92문항도 별도 유형으로 기록한다.

원문·해설·출처상 이웃 문항을 대조했다. 다만 이웃 문항을 실제 부모 질문이라고 확정하거나 두 문항을 합치지 않았다. 해설만으로 누락된 질문을 만들어내지도 않았다. 질문과 맞지 않는 해설 2문항에는 검토 표시를 남겼다.

## 복합 요구

보조 의도를 함께 기록한 문항은 124개다. 이 중 독립된 요구가 명시된 **14문항**에는 원문 그대로 인용한 `assessment_parts`를 기록했다.

| 원문 질문의 요구 | 분리한 평가 의도 |
| --- | --- |
| 인재상을 설명하고 본인의 강점을 말하라 | 기관 지식 / 개인 적합성·강점 |
| 핵심가치와 그에 대한 생각 | 공식 명칭·내용 / 개인 가치 해석 |
| 법률 개념을 설명하고 유지·폐지 의견을 말하라 | 사실·제도 지식 / 정책 논거 |
| 중요하게 생각하는 공직관과 해경이 하는 일 | 개인 공직 가치 / 조직 업무 지식 |
| 불법 민원 요구에 대한 대응과 알고 있는 매뉴얼·법률 | 윤리·소통 판단 / 직무 지식 |

외국어 자기소개·진로 질문은 인성으로 유지한다. SMCP·관제 지시·현장 표현과 역할 시연은 별도 수행 유형으로 기록한다. `requires_open_ended_rubric`는 검토 정보이며 기존 채점 기준을 자동 승인하거나 수정하지 않는다.

## 파일과 재생성

`python3 scripts/reclassify-interview-questions.py`를 실행한다. 네트워크·유료 AI·음성 합성·운영 쓰기를 수행하지 않는다.

- `scripts/data/interview-classification-v1-baseline.json`: 1차 안에서 원본과 달랐던 279개 분류. 2차 안과의 비교 기준이다.

- `artifacts/interview-classification/changes-from-v1.csv`: 직전 안에서 분류를 수정한 74문항.

## 운영 반영과 검증

AGENTS.md의 푸시·배포 전 최종 확인 규칙에 따라 사용자 확인 후에만 운영에 적용한다. 직전에 현재 질문 은행을 비교하고 스냅샷 이후 추가·수정된 문항은 재검토한다. 빈 DB 재현에는 원본 seed와 추가 45문항을 먼저 적재해야 한다.

SQL은 대상 문항을 잠근 뒤 ID·원문·기존 분류·revision=1을 확인한다. 누락·원문 수정·버전 충돌 시 전체 트랜잭션을 중단한다. 이미 목표 분류이면 건너뛰므로 재실행해도 버전·감사 이력이 늘지 않는다. 변경 전 질문과 근거는 `ip_history`에 남기고, 기존 트리거로 해당 문항의 채점 기준·인성 분석 승인을 무효화한다. 새 분류의 기준은 다시 검수해야 한다.

직무로 옮긴 문항은 인성 소재 연결을 비우고, 인성으로 옮긴 문항은 기존 준비 항목 ID에 의미 기준으로 연결한다. 분류가 같은 문항, 보류 문항, 학생 작성 내용, 원문 해설, 기존 응시 스냅샷과 다른 수강생 화면은 변경하지 않는다. 공개 승인 마이그레이션을 적용한 뒤에는 분류가 바뀌는 공개 문항이 승인 대기로 돌아가므로 새 분류를 확인하고 다시 공개 승인해야 한다. 세부 유형·보조 의도·보류·복합 평가 정보는 검토 자료이며 운영 UI·출제·채점에 자동 적용되지 않는다.

`tests/interview-question-classification.test.cjs`는 로컬 PostgreSQL 호환 DB로 경계 사례와 복합 요구, 54개 보류 제외, 누락·원문·버전 충돌의 전체 롤백, 같은 문구의 분류 일치, 기존 관리자 검색, 승인 무효화, 학생 작성 내용·해설·공개 상태 보존과 재실행 안전성을 확인한다. 기존 `tests/interview-prep.test.cjs`와 격리 빌드 `scripts/verify-interview-build.cjs`도 실행한다.
