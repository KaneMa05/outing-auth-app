# 의견 나누기

- 수강생: 스터디카페의 빨간 확성기 공지 → 의견 나누기. 온라인 관리반·인터넷 수강생 화면에서 이용합니다.
- 새 기능 미리보기: 공개된 소개글의 사진(최대 3장), 설명, 질문을 보고 해당 기능에 의견을 남깁니다. 사진을 누르면 확대됩니다.
- 자유 건의: 기능 소개와 관계없는 새로운 의견을 남깁니다. 기존 의견은 이 탭에 유지됩니다.
- 공개 의견은 다른 수강생도 볼 수 있고, 비공개 의견과 답글은 작성자와 관리자만 볼 수 있습니다.
- 의견·답글 아래의 ‘삭제’는 작성자 본인과 관리자에게 표시됩니다. 의견을 삭제하면 달린 답글도 모두 삭제되고 목록에서 사라집니다. 삭제된 의견의 답글은 직접 조회하거나 추가할 수 없습니다. 답글의 삭제 버튼은 해당 답글만 삭제합니다.
- 관리자: 온라인 스터디카페 → 의견 · 새 기능 관리. 소개글을 작성·수정하고 ‘수강생에게 공개’를 선택합니다. 공개한 글의 ‘공지에 연결’을 누르면 수강생이 공지를 눌렀을 때 그 소개글이 열립니다. 공지 문구는 ‘여러분들의 의견을 듣고자합니다.’로 유지됩니다.
- 소개글의 공개를 해제하면 수강생에게 글과 의견이 숨겨지며, 관리자에게는 기존 의견이 유지됩니다. 가장 최근 공지 연결을 설정한 공개 글이 열립니다.

## 로컬 확인

`npm run dev:local` 실행 후 수강생 화면은 `http://localhost:3000/#feedback`, 관리자 미리보기는 `http://localhost:3000/_local/admin-preview`에서 엽니다. 수강생은 기존 로컬 미리보기 인증을 사용합니다.

의견·답글은 `.local-study-cafe-feedback.json`, 소개글·사진은 `.local-study-cafe-feedback-features.json`에 저장됩니다. 로컬 브라우저들은 같은 로컬 서버의 저장 파일을 공유합니다. 파일은 Git과 배포에서 제외되고 웹에서 직접 열 수 없습니다. 로컬 의견은 운영 데이터와 별개입니다.

## 운영 반영 순서

푸시·배포 전 사용자 최종 확인이 필요합니다. 2026-09-11 사용자 요청에 따라 RONPARK APP 운영 DB에 의견 나누기 스키마를 적용했습니다. 이번 작업에서는 앱 푸시·배포를 진행하지 않았습니다.

적용 기록은 `supabase/migrations/20260911053530_add_study_cafe_feedback_hub.sql`이며 운영 migration 버전과 일치합니다. 새 소개글 테이블·권한·인덱스와 기존 `question_posts.feature_preview_id`를 추가했습니다. 기존 글은 NULL로 남아 자유 건의로 표시됩니다. 사진은 기존 비공개 `question-board-images` 버킷의 `feature-previews/` 경로에 저장합니다. 로컬의 예시 글과 사진은 운영 DB로 복사하지 않았습니다.

스키마와 기존 사진 버킷을 확인한 뒤 API와 정적 파일을 함께 배포합니다. 기존 클라이언트는 featureId 없는 요청으로 자유 건의를 계속 이용합니다. 캐시 버전은 `sw.js`에서 관리합니다.

## 검증

`npm test`에 기능별 저장·공개 범위·사진 유지·의견 분리·관리자 답글·탭 전환·중복 저장 방지 테스트를 포함합니다. 로컬 HTTP 흐름과 격리한 빌드도 확인했습니다. 브라우저 화면의 시각 검수는 별도로 필요합니다.

운영 적용 전후 기존 게시글 3건의 데이터 해시가 일치했고, 답글 0건도 유지되었습니다. RLS, 일반 클라이언트 접근 차단, 서버 권한, 외래 키와 인덱스를 확인했습니다. 서버 역할로 소개글을 저장·수정·조회하는 검증은 트랜잭션을 롤백하여 테스트 글을 남기지 않았습니다.

보안 점검 결과 오류·경고는 없고, 새 테이블에는 [RLS 정책 없음 안내](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)가 표시됩니다. 인증된 서버 API만 사용하는 구조이므로 anon/authenticated 권한을 제거하고 정책 없이 차단하는 의도된 설정입니다. 새 인덱스의 [미사용 안내](https://supabase.com/docs/guides/database/database-linter?lint=0005_unused_index)는 운영 요청이 아직 없어서 표시됩니다.
